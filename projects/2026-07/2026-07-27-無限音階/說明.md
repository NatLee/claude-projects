# 爬不到頂的音階

## 這頁的故事線

- **鉤子**：一段能「永遠往上爬、卻永遠到不了頂」的聲音。近全黑的第一屏不下定義，只丟一句大膽斷言＋一個「你」——你其實聽過它，只是沒認出來。
- **高潮（使用者親手觸發）**：進入第二幕，畫面是一座沉浸式全螢幕的透視樓梯。你**按住**一顆圓鈕（或空白鍵）親手往上爬，音真的越升越高，階數一路往上跳，你會忍不住想再爬高一點。
- **轉折**：爬了二十幾階、手指都痠了，旁邊那個「實際音高」轉盤卻悄悄轉了好幾圈又回到原點。第三幕拉開真相：**你爬了 N 階，卻一步都沒往上**——它是一座頂接著底、關起來的樓梯（用一圈轉不停的側視階梯環演示）。
- **拆穿**：第四幕掀開機關。你以為的「一個音」其實是一疊相隔八度的正弦波；往上爬時最高的悄悄淡出、最低的悄悄長出，中間永遠有音撐著，接縫你聽不到。打開「拆穿把戲」開關，只留兩個音、拿掉遮罩，你就會**親耳聽到**那一下「啪」的跳回底部。
- **記憶點**：第五幕告訴你在哪聽過它（《敦克爾克》、《黑暗騎士》蝙蝠機車、超級瑪利歐 64 的無盡樓梯），再用一個橫跨造訪的計數器補上回馬槍——「你今天爬了 N 階，加上以前總共 M 階，你還站在第一階」，並邀請你明知是騙局、還是忍不住再按一次。

容器/敘事形式：**沉浸式全螢幕＋分章旅程**（五幕），刻意避開近幾天用過的假報紙、捲動守夜、猜數字圓點。

## 這是什麼

一個把 **謝帕德音階（Shepard tone）** 這個聽覺錯覺，包裝成一段可玩故事的互動頁。謝帕德音階是 1964 年由認知科學家 Roger Shepard 提出的錯覺：把好幾個相隔八度的正弦波疊在一起，整體同步上升，同時最高的分音淡出、最低的分音淡入，於是聽起來永遠在升、卻永遠回到原點——聲音版的「無盡樓梯 / 理髮廳旋轉燈柱」。Jean-Claude Risset 後來把離散版本磨成連續無縫的滑音（Risset glissando）。

聲音完全由 Web Audio 即時合成（8 個 `OscillatorNode` ＋各自的 `GainNode`，經一個低通濾波器），**沒有任何錄音檔**。

## 怎麼玩

1. 戴上耳機、把音量轉小，按「開始」。
2. **按住**中央的圓鈕往上爬（也可用滑鼠／手指按住，或按住空白鍵、方向鍵↑）。看階數往上跳、樓梯往下捲。
3. 爬過門檻後，按「我到底爬了多高？」看真相——注意那個「實際音高」轉盤其實一直在繞圈。
4. 進到「拆穿把戲」，打開開關，親耳聽出那個被藏住的接縫。
5. 最後再爬一次，體會「明知被騙、還是停不下來」。

## 為什麼有趣

- **互動就是故事的高潮**：升與不升這個矛盾，由你親手把音推高才成立——不是掛在說明卡旁邊的小工具。
- **看得見的錯覺**：透視樓梯、繞圈轉盤、頻譜上滑動淡入淡出的分音，把「為什麼你會上當」畫出來。
- **一個漂亮的數學保證**：8 個八度、8 個等距分音、Hann 遮罩，數學上可證 **總響度恆為常數（=4）**，與相位無關——所以你永遠找不到「最大聲的頂點」，也聽不到接縫。（證明：8 個等距取樣點上 `cos(2π·pos/8)` 的總和為 0，故 Σ 遮罩 = 8×0.5 = 4。）

## 技術與 localStorage 註記

- 純靜態、單一 `index.html`、自包含；`file://` 雙擊可開，未使用任何外部資源或 `fetch()`。
- 音訊在使用者第一次點擊「開始」時才建立 `AudioContext`（瀏覽器自動播放政策要求手勢解鎖）；分頁隱藏時 `suspend()`、回來 `resume()`。
- 動畫只用 canvas 的 transform/漸層，rAF 迴圈於分頁隱藏時暫停；完整支援 `prefers-reduced-motion`（進場動畫關閉、演示自動旋轉凍結、數字不做滾動，攀爬仍可手動操作）。
- localStorage 前綴 `stair.`：
  - `stair.total`：跨造訪累計爬的階數（用於尾聲的回馬槍計數）。
  - `stair.last`：上次造訪時間戳。
- 核心音高／遮罩為純函式，另以 node 斷言驗證：響度恆為 4、每八度完美循環、接縫靜音、頻率有界、拆穿模式如預期。
