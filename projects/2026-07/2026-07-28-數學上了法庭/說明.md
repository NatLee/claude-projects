# 數學上了法庭 — People v. Collins（1968）

## 這一頁的故事線

- **鉤子**：一份加州最高法院的卷宗攤在桌上。本案沒有任何人能明確指認被告——檢方還是贏了，靠一位從沒到過現場的證人。
- **鋪陳**：1964 年那條巷子裡的四十秒；被害人認不出人，唯一目擊者在列隊指認時也不確定。檢方傳喚最後一位證人：一位數學講師。
- **第一次互動**：讀者親手「跟著他乘一次」，看六個分數相乘滾到一千二百萬分之一，然後「有罪」的紅章砸下來。讀者這時是站在檢方那一邊算完這題的。
- **轉折**：三年後卷宗重開。破綻一——那六個數字沒有一個有出處，而且彼此不獨立（讀者逐列點開，把它們一條條劃掉）。
- **高潮（讀者觸發）**：破綻二才是致命的。1/12,000,000 誠實地回答了一個問題，只是沒有人該問那個問題。讀者按下「換一個問題，重算一次」——一百格方陣亮起第二顆紅點，巨大的數字從 0 滾到 **41.8%**：在「至少有一對」的世界裡，有四成以上不只一對。滑桿讓讀者親手改變「當時可能在場的情侶總數 N」，並發現答案完全取決於一個法院自己也說無法確定的數字。
- **記憶點**：附錄最後一行，法官留下 (e−2)/(e−1) ≈ 41.802%——一樁三十五美元的搶案，最後留在判決書裡的是一個常數。然後鏡頭拉遠：三十五年後的倫敦，同一個問錯的問題又走進另一間法庭。收在「那個數字從來沒有說謊，它只是很誠實地回答了一個沒有人該問的問題。」

## 這是什麼

「檢察官謬誤」（prosecutor's fallacy）的一堂課，包成一份法庭卷宗。它講的是條件機率裡最容易被調包的一步：
**P(證據｜無辜)** 很小，不等於 **P(無辜｜證據)** 很小。

## 怎麼玩

1. 往下捲，讀證物 A 與證物 B。
2. 在證物 B 按「跟著他，乘一次」，看六個分數依序相乘到 1/12,000,000，判決章落下。
3. 在破綻一，逐列點開六項特徵（可用鍵盤 Tab + Enter），把它們一條條劃掉。
4. 在破綻二按「換一個問題，重算一次」——這是全頁的高潮。
5. 拉動下方滑桿改變 N（可能在場的情侶總數），看那個百分比怎麼隨之飄移。

## 為什麼有趣

檢方的算式其實沒有「算錯」。1/12,000,000 就是那六個分數的乘積。真正的錯誤發生在算式之外：它回答的是「隨機一對情侶剛好長這樣的機率」，而陪審團要知道的是「既然已經存在一對這樣的情侶，會不會還有第二對」。同樣一組數字，換個問法，從一千二百萬分之一變成四成一。

而那個四成一還有個更漂亮的尾巴：當 N 很大且 p = 1/N 時，這個機率會收斂到 (e−2)/(e−1) ≈ 41.802%。法院把它寫在判決書附錄的最後一句。

### 41.8% 是怎麼算出來的

完全照抄判決書附錄的推導。令 p = 1/12,000,000 為單一情侶符合全部特徵的機率，N 為當時可能出現在該區域的情侶總數：

- 至少一對符合： `B = 1 − (1−p)^N`
- 恰好一對符合： `E = N · p · (1−p)^(N−1)`
- 在「至少有一對」的條件下，還有第二對的機率： `(B − E) / B`

法院寫道：N 在案發區域「超過數百萬」，此時商數很快超過 4/10；當 N 接近 1,200 萬時約為 41%。並補了一句：若 p = 1/N 且 N 趨近無限大，此商數的極限為 (e−2)/(e−1)。

程式實作上，`(1−p)^N` 在 p 極小時直接用 `Math.pow` 會流失精度，因此改用 `Math.expm1(N·Math.log1p(−p))` 計算，於 N = 1.2×10⁷ 時得 0.418023…，與 (e−2)/(e−1) = 0.418023… 完全一致（因為此時恰好 N·p = 1）。

已用 node 斷言驗證的性質：

- 六項分母乘積等於 12,000,000
- N = 12,000,000 時結果趨近 (e−2)/(e−1)，差距 1.0×10⁻⁸（即 O(1/N) 的有限項殘差）
- 隨 N 單調遞增；N → 極小時趨近 0
- 與蒙地卡羅模擬（Poisson 近似，10 萬次）在 1 個百分點內吻合

### 一個必要的說明

判決書原文使用的是 1968 年的用語（如 "Negro"），本頁中譯改為中性表述。頁面上「41%」的正確讀法是「在已知至少存在一對符合特徵的情侶的前提下，存在第二對的機率」，而不是「被告無罪的機率有 41%」——後者需要另外的先驗資訊。維基百科條目在這一句上的措辭稍嫌寬鬆，本頁採判決書附錄的原意。
