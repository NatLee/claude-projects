# 平均報酬騙了你

> 一張宣傳單寫著「四年平均年報酬 +25%」。它沒有說謊。四年後，你的一百萬還是一百萬。

---

## 這一頁的故事線

**鉤子。** 第一屏不是標題，是一張做得很像真的基金宣傳單：俗氣的金、驚嘆號、星形貼紙、
斗大的「四年平均年報酬 **+25%**」，右上角還有一顆星號和一段密密麻麻的小字。
下面只有一句旁白：**「這句話沒有說謊。」** 什麼都不解釋。

**轉折。** 往下捲，你按一下按鈕，那四個年度被一張一張攤出來：
**+100%、−50%、+100%、−50%**。加起來除以四，真的就是 +25%。
廣告一個字都沒騙你——它只是選了一種平均。這裡蓋上一枚紅色印章：**算術平均**。

**高潮。** 一個按鈕：「那我的 100 萬呢？」按下去，資產曲線一段一段長出來，
數字同時跟著滾：200 萬 → 100 萬 → 200 萬 → 100 萬。
曲線最後**剛好停在本金那條虛線上**。四年後你回到原點。廣告 +25%，你實拿 0%。
這個「哇」必須由使用者親手按下才會發生。

**記憶點。** 最後一記回馬槍：跌掉的百分比和漲回來的百分比從來不對等。
賠 10% 要賺 11.1%，賠 50% 要賺 100%，賠 90% 要賺 900%。
收在一句邀請：**「下次看到『平均報酬』四個字，先問一句：平均的，是哪一種平均？」**

**視覺上的 before / after 本身就是敘事**：第一屏是奶油紙、金箔、襯線字的廣告世界；
翻過那條金線之後，整個頁面換成深色、等寬字、格線、克制的資料語言。

---

## 這是什麼

一頁講「算術平均 vs 幾何平均」與**波動拖累（volatility drag）**的互動敘事。
四個章節：

1. **第一章 · 攤開那四年** — 按鈕翻出四個年度報酬，親眼看見 +25% 是怎麼算出來的。
2. **第二章 · 那我的錢呢** — SVG 資產曲線逐段繪製 + 數字滾動，四年走完回到原點。
3. **第三章 · 這不是特例，是規則** — 一支滑桿把算術平均**釘死在 +8%**，
   只調整波動度 σ（0% → 60%），看二十年後的終值從 466 萬一路掉到 12 萬。
   同時對照那條好用的近似式 `幾何 ≈ 算術 − σ²∕2`，並讓你親眼看到它在高波動時開始失準。
4. **第四章 · 換你自己的數字** — 一個真的能用的工具：輸入任意年度報酬序列
   （可增可刪、可改本金，附四組一鍵情境），即時算出算術平均、年化報酬（CAGR）、終值，
   以及兩者的落差（單位：百分點）。

## 怎麼玩

- 按「把那四年翻出來」看廣告的算法；再按一次可以重播。
- 按「那我的 100 萬呢？」啟動主動畫。按「再看一次」可重播。
- 拉第三章的滑桿（鍵盤左右鍵也可以）。四個讀數與曲線即時更新。
- 第四章：點預設情境、直接改任一年的數字、按「＋ 加一年」或每列右邊的「×」。
  本金也可以改。輸入 −100% 是合法的（歸零）；輸入小於 −100% 會被擋下並標紅。
- 你在第四章編輯的序列與本金會留在瀏覽器裡，下次打開還在。

## 為什麼有趣

因為那張宣傳單**真的沒有說謊**。這不是揭發詐騙，是揭發一個合法、常見、
而且每個人都看得懂卻很少去想的語意陷阱：「平均」有很多種，
而金融產品的廣告用的那一種，跟你戶頭裡的那一種，不是同一種。

+100 / −50 這組數字之所以好用，是因為它把落差推到最極端又最乾淨：
算術平均 **正好** +25%，四年連乘 **正好** 等於 1，終值 **正好** 等於本金。
沒有四捨五入，沒有「大約」。

## 資料來源與方法論

### 數學事實

- **算術—幾何平均不等式（AM–GM）**：對任意一組非負數，幾何平均 ≤ 算術平均；
  等號成立**若且唯若所有數字都相同**。把 (1+r₁), (1+r₂), … 代進去就得到：
  只要年度報酬不是每年都一模一樣，**幾何平均嚴格小於算術平均**。
  你實際拿到手的是幾何平均（＝ CAGR），不是算術平均。
- **本頁核心案例**：報酬序列 +100%、−50%、+100%、−50%。
  - 算術平均 = (1 − 0.5 + 1 − 0.5) ÷ 4 = **0.25**（精確值，不是近似）
  - 累積成長 = 2 × 0.5 × 2 × 0.5 = **1**
  - CAGR = 1^(1/4) − 1 = **0**，終值 = 本金
  這三件事在 IEEE754 浮點數下也都是**精確相等**，已寫成斷言測試（見下）。
- **常用近似式**：`幾何平均 ≈ 算術平均 − σ² ∕ 2`（σ 為報酬的標準差）。
  **⚠ 這是近似，不是恆等式。** 它來自對 ln(1+r) 做二階泰勒展開，
  在報酬幅度小、波動不大時貼得很緊，波動一大就會偏離。
  頁面第三章直接把「真值」與「近似值」並排顯示，讓這個偏離看得見：
  σ = 5% 時誤差約 0.009 個百分點；σ = 50% 時誤差擴大到約 0.23 個百分點。
  要精確答案，只能老實把每一年乘一遍。
- **回本算式**：賠掉比例 L 之後，需要 `L ∕ (1 − L)` 的報酬才回到原點。
  賠 10% → +11.1%；賠 20% → +25%；賠 30% → +42.9%；賠 50% → +100%；賠 90% → +900%。
  頁面上那張表的數字是用 `breakevenGain()` 現場算出來的，不是寫死的字串。

### 第三章的實驗設計

滑桿背後不是模擬，是一組刻意造出來的兩態序列：每年輪流 `(m + σ)`、`(m − σ)`，
共 20 年，m 固定 = 8%。年數為偶數時，這組序列的**算術平均恰好等於 m、母體標準差恰好等於 σ**。
所以拉動滑桿時，唯一變動的變數真的只有波動度——這是一個乾淨的對照實驗，
不是「隨機跑一跑看起來會怎樣」。

閉式解：幾何平均 = √((1+m)² − σ²) − 1。頁面顯示的是逐年連乘的結果，兩者一致。

### 報酬單位約定

- **`math.js` 內部一律使用小數**：`0.25` = +25%，`-0.5` = −50%，`0` = 0%。
- **UI 層（第四章輸入框）使用百分比整數**：使用者輸入 `100` 代表 +100%，
  在送進 `math.js` 之前除以 100。這個轉換只發生在 `index.html` 的 `compute()` 一處。
- 合法範圍是 `r >= -1`。小於 −1 的報酬不存在（不可能賠掉超過本金的全部），會丟 `RangeError`。

## 技術註記

### 檔案

```
index.html   單一入口。CSS 與敘事層 JS 全部內嵌。
math.js      純函式核心，不碰 DOM。瀏覽器用一般 <script src> 載入，node 也 require 得到。
說明.md      本檔。
```

### 純函式 API（`math.js`）

| 函式 | 說明 |
| --- | --- |
| `arithmeticMean(returns)` | 算術平均。空陣列回傳 `null`。 |
| `geometricMean(returns)` | 幾何平均。空陣列回傳 `null`；期間內歸零則回傳 `-1`。 |
| `cagr(returns)` | 年化報酬。年度序列下就是 `geometricMean`，另開名字方便查找。 |
| `growthFactor(returns)` | 累積成長倍數 Π(1+r)。空陣列回傳 `1`。 |
| `finalValue(principal, returns)` | 終值。空陣列回傳本金。 |
| `cumulativeValues(principal, returns)` | 逐年資產陣列，長度 n+1，畫曲線用。 |
| `stdev(returns, sample)` | 標準差。預設母體公式（除以 n），`sample=true` 改樣本公式。 |
| `breakevenGain(loss)` | 回本所需報酬 `L/(1-L)`。`loss >= 1` 回傳 `Infinity`。 |
| `approxGeometric(arith, sigma)` | 近似式 `arith - σ²/2`。**只是近似**。 |
| `makeVolSeries(mean, sigma, years)` | 造出「算術平均固定、波動可調」的兩態序列（第三章用）。 |
| `round12(x)` | 把浮點誤差修到小數第 12 位。 |
| `assertReturns(returns)` | 輸入驗證，非法就丟 `TypeError` / `RangeError`。 |

`round12` 存在的理由：`0.9 / (1 - 0.9)` 在 IEEE754 下是 `9.000000000000002`，
不修掉的話 `breakevenGain(0.9) === 9` 會是 `false`，表格也會印出一串醜數字。

結尾以 `module.exports` 匯出，**不是 ES module**：
瀏覽器用一般 `<script src="math.js">`，node 用 `require()`，兩邊同一份檔案。

### 邊界處理

- 空陣列：平均類回傳 `null`（「沒有資料」不是「平均 0」）；`finalValue` 回傳本金。
- 報酬 = −100%：資產歸零，之後怎麼漲都是 0；`geometricMean` 回傳 −1。
- 報酬 < −100%：丟 `RangeError`，UI 會標紅並顯示訊息、清空結果。
- 空欄位 / `NaN` / `Infinity` / 非陣列：丟 `TypeError`。
- 本金 0：不會出現除以零。
- 第四章年數上限 40 年，最後一列不能刪。

### 渲染與動畫

- **完全不用 canvas**，三張圖都是手寫 SVG（`viewBox` + `width:100%`，不需要 dpr 或 ResizeObserver）。
- **不用漸層描邊**。所有折線與格線都是純色 `stroke`，避開
  「`stroke:url(#g)` 搭 `objectBoundingBox` 會讓水平／垂直線整條不繪製」這個地雷。
  唯一的 `drop-shadow` 掛在群組 `<g id="c2-lines">` 上，不掛在個別路徑上。
- **描線動畫可靠重播**：`transition:none` → 設 `strokeDashoffset = 全長` →
  讀 `getBoundingClientRect()` 強制 reflow → 下一個 `requestAnimationFrame` 才開 transition
  並設 `dashoffset:0`。路徑點由左而右產生，動畫方向與閱讀方向一致。
- 直線段的長度**用畢氏定理自己算**，不呼叫 `getTotalLength()`——有些環境（例如 jsdom）沒實作它。
- 動畫只用 `transform` / `opacity`（加上描線用的 `stroke-dashoffset`）。
- 滑桿以 `requestAnimationFrame` 節流，不會每個 input 事件都重畫。
- `document.hidden` 時動畫直接跳到終值；`visibilitychange` 會把進行中的動畫收尾。

### 防呆與退路

- `prefers-reduced-motion`：以 `typeof window.matchMedia === 'function'` 檢查後才用，
  並同時支援 `addEventListener('change')` 與舊版 `addListener`，動態追蹤變化。
  開啟時所有動畫直接跳終值，內容一項不少。
- `IntersectionObserver` 不存在時，所有 `.reveal` 元素直接顯示——**不會整頁空白**。
- `requestAnimationFrame` 不存在時退回 `setTimeout`。
- `localStorage` 被停用或丟例外（無痕模式、`file://` 的某些設定）時，讀寫都包在 `try/catch`，
  頁面照常運作，只是不記錄。

### localStorage

只有兩個 key，都帶 `voldrag_` 前綴：

| key | 內容 |
| --- | --- |
| `voldrag_seq` | 第四章的年度報酬序列（JSON 陣列，單位百分比） |
| `voldrag_principal` | 第四章的本金（字串，單位萬元） |

讀取時會驗證：必須是陣列、長度 1–40、每個元素都是有限數字，否則當作沒有存過。

### 自包含

無 `type="module"`、無 `fetch()`、無任何外部資源（連 cdnjs 都沒用到，圖表全部自己畫）。
雙擊 `file://` 直接可開。

### 測試

1. **語法**：`node --check math.js`，以及用 `vm.Script` 檢查 `index.html` 的內嵌 script。
2. **純函式斷言**（24 項）：核心案例三個精確相等、平穩報酬時算術＝幾何、
   隨機 200 組序列驗證 AM–GM、`breakevenGain(0.5) === 1`、`breakevenGain(0.9) === 9`、
   −100% 之後終值為 0、空陣列不爆、非法輸入被擋、近似式在高波動時偏離。
3. **jsdom 冒煙測試**：把 `math.js` inline 進 HTML 後餵給 jsdom
   （jsdom 沒有 `matchMedia`、沒有 `IntersectionObserver`、沒有 `rAF`，正好驗證上面那些退路），
   點過每一個按鈕、改過每一種輸入、拉過滑桿，確認 0 個 JS 執行錯誤，並比對關鍵文字節點的數值。
   另外再用 opaque origin（`about:blank`）跑一次，驗證 `localStorage` 丟例外時頁面依然正常。
