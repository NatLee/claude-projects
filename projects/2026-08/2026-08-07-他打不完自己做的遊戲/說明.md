# 他打不完自己做的遊戲

**2026-08-07｜創意・娛樂**

## 這一頁的故事線

- **鉤子**——「這款遊戲太難了，他打不完。而那款遊戲，是他做的。」不解釋、不定義，先把矛盾丟在你臉上。
- **鋪陳**——他的工作是每天把它從頭打完一次。你按下「跑一次測試」，親眼看飛船撿了三格火力、被打一下、全部歸零。按第二次、第三次，頁面開始念你：「你大概已經開始不耐煩了吧？」
- **轉折的前置**——他替自己開了一道後門，條件互相打架：好記到手指自己會走，又絕對不能誤觸。答案分三段揭曉：↑↑↓↓／←→←→／BA。
- **高潮（由你觸發）**——第三章把遊戲替你暫停好。**你必須自己按出那十下**。錯一下，螢幕震一下，從頭。按對，火力表六格依序點亮、兩顆 OPTION 開始繞著飛船轉、FULL POWER 浮出、8-bit 音階響起。
- **轉折**——這段程式碼本來要刪掉。發現時卡帶已經在準備量產，團隊決定不刪。你剛剛按的那十下，是一件忘了收拾的東西。
- **擴散**——「玩家大概一輩子也碰不到」這句話錯得非常徹底。你再按一次同樣的十下，每按一下亮一塊磁磚，十下剛好照亮它跑到過的十個地方。
- **記憶點**——2020 年 2 月 25 日，橋本和久過世，61 歲。全世界的訃聞標題只寫了同一件事。「一段他打算刪掉的程式碼，替他活到了現在。」最後一句邀請：這一頁也埋了一組，再按一次——按對了，整個畫面轉成磷光綠，只留下那十個符號和他的生卒年。

## 這是什麼

一頁講「Konami Code（コナミコマンド）」身世的互動敘事。它不是列冷知識，而是把同一組按鍵在頁面上用三次，每一次意義都不同：第一次是**解放**（你拿到全部火力）、第二次是**擴散**（它跑進十個地方）、第三次是**悼念**（它成了一個人的墓誌銘）。

## 怎麼玩

1. 第一章：按「▶ 跑一次測試」，看火力歸零。多按幾次，文案會跟著變。
2. 第三章：用鍵盤方向鍵、`B`、`A`，或點畫面上的手把，按出 `↑↑↓↓←→←→BA`。錯一下從頭（若按錯的那下剛好是開頭的 ↑，會被當成新的第一下）。
3. 第五章：同一串按鍵再按一次，磁磚一塊一塊亮起。
4. 結尾：解開第三章之後，在頁面任何地方（或用結尾的小手把）再按一次，會有最後的彩蛋。
5. 右上角 `♪` 可以關掉 8-bit 音效。

## 為什麼有趣

- 它是「工程師的私人捷徑意外變成全球流行文化」最乾淨的個案：一段本來要刪掉的除錯碼，活得比作者還久。
- 那串按鍵的設計本身是一道工程權衡題——**好記**與**不可誤觸**互為反面，而 ↑↑↓↓←→←→BA 同時滿足了兩邊，還漂亮得像兒歌。
- 決定不刪的理由非常工程師：「動它可能生出新的 bug。」三十幾年的文化現象，起點是一次風險評估。

## 方法論與取捨

- **只寫查得到的**：頁面裡沒有虛構的開發日誌或引號對白。「打不完自己移植的遊戲」「本來要刪掉」「發現時已在準備量產」「決定不刪是因為怕生出新 bug」皆出自上列來源；沒有來源支持的細節（例如卡在第幾關）一律不寫。
- **火力表的六格**（SPEED UP／MISSILE／DOUBLE／LASER／OPTION／?）沿用《Gradius》原本的強化道具列，不是自己編的。
- **飛船、膠囊、爆炸都是示意**，不是原作素材；全站不外連，圖形一律用內嵌 SVG 與 CSS 畫。
- **寬容的重試規則**：按錯時如果那一下剛好是序列開頭的 ↑，就當作新的第一下，避免使用者卡在「連按兩次上」的地方永遠重來。這條規則以 `logic.js` 的純函式實作，並用 node 斷言驗證（十組情境，含越界與無效輸入）。

## 技術註記

- 純靜態、單一資料夾、`file://` 雙擊可開；沒有外部資源、沒有 `fetch()`、沒有 ES module。
- 邏輯抽在 `logic.js`（`KonamiLogic.normalize` / `feed` / `glyphs`），沒有 DOM 依賴，可直接在 node 裡跑斷言。
- 動畫只用 `transform` / `opacity`；星空是兩份一模一樣的星點靠 `translate3d(-50%)` 循環接合。分頁隱藏或兩個螢幕都離開視野時，動畫以 `animation-play-state:paused` 停下。
- `prefers-reduced-motion` 完整降級（含 `matchMedia` 的 `change` 監聽）：第一章的測試直接跳到結果、火力表一次點亮、不震動。
- 鍵盤方向鍵只有在互動區進入視野時才 `preventDefault()`，其他時候留給使用者捲頁。
- localStorage 前綴 `konami86.`：`konami86.sound`（音效開關）、`konami86.cracked`（是否解開過）。
