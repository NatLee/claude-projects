# 下一次該在哪一天

## 故事線

- **鉤子**：不從「間隔效應是什麼」開始，而從讀者的處境切進去——你昨天背完五十個字，今天早上一半已經不見了，而你不知道下一次該什麼時候再看。第一屏給的是一個問題，不是一段定義。
- **轉折**：第一章指出真正的問題不是懶惰，是「行事曆上沒有那一格」。第二章揭曉這件事其實有標準答案，但那個答案會先反問你一個從來沒有人問過你的問題——**你想記多久？** 最佳間隔不是一個固定天數，它跟著保留期走：幾週的保留期約 20%，一年的保留期約 5%。
- **高潮（由使用者觸發）**：第三章把日期輸入框交給讀者。他填進自己的考試日、按下「排給我看」，一份具體的日期清單當場長出來（每一格標出距離目標幾天、這次間隔佔保留期百分之幾），同時三條記憶曲線在下面畫上去：不複習、集中一天複習完、照這份排程複習。被撐住的那條曲線自己說話。
- **記憶點**：一句帶得走的心算——**剩下的天數 ÷ 5**（目標在一年以後改成 ÷ 20）。收尾之後工具仍可反覆使用：換日期、換排法、重設。

## 這是什麼

一個「間隔複習排程器」。你給它一個必須「還記得」的日子，它回你一份可以直接照著做的日期清單。

## 怎麼用

1. 填 **目標日期**（考試／面試／出國／上台那天）。「從哪天開始算」預設今天，可以改。
2. 選填 **這批東西有多少**（會拿來粗估每輪要花幾分鐘）與 **你打算複習幾次**（留空就用建議值；建議值是依保留期推出來的）。
3. 選 **排法**：
   - **等間隔**：把「今天 → 目標日」平均切成 N+1 段。
   - **擴張間隔**：每一段乘上倍率（預設 1.4×），前面密、後面疏，總長仍等於保留期。
4. 按 **排給我看**。之後任何欄位一改，排程與曲線就即時跟著更新。
5. **複製這份排程**會產生純文字，可以直接貼進行事曆、備忘錄或待辦清單。若瀏覽器擋掉剪貼簿 API（`file://` 開啟時常見），會退回顯示一個可全選的文字框。

排不出來的情況也會誠實講：目標日已經過去、或只剩一天（那時候間隔複習幫不上忙，頁面會直說）。

## 為什麼有用

「間隔複習有效」這句話幾乎人人聽過，但它不含任何可執行的資訊——沒有日期，就沒有行動。這頁把研究結論翻譯成日曆上的格子。而且它強迫你先回答那個真正決定一切的問題：你想記多久。

## 資料來源與方法論

### 兩篇主要文獻

1. **Cepeda, N. J., Pashler, H., Vul, E., Wixted, J. T., & Rohrer, D. (2006). Distributed practice in verbal recall tasks: A review and quantitative synthesis. _Psychological Bulletin, 132_(3), 354–380.**
   統合分析，涵蓋 **184 篇文章、317 個實驗、839 次評估**。核心結論：學習間隔（inter-study interval, ISI）與保留期（retention interval, RI）**共同**決定最終成績——讓成績最高的那個 ISI，會隨著 RI 拉長而變長。該回顧也檢視了擴張式 ISI 的效果（見下）。

2. **Cepeda, N. J., Vul, E., Rohrer, D., Wixted, J. T., & Pashler, H. (2008). Spacing effects in learning: A temporal ridgeline of optimal retention. _Psychological Science, 19_(11), 1095–1102.**
   **1354 名受試者**（線上記憶研究樣本；平均年齡 34 歲，SD = 11，範圍 18–72，72% 為女性）。每人先學 32 條冷僻但真實的知識到「全部答對一次」的標準，經過 **0 到 105 天（最長約 3.5 個月）**不等的間隔後複習一次，再於 **7、35、70、350 天**之後接受回憶與再認測驗，共 **26 種「間隔 × 保留期」組合**。
   結果：**在每一個保留期上，間隔拉長都會先讓成績上升、之後緩緩下降**（倒 U）。以固定的總學習時間計，最佳間隔相對於「零間隔」讓回憶成績提升 **64%**（d = 1.1）、再認提升 26%（d = 1.5）。四個保留期（7／35／70／350 天）實測的最佳間隔（回憶）分別是 **1／11／21／21 天**。

### 5–20% 這條比例的確切出處與適用範圍

原文摘要（2008，in-press 版）：**「The optimum gap value was about 20% of the test delay for delays of a few weeks, falling to about 5% when delay was one year.」**

補充兩件事，避免誤用：

- 正式出版版本的摘要措辭較寬：「declined from about 20 to 40% of a 1-week test delay to about 5 to 10% of a 1-year test delay」。本頁採較保守的 **20% → 5%** 錨點。
- 論文用來擬合資料的「保留曲面」（R² = .98）本身給出的脊線是：保留期 350 天時最佳間隔 **23 天，即 7%**。該曲面形式為
  `Recall = A (bt + 1)^(−R)`，其中 `A = p + (1 − p) e^(−a·g)`、`R = 1 + c (ln(g + 1) − d)²`，參數 `p = .760, a = .017, b = .011, c = .092, d = 3.453`。
  **本頁沒有直接用這個曲面來排程**——它描述的是「兩次學習 + 一次測驗」的實驗設計，不能直接外推成多次複習的排程；只把它的兩個結論（比例隨保留期下降、左陡右緩）拿來用。

**誠實邊界**：這條比例是從**實驗室的詞彙與事實記憶任務**歸納出來的經驗法則，不是精算公式。不同材料（詞彙 vs. 技能 vs. 概念理解）、不同人、不同起始熟練度，差異都很大。它給你的是量級（是「幾天」還是「幾週」），不是精確到日的處方。

另外一個值得記住的非對稱性（原文結論）：**間隔太長的代價，明顯小於間隔太短的代價**——成績隨間隔上升得很陡，超過最佳點後只是緩緩下滑。所以要猜錯，寧可晚一點。

### 本頁的比例函數

以 2008 年摘要的兩個錨點做對數內插，兩端夾住：

```
ratio(D) = clamp( 0.20 × (D / 28)^k , 0.05 , 0.35 )
k = ln(0.05 / 0.20) / ln(365 / 28) ≈ −0.5399
最佳間隔 g*(D) = max(1, ratio(D) × D)
```

（`D` = 從今天到目標日的天數，即保留期。）
性質：`ratio` 隨 `D` 單調遞減、`g*` 隨 `D` 單調遞增，兩者都用 node 斷言驗過（`D` = 2…3650）。
參考值：`D` = 14 → 29%、28 → 20%、90 → 11%、180 → 7%、365 → 5%、730 → 3.4%。

### 排程演算法

`N` 次複習把「今天 → 目標日」切成 `N + 1` 段，最後一段是「最後一次複習 → 目標日」（目標日本身就是最後一次提取）。

- **建議次數**：`N* = round(D / g*) − 1`，夾在 1…12。
- **等間隔**：每段 `D / (N + 1)`。
- **擴張間隔**：第 `i` 段 `= s₁ · f^(i−1)`，其中 `s₁ = D (f − 1) / (f^(N+1) − 1)`，`f` 為倍率（1.1–2.0，預設 1.4）。兩種排法的**平均間隔相同**（都是 `D/(N+1)`，錨在 Cepeda 的比例規則上），差別只在分佈。
- **取整**：先前推保證日期嚴格遞增（至少差一天），再後壓保證每個日期都落在目標日之前；次數超過可用天數時自動縮減。

### 記憶模型（示意）

頁面上三條曲線用的是一個會真的在跑的簡化模型，公式與參數如下：

```
可提取度  R(t) = exp( −(t − t_last) / S )
複習時    g = max(0.05, t − t_last)
          S ← S × ( 1 + G · exp( −(ln(g / S))² / (2σ²) ) )
初始      S₀ = 2.5 天，  G = 1.2，  σ = 1.5
```

即：**指數遺忘 ＋ 每次成功提取後衰減率下降**（穩定度 S 變大）。增幅是 `ln(g/S)` 的高斯函數，在 `g ≈ S`（可提取度掉到約 37%）時最大——太早複習（還沒忘，`g ≪ S`）與太晚複習（忘光了，`g ≫ S`）收穫都少。這正是間隔效應的形狀來源。

三條曲線的差別只在複習事件的位置：

| 曲線 | 複習事件 |
|---|---|
| 不複習 | 無 |
| 集中一天複習完 | 全部 `N` 次擠在第 0.05、0.10、0.15… 天 |
| 照這份排程 | 排程產生的日期 |

**這是示意模型，不是預測工具。** 它用來比較三種做法的**形狀**，數字（例如「目標日剩 95%」）不應該當成你的分數。這一點也寫在頁面上。

### 與 Anki／SM-2 的關係

Anki 那類軟體走的是**擴張式間隔**：SM-2 演算法用一個 ease factor（初始 2.5）把每次間隔往外推，且依你每次回答的難易度調整。這頁的「擴張間隔」是同一個精神的簡化版，但有兩個關鍵差異：

1. 這頁**沒有你的作答回饋**，只有日期——它排的是行事曆，不是抽認卡。
2. 這頁的擴張排程**被總長度綁住**（所有間隔加起來等於保留期），所以倍率越大，第一次複習來得越早。

**保留態度**：Cepeda et al. (2006) 檢視了擴張式 ISI，但資料**並未給出「擴張優於等間隔」的壓倒性答案**。後續實驗也是各有勝負——例如 Karpicke & Roediger (2007, _Journal of Experimental Psychology: Learning, Memory, and Cognition, 33_(4), 704–719) 發現擴張式提取有利於**短期**保留，而等間隔提取對**長期**保留更好。所以這頁兩種都給，預設等間隔，讓你自己看差別，而不是替你選邊。

## localStorage

- 前綴：`spacecal26.`（抽成同檔字面常數 `var LS = 'spacecal26.';`）
- 唯一的 key：`spacecal26.state`，內容是一個 JSON：目標日期、項目數量、複習次數、排法、擴張倍率。
- 讀取時如果存下來的目標日期**已經過去就不還原**，避免一開頁就看到一份過期排程。按「重設」會把這個 key 刪掉。

## 渲染自我檢查表

- **SVG 漸層描邊**：全頁沒有使用 SVG，三張圖（第一屏月曆、比例曲線、遺忘曲線）**都走 canvas**，不存在 `stroke:url(#g)` 與 `gradientUnits` 的坑。
- **逐路徑 drop-shadow**：沒有使用 `filter: drop-shadow()`。
- **canvas CSS 尺寸**：三個 canvas 都有明確的 CSS 高度（`.hero canvas` 由 `inset:0` + `min-height:100svh` 撐開；`.ratiobox canvas` 190px；`.chartbox canvas` 250px／手機 220px）。
- **resize 回饋迴圈**：`measure()` 先算出目標 `width`／`height` 再**比較**，不相等才指派，因此 `ResizeObserver` 不會每幀翻倍。曲線圖從 `hidden` 變成顯示時會另外呼叫一次 `measure()`。
- **dasharray 畫線動畫**：沒有使用 dasharray 動畫。畫線是 canvas 內用「已繪製點數」推進的，重播只要把進度歸零即可，不依賴 CSS transition 的重排時機。
- **繪製方向**：兩張曲線都由左往右畫，與時間方向一致，不會倒放。
- **rAF 紀律**：單一 rAF 迴圈驅動全部畫布；`document.hidden` 時整圈跳過；每個畫布用 `IntersectionObserver` 標記可見性，離屏不畫；靜態圖只在 `dirty` 時重畫，動畫進行中才持續要求下一幀。
- **prefers-reduced-motion**：初始讀取 + `matchMedia` 的 `change` 事件動態監聽。開啟時：捲動進場全部直接顯示、清單不做 stagger、曲線一次畫完、第一屏月曆停止動畫。
- **無障礙**：日期／數字都是原生 `<input type="date">`／`<input type="number">`，排法用 `<fieldset>` + radio（方向鍵可切換），所有輸入有可見的 focus 樣式與 `aria-label`，排程結果放在 `role="status" aria-live="polite"` 的摘要中播報，兩張資訊圖有 `aria-label`。
- **手機**：<640px 表單單欄、工具區塊出血到邊緣；<560px 曲線圖降為 220px 高。

## 測試

- `node tools/check.js`：本專案無錯誤、無提醒。
- 核心邏輯（`SC` 物件，可在 node 中單獨載入）以 node `assert` 驗過 **174 組斷言**，包含：
  - 日期算術：閏年（2024／2000／1900 百年例外）、2 月底跨月、12/31 跨年、加 365／366 天、無效日期（2 月 30 日、13 月、空字串）判定、星期換算，以及連續 4000 天的字串↔天數雙向一致性。
  - 比例規則：`D` = 2…3650 全掃，最佳間隔不遞減（`D` ≥ 12 後嚴格遞增）、比例不遞增，兩個錨點（28 天 = 20%、365 天 = 5%）精確落點。
  - 排程：8 組跨月／跨年／閏年日期 × 兩種排法 × 7 種次數，驗日期嚴格遞增、全部落在今天之後與目標日之前、間隔加總等於保留期；再加一次「保留期 2…800 天 × 兩種排法 × 1…12 次」的全域掃描（0 個壞日期）。
  - 策略差異：等間隔的所有間隔差距 ≤ 1 天（取整誤差）；擴張的間隔逐次不減、最後一段大於第一段三倍以上；倍率越大第一次來得越早。
  - 記憶模型：三條曲線都從 100% 出發、未複習時單調遞減、值落在 0…1；每一次複習都對應一次跳升；目標日「照排程 > 集中一天 ≥ 不複習」，且在 30／60／120／240／365 天五種保留期下都成立。
- 另外用一個極簡 DOM shim 在 node 裡把頁面的 UI 程式碼跑過一遍（含 canvas 繪圖呼叫），驗證：按下「排給我看」會產生正確列數的清單與摘要、切換擴張排法會更新、只剩一天／日期已過去會顯示誠實訊息、重設會清空並移除 localStorage、重新載入會還原上次設定。
