# 九成五還不夠

## 故事線

- **鉤子**：第一屏不解釋任何事，直接把一段英文丟到你臉上，其中 5% 的詞被塗成黑條。「這段英文，你讀得懂嗎？」——不是問句修辭，是真的要你試。旁邊只補一句：每二十個字有一個不見了，聽起來不多。
- **轉折**：你按下「我讀完了，揭曉」，黑條一格一格退場，原文長回來。這時才告訴你：你剛剛讀的就是 **95%**——不是九十五分，是「你認識文章裡 95% 的詞」。接著把 100 / 98 / 95 / 90 / 80 五顆按鈕交給你，同一段文字來回切。98% 和 95% 在數字上差兩格，在眼睛裡差一個世界，這件事沒有人能替你體會，只能自己按。
- **鋪陳**：第一章講那條線怎麼來的（2000 年，兩個人，一篇 633 字的故事，66 個紐西蘭大學生）；第二章講帳單——4,000 個詞族買到 95%，再走到 98% 要 8,000 到 9,000 個，中間三個百分點要價四五千個字，並用一條實測的累積覆蓋率曲線把「懸崖」的形狀畫出來。
- **高潮（由使用者觸發）**：第三章把機器交出去。貼上任何一段英文，拉字彙量滑桿，當場得到四樣東西：你看得懂這篇的百分之幾、這篇跨過 95%／98% 各需要多少詞族、逐字標出你不認識的那些、以及一份「先學這些」的優先清單。故事在這裡從「別人的研究」變成「你手上這一篇」。
- **誠實的第二拍**：第四章回頭拆自己的台。那條被引用二十幾年的線，地基是 66 個人、一篇文章、一個國家、一次迴歸。2023 年 Kremmel 等人在 *Language Learning* 做了正式複製研究，**結果沒有被完全複製**。頁面把這件事寫在工具下面，而不是藏在附錄裡。
- **記憶點**：收尾回到那道懸崖——「你不是學不會，你只是走到了帳單開始變貴的地方。」然後一句邀請：那台機器還開著，再貼一篇進去。

## 這是什麼

一台**英文閱讀覆蓋率檢查機**，外面包著一個關於「98% 這條線」的故事。

覆蓋率（lexical coverage）＝你認識的詞佔文章總詞數的比例。研究上它是預測「這篇你讀不讀得動」最強的單一指標之一。這頁做兩件事：先讓你**體感**不同覆蓋率長什麼樣子，再讓你**量測**自己手上那篇落在哪裡。

## 怎麼用

1. **第一屏**：直接讀那段被塗黑的英文（那是 95%）。讀完按「我讀完了，揭曉」。
2. **揭曉區**：按 100% / 98% / 95% / 90% / 80% 五顆按鈕，同一段文字換不同密度。建議在 98% 和 95% 之間來回按幾次——那兩個百分點是整頁的重點。
3. **第三章的機器**：
   - 把任何一段英文貼進文字框（新聞、論文摘要、小說開頭、遊戲台詞都可以），也可以直接按三顆示範按鈕：**兒童故事 / 財經新聞 / 學術摘要**。
   - 拉「你認識最常見的幾個詞族？」滑桿（500–9,000，每格 250）。整頁的數字、曲線、標記與清單都會即時跟著動。
   - **大數字**＝這篇對你的覆蓋率；**四格統計**＝總詞數、你不認識幾個、跨過 95% 與 98% 各需要多少詞族。
   - **曲線圖**：橫軸字彙量、縱軸覆蓋率，白點是你現在的位置，藍點／金點是這篇跨過 95%／98% 的地方。
   - **標記區**：橘色螢光＋實線底＝超出你字彙量的詞；點狀底＝專有名詞（視為已知）。不只靠顏色分辨。
   - **優先清單**：照「在這篇出現幾次 × 有多常見」排出最值得先查的 14 個字，可一鍵複製（剪貼簿被瀏覽器擋掉時會退回提示，`file://` 開啟常見）。
4. 滑桿位置會記住，下次開頁自動還原。

## 為什麼有用

「多背單字」是一句沒有單位的建議。這頁給它單位：**詞族**、**百分點**、**這一篇**。

它想讓人看見兩件很少被同時說出口的事：

1. **前面很便宜，後面很貴。** 最常見的 1,000 個詞族就買到八成多，之後每一千個只再買一到兩個百分點。學英文中期那種「沒有在進步」的錯覺，多半不是你變慢了，是價目表換了。
2. **95% 不是「差一點的 98%」。** 兩者相差的不是 3 個百分點，是四五千個詞族，以及「能不能一個人把它讀完」這個質變。

## 資料來源與方法論

### 1. Hu & Nation (2000)——那條 98% 的線

**Hu, M., & Nation, P. (2000). Unknown vocabulary density and reading comprehension. _Reading in a Foreign Language, 13_(1), 403–430.**

- 材料：一篇 **633 字**的敘事文，做成四個版本，未知詞密度分別對應 **100%、95%、90%、80%** 的已知詞覆蓋率。所謂「未知詞」是把原詞**換成不存在的假字**（長得像英文、查不到、猜不著），以確保受試者確實不認識。
- 受試者：紐西蘭威靈頓維多利亞大學一門大學先修英語課的 **66 名學生**。
- 測量：多選題＋書面回憶（written recall）。
- 結論：把理解成績對覆蓋率做迴歸外推，「足夠理解」所需的覆蓋率落在 **98%** 附近；**95% 那一組只有少數人達到足夠理解**。
- 「足夠理解」的定義是**不靠字典、註解或老師**，獨立讀懂（unassisted reading）。

### 2. Kremmel et al. (2023)——複製研究，結果沒有被完全複製

**Kremmel, B., Indrarathne, B., Kormos, J., & Suzuki, S. (2023). Unknown Vocabulary Density and Reading Comprehension: Replicating Hu and Nation (2000). _Language Learning, 73_(4), 1127–1163.**

- 動機：98% 這個門檻在 L2 詞彙研究與教學上極具影響力，但它的來源是**一次只有 66 名紐西蘭大學生的迴歸分析**。
- 樣本：**104 名斯里蘭卡成人英語學習者**，非學術情境——刻意離開原研究那種 WEIRD（西方、受過高等教育、工業化、富裕、民主）樣本。
- 流程：先做接受性字彙量測驗，再讀其中一個未知詞密度版本的文章，然後作答理解測驗。
- 結論（本頁採用的說法）：**達到足夠理解所需的比例不必然是 98%**；雖然可視為部分複製，但**沒有任何一項複製完整重現原研究的結果**。

這一段是頁面第四章的全部依據。頁面沒有把 98% 丟掉，而是把它降級成「木尺不是雷射」：它給你量級（離很遠會很痛苦、貼近會順很多），不給你判決（你卡在 96.4% 會怎樣，沒有人真的知道）。

### 3. Nation (2006)——4,000 與 8,000–9,000 這兩個數字

**Nation, I. S. P. (2006). How large a vocabulary is needed for reading and listening? _Canadian Modern Language Review, 63_(1), 59–82.**

- 方法：試用 **14 份各一千個詞族的 BNC 詞族清單**，逐段測算對不同文本類型（書面與口語）的累積覆蓋率。
- **95%**：約 **4,000 個高頻詞族＋專有名詞**，可覆蓋報紙與小說約 95%。
- **98%**：**報紙約需 8,000 個詞族、小說約需 9,000 個**（書面文本 8,000–9,000）。同一篇也給了口語的對應值：**口語文本約 6,000–7,000** 個詞族。本頁只用書面那組數字，因為頁面談的是「閱讀」。
- 這正是頁面第二章「中間那三個百分點，要價四千到五千個字」的來源，也是滑桿上限設在 9,000 的原因。

### 4. Zipf 分布與「懸崖」

英文詞頻是重尾的 Zipf 型分布：最常見的 1,000 個詞族約可覆蓋一般書面文本 80% 左右（口語文本更高），之後每多一千個詞族的邊際報酬急速遞減。頁面第二章那張圖畫的就是這個形狀。

### 5. 內建詞頻清單：**自製的近似品**，不是任何具名語料庫

**這是本頁最需要誠實交代的地方。頁面裡那 9,000 個詞族不是 BNC 詞族表，不是 COCA，不是 NGSL，也不等同於任何已發表的分級清單。**它是為了讓這頁能離線、單檔、雙擊即開而現場合成的近似排序。做法如下：

**原料（三份公開的英文詞頻資料）**

| 來源 | 內容 | 規模 |
|---|---|---|
| 英文維基百科詞頻表 | word + count | 約 277 萬個詞形、合計約 24.7 億次 |
| OpenSubtitles 英文字幕詞頻表 | word + count（前 50,000 名） | 合計約 7.25 億次 |
| Google 常用英文詞表（web，10k） | 只有排序，沒有次數 | 9,999 個詞 |

**排序融合**：三份各自轉成排名，用 reciprocal rank fusion 合成
`score(w) = 0.45/(50+rank_wiki) + 0.40/(50+rank_subs) + 0.15/(50+rank_web)`
權重偏向書面（維基 0.45）與口語日常（字幕 0.40），網頁表只當微調。所有候選詞先用一份 37 萬字的英文詞典（`words_alpha`）過濾，去掉拼錯字與雜訊；另外套一份髒話黑名單。

**收成詞族**：取融合後前 16,000 個詞形，用**與頁面執行期完全相同的形態規則**做 union-find 合併——屈折形（-s / -es / -ies / -ed / -ied / -ing / 不規則）無條件併入基本形；派生形（-er / -est / -ly / -ily）**只有在基本形更高頻時才併**（否則 `matter → matte`、`early → ear` 這種假詞源會把常用字併進罕用字）。每個詞族取家族中最高頻的成員當代表，再依代表的排名取前 **9,000 個詞族**。

**已知的偏差，請當成使用限制看**

- **有專有名詞混進來**。原始頻率表是全小寫的，`brazil`、`graham`、`natalie`、`eisenhower`、`taiwanese`、`spock` 這類詞會佔掉詞族名額，尤其集中在第 3–9 千帶。實務上影響有限（工具本來就把大寫的專有名詞另外算成已知），但它確實讓後段的「詞族」比正規的 BNC 詞族表雜。
- **口語偏重**。字幕語料佔 0.4 權重，所以口語高頻詞（`gonna`、`okay`、`hey`）排得比書面表更前面。
- **詞族定義比 Nation 窄**。這頁只合併屈折與少量派生（-er/-est/-ly），Nation 的詞族還包含 -tion / -ment / -ness / un- / in- 等更廣的派生層級（Bauer & Nation 的 Level 6）。**同樣的文章，本頁算出來的「所需詞族數」會比用正規詞族表偏高。**
- 所以第二章那張圖上，95% 落在 **5,250** 個詞族，而不是 Nation 的 4,000。頁面圖說已經把這件事寫出來：量級一致，形狀才是重點。

**驗證過的一件事**：頁面裡寫死的 `GENERAL` 累積覆蓋率陣列（37 個點，0→9,000 每 250 一格），本次驗收用原始字幕頻率表**重算過一次，逐點完全相符**；分母是 **683,090,613 個詞次**（即頁面上說的「6.8 億詞的英文對白語料」）。9,000 個詞族在該語料上的覆蓋率是 **97.00%**，第一個 1,000 個詞族是 **84.29%**。

### 6. 斷詞與屈折還原的規則（執行期）

**斷詞**：一條正則把原文切成「詞 / 數字 / 空白 / 標點」四種片段，且**切完可以無損拼回原文**（有斷言驗）。

- 詞 = 一串拉丁字母，允許中間帶撇號（`don't`、`boy's`）與連字號（`well-known`）。
- **字母類別含重音拉丁字母**（À-Ö、Ø-ö、ø-ɏ），所以 `café`、`naïve`、`résumé`、`Zoë` 是完整的一個詞，不會被切成 `caf` ＋亂碼。
- 數字（含 `1,250`、`3.14`、`50%`）自成一類。
- 中日韓文字、emoji 一律歸到「標點」，不計入總詞數。

**正規化**：轉小寫 → 去重音（NFD 去除結合附加符號，另外處理 ß/æ/œ/ø/đ/ł/þ/ð）→ 處理撇號（`don't → do`、`boy's → boy`）→ 只留 a–z 與連字號。

**還原（找詞族）**：先直查清單；查不到才依序試這些規則，最多回溯兩層——

| 規則 | 例 |
|---|---|
| 不規則表（262 組） | went→go、children→child、worse→bad、bigger→big、phenomena→phenomenon |
| -ies → -y | babies→baby |
| -es / -s（`ss` 結尾除外） | boxes→box、cats→cat |
| -ied → -y、-ed（含去重複子音） | studied→study、stopped→stop |
| -ing（含 +e、去重複子音） | running→run、making→make |
| -er / -est / -ier / -iest / -ly / -ily | happily→happy |

**防誤傷**：每個候選都有最小長度限制，另外有一份 **43 個字的 NEVER 名單**（`bus`、`is`、`this`、`as`、`us`、`gas`、`news`、`means`、`series`、`species`、`less`、`always`、`across`、`serious`、`obvious`…）——這些字長得像屈折形但不是，一律禁止切詞尾。所以 `bus` 不會變成 `bu`、`this` 不會變成 `thi`、`news` 不會併進 `new`。（`is`／`was`／`has` 仍會走不規則表併進 `be`／`have`，這是對的。）

**連字號詞**：`well-known` 這種取**各段裡最罕見的那一段**當難度；只要有一段查不到，整個詞算未知。

**專有名詞**：大寫開頭且（不在句首 或 查不到）→ 判為專有名詞；全大寫（NASA、FBI）也是。專有名詞與數字**計入總詞數但視為已知**——這是沿用 Nation 計算覆蓋率的慣例（讀者通常不需要「認識」人名地名就能讀下去）。句號後重設句首旗標，但 `Dr.`／`Mr.` 這種縮寫不算換句。

**覆蓋率**：`已知詞數 / (一般詞 + 專有名詞 + 數字)`。空文本回 0，不會除以零。

## 渲染自我檢查表

- **SVG 漸層描邊**：全頁沒有 SVG。兩張圖都走 canvas，不存在 `stroke:url(#g)` 與 `gradientUnits` 的坑。
- **逐路徑 drop-shadow**：沒有使用 `filter: drop-shadow()`。
- **canvas CSS 尺寸**：`#cvGeneral{height:300px}`、`#cvText{height:290px}`（<560px 降為 260／250），寬度 `width:100%`。兩者都有明確 CSS 高度。
- **resize 回饋迴圈**：`measure()` 先算出目標 `nw`／`nh`，**比較後不相等才指派** `cv.width`／`cv.height`。本次驗收在 dpr=2 下連發 200 次 `ResizeObserver` 回呼，尺寸維持 1312×600／1312×580 不變（dpr=1 也另跑一輪）。
- **dasharray 畫線動畫**：沒有使用。曲線是 canvas 內用「已繪製點數 × 進度」推進的，重播只要把 `prog` 歸零（`replay()`），不依賴 CSS transition 的重排時機。
- **繪製方向**：曲線由左往右（字彙量由小到大）逐點長出，與軸向一致，不會倒放。
- **rAF 紀律**：單一 rAF 迴圈驅動兩張畫布；`document.hidden` 時整圈跳過；每張畫布用 `IntersectionObserver` 標記可見性，離屏不畫；靜態時只在 `dirty` 才重畫。
- **prefers-reduced-motion**：初始讀取 ＋ `matchMedia` 的 `change` 事件動態監聽。開啟時：所有捲動進場元素直接顯示、塗黑條不做 stagger 延遲、曲線 `prog` 直接設 1（一次畫完）、大數字不滾動、`scrollIntoView` 改用 `behavior:"auto"`、CSS 也把相關 transition 全關掉。
- **文字量測與版面**：曲線圖的軸名靠右對齊（本次驗收發現靠左會疊在 `0` 刻度上，糊成「0詞族數」，已修）；游標提示框在覆蓋率貼近 100% 時會翻到白點下方，避免蓋住白點本身（也是本次修的）。
- **無障礙**：兩張 canvas 有 `role="img"` ＋ `aria-label`；覆蓋率判語在 `role="status" aria-live="polite"`；密度旁白 `aria-live="polite"`；密度按鈕用 `aria-pressed` 表達單選狀態；標記區不只靠顏色（未知詞有實線底＋螢光，專有名詞有點狀底）；塗黑的詞會設 `aria-hidden`。
- **手機**：<560px 面板出血到邊緣、內距縮小、兩張圖降低高度；文字框可垂直拉伸。

## 測試

本次驗收（接手既有 `index.html`）跑了三層測試，全部在 `/tmp` 進行，未留檔在倉庫裡。

### A. 純函式斷言（node `assert`）

把頁面的 `<script id="engine">` 原樣抽出來當模組載入（它本來就把 API 掛在 `window`／`globalThis.COVER98` 上），跑 **1,536 組斷言**，全過：

- **正規化**：去標點、縮寫（`DON'T`→`do`）、彎引號、所有格、連字號保留、純數字／中文／空字串／`null`／`undefined` 都回空字串。
- **屈折還原**：`cats→cat`、`running→run`、`studied→study`、`boxes→box`、`babies→baby`、`stopped→stop`、`making→make`、`went→go`、`children→child`、`worse→bad`、`bigger→big`、`wolves→wolf`、`phenomena→phenomenon`、`happily→happy` 各自與基本形落在同一個 rank。
