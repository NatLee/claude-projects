# 他把病床架上磅秤

> 1907 年的一本實驗紀錄簿，攤開在你面前。六筆紀錄，一台磅秤，一個活了一百二十年的數字。

---

## 故事線

**鉤子｜** 第一屏不講靈魂，也不講二十一公克。只有一根橫樑。它被人刻意頂在上限位桿旁邊，微微顫著，撐了三小時四十分鐘——然後掉下去，撞上下面那根桿子，發出一聲，沒有回彈。床上那個人剛剛停止呼吸。全世界都知道的那個答案，被藏到第三章才拿出來。

**鋪陳｜** 讀者先摸一次那台秤：靈敏度十分之二盎司（5.67 公克），比這輕的東西，橫樑一動也不動。接著翻開簿子的六個分頁——四位肺結核、一位糖尿病昏迷、一位死因未載。每一頁都是 MacDougall 自己寫下的原始描述，不加評語。每翻一頁，讀者要親手按下一個判定：**這一筆能用嗎？** 按完才看得到他當年自己的註記。六頁翻完，讀者會自己算出來：他自己作廢了兩筆，剩下四筆裡一筆的數字取決於「死亡是哪一秒」、一筆的失重根本沒停下來、一筆是那台秤自己回不去原位。**能用的只有一筆。**

**高潮（使用者親手觸發）｜** 第四章把那台磅秤交到讀者手上。六個當年沒有被排除的干擾因素，一個一個由讀者打開：儀器解析度、被頂在限位桿上的橫樑、臨終體溫上升導致的出汗、死亡時刻的主觀判定、床架的機械擾動、最後一口氣的空氣。每打開一個，中央那個 21.3 就被吃掉一塊，同時誤差帶往兩邊擴張，天平的指針開始在雜訊裡漂。**關鍵設計：數字不會歸零。** 它停在大約 10 公克——但誤差帶已經漲到 ±14 公克，零被吞進去了。訊號沒有被消滅，是被淹沒了。這才是真的判準。

**教學上的公允｜** 第六個因素（最後一口氣的空氣）打開後幾乎沒有動靜，並且會告訴讀者：**這條反駁站不住腳**——MacDougall 自己躺上那張床，用力吸吐，橫樑沒有動。他做過這個對照。讀者要學會的不只是「怎麼拆一個實驗」，還有「怎麼分辨哪些批評是對的」。

**轉折｜** 十五隻狗。同樣的秤、同樣的方法，全部零。他的結論不是「我的方法有問題」，是「狗沒有靈魂」。而他自己在同一頁承認：狗的測試因為給了兩種鎮靜藥物而失效，因為他找不到病死的狗。

**記憶點｜** 反轉不是「他是騙子」。他真正想做的事其實了不起：把一個兩千年來只屬於神學的問題，搬進一個可以被測量的房間。他也在論文裡親手寫下「這件事必須做過大量的實驗才能證明」。他知道。問題是他做了一次就停了——1920 年他過世，這個實驗從來沒有被重複過，而那個他自己都說要再做很多次的數字，變成了一部電影的片名。收尾把鏡頭拉遠到那本簿子：第一頁的第一行沒有變過，只是後面該有的那幾百頁，一直空著。

**敘事容器｜** 1907 年的手寫實驗紀錄簿與那台天平。整頁是一張攤在深色桌面上的泛黃紙，有橫格線、鋼筆藍黑墨水、紅筆註記、六個病例的分頁標籤，以及貫穿全頁的那根橫樑（canvas 繪製，帶阻尼擺盪）。

## 這是什麼

一個純靜態的單頁互動敘事，關於 1907 年 Duncan MacDougall 的「二十一公克」實驗。重點不是嘲笑一百多年前的醫師，而是把**「怎麼判斷一個實驗站不站得住腳」**這件事，變成讀者親手做過一遍的技能。

## 怎麼玩

1. **第一章｜那台秤能看見什麼**：拖動滑桿往秤上加重量。低於 5.67 公克時橫樑完全不動——先建立「解析度」的身體感。
2. **第二章｜六個沒有名字的人**：點左側（手機為上方）的六個分頁標籤翻閱紀錄。每一頁讀完後按「可採信 / 不可採信」，才會展開 MacDougall 自己的註記。六筆都判定完，會出現一段結算。判定會記在瀏覽器裡，下次回來還在。
3. **第三章｜那個數字**：捲進畫面時，21.3 公克從零滾上來。
4. **第四章｜磅秤現在在你手上**（高潮）：逐一打開六個干擾因素，看剩餘訊號被吃掉、誤差帶擴張、指針開始漂。旁邊有「全部打開」與「重設」。
5. **第五章｜十五隻狗**、**收尾**：純敘事。

鍵盤：所有分頁標籤、判定按鈕、因素開關都可 Tab 聚焦、Enter/Space 觸發，並有可見的聚焦框；狀態變化由 `aria-live` 播報。

## 為什麼有趣

因為那個「21 公克」是幾乎每個人都聽過、卻幾乎沒有人查證過的數字。而查證它需要的不是專業知識——需要的只是**把他自己寫的東西讀完**。這一頁的所有拆解材料，全部來自 MacDougall 1907 年那篇論文的原文：靈敏度是他寫的、蒸發速率是他量的、「我把橫樑頂在上限位桿旁」是他寫的、「這一次的實驗沒有價值」是他自己判的、「震動可能造成一盎司半的假讀數」也是他自己承認的。**拆掉這個實驗的所有工具，都在他自己的論文裡。**

### 狗的對照組

原文：「同樣的實驗在**十五隻狗**身上進行，採取了一切求準確的預防措施，結果一致為負：死亡時沒有重量損失。」狗重 15–70 磅，該秤靈敏至 1/16 盎司。

他同時自承：狗的測試「因為使用了兩種為求安靜與不掙扎而給的藥物而失效（vitiated）」，並說理想的受試犬應是病重到無力掙扎者，「但我沒有這樣的運氣」。因為找不到病死的狗，一般推定他毒殺了健康的狗（Roach 2003；Snopes 2003）。頁面上以一句「他找不到病死的狗」帶過，不鋪陳細節。

### Augustus P. Clarke 的批評（1907 年 5 月，同刊）

死亡瞬間肺部停止冷卻血液，體溫略升，導致出汗與水分蒸發增加，足以解釋那 21 公克。Clarke 並指出：狗沒有汗腺，本來就不會以這種方式失重——所以「狗沒有損失」根本不能拿來當「狗沒有靈魂」的證據。MacDougall 與 Clarke 在該刊上的往返至少持續到當年 12 月。

## 頁面上每個干擾量級估計的依據與不確定性聲明

**重要：頁面上這六個數字都是「量級估算」，不是實測值，也不是重做實驗得到的。** 頁面本身也明確標示了這一點。它們的用途是回答「這些因素加起來，是不是足以淹沒那個訊號」，而不是主張「答案精確地正好是零」。

共同的基準數字：MacDougall 自己測得第一例的基線水分流失率為 **每小時 1 盎司 = 28.35 g/hr ≈ 0.4725 g/分**（原文明載）。以下多項估計都由這個他自己的數字推導。

| 因素 | 扣減中心 | 不確定度（±） | 依據與不確定性 |
|---|---|---|---|
| 儀器解析度 | 0 g | 5.67 g | 他自陳天平靈敏至 2/10 盎司 = 5.67 g。這是**純誤差項**，不扣減。意義：21.26 g 只有 3.75 個最小可辨單位 |
| 橫樑被頂在上限位桿旁 | 7.1 g | 4.7 g | 他自述「三小時四十分鐘裡我一直讓橫樑末端略高於平衡點、靠近上限位桿」。靠住限位桿的橫樑有靜摩擦，累積的不平衡會一次釋放。以 0.4725 g/分 × 5～25 分鐘 ⇒ 2.4～11.8 g，取中心 7.1、半寬 4.7。**不確定性高**：實際靜摩擦門檻未知，時間窗是推估 |
| 臨終出汗與體溫上升 | 4 g | 4 g | Clarke 1907 的機制。以基線 0.4725 g/分，若臨終數分鐘內流失率升為 2～4 倍，額外流失約 0～8 g，取中心 4、半寬 4。**不確定性最高的一項**：無任何當代直接量測，僅是量級推論 |
| 死亡時刻的判定 | 0 g | 4.72 g | 他在第二例自述有 18 分鐘的疑慮期。取 ±10 分鐘 × 0.4725 g/分 = 4.72 g。**純誤差項**，不扣減 |
| 床架與機械擾動 | 0 g | 10.6 g | 他在第六例自承震動未止可能製造 **1.5 盎司 = 42.5 g** 的假訊號。這是他自己給的量級上界；本頁保守只取其 **1/4**（10.6 g）作為第一例的擾動誤差。**純誤差項**，不扣減 |
| 最後一口氣的空氣 | 0.3 g | 0.3 g | **這一項基本上不成立。** 呼出的氣體被等體積的空氣取代，淨變化只剩溫濕度造成的密度差，量級在零點幾公克。而且他自己做了對照：他與同事分別躺上那張床用力吸吐，橫樑沒有動。頁面會明白告訴讀者這條反駁失敗 |

**合成方式**：扣減採線性相加（Σ sub = 11.4 g），不確定度採**平方和開根號**（獨立誤差的標準合成，quadrature）：√(5.67² + 4.7² + 4² + 4.72² + 10.6² + 0.3²) ≈ 14.3 g。

**全部開啟後的結果**：剩餘 **21.26 − 11.4 ≈ 9.9 g**，不確定度 **±14.3 g**，區間 **−4.5 ～ +24.2 g**。**零落在區間內 ⇒ 這個訊號不顯著。**

這個設計是刻意的：數字**不會歸零**。若把它做成剛好抵銷到零，反而是另一種造假。真正的結論是「原始資料的雜訊比訊號還大」，而不是「靈魂剛好重零公克」。

順帶一提：即使**只**打開前四項（解析度、限位桿、出汗、時刻判定），區間下緣仍勉強在零以上；壓垮它的是第五項——那個 42.5 公克的假訊號量級，也是他自己寫的。

## 渲染自我檢查表

- [x] **SVG 漸層描邊**：頁面上唯一的 SVG 是手寫底線的 `<path>`，用**純色 stroke**，完全沒有用 `stroke:url(#…)`，因此不存在 `gradientUnits` 地雷。天平的橫樑是**水平線**——依規範走 canvas，不走 SVG。
- [x] **逐路徑 drop-shadow**：沒有任何 `filter: drop-shadow()` 掛在路徑上。紙張與卡片的陰影一律是 `box-shadow`（DOM 元素，非零面積）。
- [x] **canvas CSS 尺寸**：三個 canvas（`#cvHero`、`#cvWeigh`、`#cvBeam`）在 CSS 中都給了明確的 `height`（含 <560px 的 media query 覆寫），不會落入「高度取自 width 屬性」的回饋迴圈。
- [x] **resize 先比較再重設**：`measure()` 內 `if (cv.width !== nw || cv.height !== nh)` 才指派，`ResizeObserver` 連發不會清空畫布，dpr 上限 2。
- [x] **dasharray 重播**：`playStroke()` 嚴格照樣板順序——`transition:none` → `strokeDashoffset=100` → `getBoundingClientRect()` 強制 reflow → 下一個 `requestAnimationFrame` 才開 transition 並設 `0`。切換分頁時會重播，已實測可重複觸發。用 `pathLength="100"` 正規化路徑長度，不依賴 `getTotalLength()`。
- [x] **畫線方向**：底線 path 由左至右（`M2 8 C …` 起點在左），與中文書寫方向一致，不會倒著寫。
- [x] **動畫只用 transform/opacity**：進場、卡片、誤差帶（`translateX` + `scaleX`，`transform-origin:left`）、指標（包住整條軌道再 `translateX`，避開對 2px 元素用百分比的錯誤）全部只動 transform/opacity；canvas 內另計。
- [x] **rAF 紀律**：單一 rAF 迴圈驅動三個 canvas，`document.hidden` 時整批跳過並在 `visibilitychange` 重置時基；每個 canvas 各有 `IntersectionObserver`，離屏不重畫。
- [x] **prefers-reduced-motion**：完整降級（不擺盪、直接落到目標角度；不抖動雜訊；不做鋼筆字 stagger；底線直接顯示；數字直接跳值），並用 `matchMedia` 的 `change` 事件動態監聽（含舊版 `addListener` fallback）。
- [x] **`file://` 可開**：單一 HTML 檔自包含，零外部資源、零 `fetch()`、零 ES module，全站 ES5 語法。
- [x] **無障礙**：分頁標籤用 `role="tab"` / `aria-selected`（含 ← → Home End 鍵盤導覽）；判定按鈕與因素開關用 `aria-pressed`；結果用 `aria-live="polite"` 播報；`:focus-visible` 有可見外框；裝飾性 canvas 皆 `aria-hidden`。
- [x] **手機 <560px 單欄**：分頁標籤改為橫向捲動列，因素面板單欄，canvas 高度降階。

## 核心邏輯的 node 斷言

以下純函式以 `/* ===== PURE_START ===== */ … /* ===== PURE_END ===== */` 標記在 `index.html` 內，測試時直接從 HTML 抽出該區塊 eval 後驗證（測的就是頁面上跑的那段程式碼）：

- `tally(active)`：干擾因素的累加與剩餘量計算
  - 空集合 ⇒ 值 = 21.26、不確定度 = 0、`significant === true`
  - 全開 ⇒ `Math.abs(value) < unc`、`lo < 0 < hi`、`significant === false`
  - 逐一加入因素時，`value` 單調不增、`unc` 單調不減
  - 加入順序不影響最終結果（交換律）
- `stepBeam(state, target, dt, w, z)`：阻尼擺盪
  - 從任意初始角度與速度出發，2 秒模擬後收斂到目標（|a − target| < 1e-3）且速度趨近 0
  - 不發散：任何一步的 |a| 都有界，無 NaN／Infinity
  - `dt` 超過 0.05 會被夾住（分頁切回時的大時間步不會炸掉）
- `gramsToDeg(g, maxDeg, span)`：夾在 ±maxDeg 之間，且在區間內單調遞增
