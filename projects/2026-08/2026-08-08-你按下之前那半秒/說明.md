# 你按下之前那半秒

## 故事線

- **鉤子｜** 第一屏沒有任何一句話提到自由意志。只有一個轉得很快的鐘點，和一句「等你想按的時候，就按。沒有人會催你。」讀者先坐進那張椅子，才知道自己在哪裡。
- **鋪陳｜** 三條規則（想按就按／兩次之間至少等三秒／按完回想「我要按了」第一次冒出來時，點在哪裡），然後讀者真的按八次（只有前三次會被問 W，第三次之後自動切成「只按」）。每按一次，右邊的記錄器就吐出一段那一次的模擬腦電。八條歪歪扭扭的線，一條一條看，什麼都不是。
- **轉折｜** 讀者按下「疊起來」。二十條線以**自己按下的瞬間**為零點往回對齊、平均——那條被印了四十年的緩慢上升曲線，在讀者自己的資料上長了出來。旁邊標著 −550 ms（準備電位起點）與 −200 ms（Libet 受試者自述意識到的時刻），還有讀者自己的 W。
- **高潮｜** 讀者親手按下「同一批資料，換一種零點」。一條原始資料都沒動，只把對齊點換成等待期間的隨機時刻——曲線消失，攤成一團雜訊。可以來回切換，也可以一直重抽。
- **記憶點｜** 揭曉這正是 Schurger 的論點：記錄器裡那個模型**沒有「準備」這個東西**，只有雜訊和一條門檻。你剛剛親手做出了那條曲線。收尾誠實交代這場爭論到現在還沒結束，並留下一句回馬槍：「下次有人拿一張圖告訴你某件事是註定的，先問一句：這張圖，是以什麼時刻對齊的？」

容器形式是**一間實驗室**：一張椅子、一個按鈕、一台會吐紙的記錄器。不是論文導讀，也不是哲學論述。

---

## 這是什麼

一頁可以親手重做的 Libet 實驗，外加一個 2012 年才有人提出的反轉。純靜態、單一資料夾自包含，雙擊 `index.html` 就能開，沒有任何外連資源。

## 怎麼玩

1. 往下捲到實驗站。左邊是鐘（一圈 2.56 秒，每格約 43 毫秒），右邊是記錄紙。
2. **想按的時候就按**。滑鼠點、或鍵盤空白鍵／Enter 都可以。兩次之間至少要讓鐘走滿 3 秒，太快會被擋下來。
3. 按完鐘會凍結，圓周上會亮起「按下之前最後 1.5 秒」那一段。**點一下你第一次覺得「我要按了」的位置**；也可以用底下的滑桿標（鍵盤使用者、以及開了「減少動態」的人走這條路）。
4. 覺得標記太累，可以按「我標夠了，接下來只按」——之後只按不標，W 只會用你已經標過的那幾次去算，不會偽造。
5. 按滿 8 次（或按到 5 次以上用「按夠了，去看結果」）之後，第二章會解鎖。
6. 第二章第一次疊起來時，曲線會因為試次太少而毛躁；按「用你的節奏補到 40 次」可以把試次數補到 40——補進來的每一次，等待時間都是從讀者自己按出來的分布裡抽樣（加 ±0.8 秒抖動）再餵回同一個累積器模型，所以曲線仍然是由讀者的節奏長出來的，只是不必坐在那裡按四十遍。頁面上明講這一點。記錄紙只印最後 8 條，避免擠成一團。
6. 疊起來 → 看那條曲線 → 換一種零點 → 看它消失。

## 為什麼有趣

因為那個「背脊一涼」的瞬間不是被告知的，是自己做出來的。讀者先花兩分鐘產生一批**自己的**資料，看見那條有名的曲線從裡面長出來，然後才發現：同一批資料換個零點就什麼都沒有。結論不是被寫在說明卡上，是從自己的手裡浮出來的。

## 資料來源與方法論

### Libet 的實驗設計

- Libet B., Gleason C. A., Wright E. W., Pearl D. K. (1983). *Time of conscious intention to act in relation to onset of cerebral activity (readiness-potential): The unconscious initiation of a freely voluntary act.* **Brain** 106: 623–642.
- 受試者坐著，面前是一台示波器改裝的「鐘」：一個亮點沿著圓周旋轉，**一圈 2.56 秒**，圓周上按傳統時鐘刻度標了 0–55（每 5 格標一次），所以每一小格約 **42.7 毫秒**。
- 指示：在「自己想動的時候」隨意屈腕／按下，不要事先計畫；同時記住**第一次意識到想動**時亮點的位置，事後回報。這個時間點稱為 **W**。
- 同步記錄頭皮腦電（EEG，主要看 Cz 附近）與肌電（EMG）。EMG 起始被當作動作時刻（零點）。
- 結果：**準備電位（readiness potential, RP）在動作前約 550 毫秒**就開始緩慢爬升（未事先計畫的自發動作，Libet 稱之為 RP II）；受試者自述的 **W 平均落在動作前約 200 毫秒**。腦的準備因此比意識早了大約 **350 毫秒**。
- Libet 本人並沒有宣告自由意志死亡：他認為那剩下的約 200 毫秒還足以讓意識**否決（veto）**已經啟動的動作。

### Schurger 的重新解釋

- Schurger A., Sitt J. D., Dehaene S. (2012). *An accumulator model for spontaneous neural activity prior to self-initiated movement.* **PNAS** 109(42): E2904–E2913. doi:10.1073/pnas.1210467109（PubMed 22869750）。
- 主張：RP 可以用一個**有洩漏的隨機累積器（leaky stochastic accumulator）**解釋。運動區本來就有自發的神經雜訊在上下漂移；當「總之要動一下」的驅動很弱時，動作發生的**精確時刻**主要由這些閾下漲落決定——漂移剛好越過門檻，手就動了。
- 最關鍵的一點：因為研究者是**以動作發生的時刻往回對齊（time-locked to movement onset）**去平均所有試次，這種對齊方式**本身**就會把隨機雜訊平均成一條緩慢上升的曲線，即使底下根本沒有任何「準備」歷程。

### 「往回對齊本身會製造曲線」的統計原理

設 x(t) 是一個平穩、有自相關的隨機過程，動作發生於 x 首次由下往上越過門檻 θ 的時刻 t\*。

- 在 t\* 這一點，**依定義** x(t\*) ≈ θ，也就是分布的上緣。
- 因為過程有自相關（時間常數 τ = 1/λ），t\* 前的一小段時間內 x 也偏高，而更早之前 x 回到平均值附近。
- 對每個試次取 [t\*−T, t\*] 這段窗口、做基線校正、再跨試次平均：**平均值必然從 0 慢慢爬到 θ − 平均值**，而爬升所需的時間尺度就是 τ。
- 換成隨機零點時，這個「條件」消失了：E[x(隨機時刻)] 就是平穩平均值，基線校正後平均是 0，只剩下 1/√N 的抽樣雜訊。

所以「曲線」不是資料的性質，是**選樣的性質**。這一頁做的就是把這兩種平均並排放在同一批資料上。

### 這一頁用的模型與參數

離散化的 Ornstein–Uhlenbeck 型累積器（Euler–Maruyama）：

```
x(t+dt) = x(t) + (−λ·x(t) + I)·dt + c·ξ·√dt      ξ ~ N(0,1)
x 由下往上越過 θ  ⟶  動作發生
```

| 參數 | 值 | 意義 |
| --- | --- | --- |
| `dt` | 0.005 s | 時間步（＝ 200 Hz 取樣） |
| `λ` (leak) | 3 s⁻¹ | 洩漏率，時間常數 1/λ ≈ 333 ms |
| `I` (drift) | 0.12 | 微弱的驅動：「總之等一下要動」 |
| `c` (noise) | 0.20 | 雜訊強度 |
| `θ` (threshold) | 0.20 | 門檻 |
| minWait | 3.0 s | 未滿 3 秒就越界的試次整段作廢（對應 Libet 對受試者的要求） |
| epoch | −1500 ms ～ +250 ms | 取樣窗口；基線＝最前面 200 ms |
| 隨機零點 | 距離真正的動作至少 1000 ms | 避免隨機窗口把真正的越界事件包進來 |

由這組參數可以推出：平穩平均值 I/λ = 0.04，平穩標準差 c/√(2λ) ≈ 0.082，門檻約在平均值以上 2 個標準差。實測的等待時間中位數約 **5.4 秒**、p10 ≈ 3.3 秒、p90 ≈ 10.6 秒——和人在自定步調任務裡的按鍵間隔是同一個量級。

**使用者的資料怎麼「真的是他的」**：每按一次，頁面用「這一次的試次序號 × 你的等待時間（毫秒）× 本次開頁的隨機鹽」組成種子，然後在模型自己的分布裡做拒絕抽樣，挑出一個**等待時間跟你這一次差不多（誤差 < 0.25 s）**的試次。所以按鍵的節奏真的決定了紙上印出什麼；換一個人按，二十條線全都不一樣。這是從模型分布裡條件抽樣，不是把曲線寫死。

### 誠實的簡化

- 頁面上的腦電是**模擬的**，不是量到的（頁面本身也明說了這一點）。真正的實驗需要頭皮電極。
- W 的標記可以點鐘面、也可以用滑桿。滑桿每次重置到 750 ms（區間中點）以降低預設值造成的偏誤；即使如此，滑桿標出來的 W 一定比真正的鐘面回報粗糙。
- 選了「只按不標」之後的試次不會產生 W，平均 W 只用你實際標過的那幾次計算——不補值、不外推。
- 「隨機對齊」刻意避開動作前後 1000 ms。這不是為了讓結果好看，而是因為窗口若涵蓋真正的越界事件，那就不再是「隨機零點」，而是另一種形式的動作對齊。
- 讀者只按 8 次時，兩種對齊的平均都會有肉眼可見的抖動；這正是「補到 40 次」存在的理由，補完之後對比才乾淨。頁面上寫的是「剩下的起伏只有原本的幾分之一，而且沒有方向」，沒有宣稱它已經是一條完美的直線。

### 這場爭論還沒結束

Schurger 的模型沒有被普遍接受為定論，也沒有被推翻。2020 年代仍有大量來回：關於隨機漂移與累積歷程的相對貢獻、關於 RP 是否也反映時間估計與預期節奏、關於閾下漲落能否單獨解釋 RP 的形狀與頭皮分布。可參考 Frontiers in Psychology (2023) 文章編號 1271180 一系列討論，以及 *Trends in Cognitive Sciences* 上「What Is the Readiness Potential?」等回顧。

**這一頁刻意不宣稱誰贏。**它只證明一件小事：一條曲線的形狀，有一部分來自你決定從哪裡開始看它。

## localStorage

**這一頁完全沒有使用 localStorage。** 頁面上的所有資料（你按的那幾次、你的 W、疊起來的平均）都只活在這次的分頁裡，重新整理就沒了——因為重來一次本來就是這個實驗的一部分。若日後要加上儲存，前綴一律使用 `libetrp26.`（含結尾的點）。

## 渲染自我檢查表

- [x] **完全不用 SVG 描邊**：整頁的圖形（鐘面、記錄紙、平均圖）都走 canvas，所以不存在 `stroke:url(#grad)` 搭配 `objectBoundingBox` 讓水平／垂直線整條消失的問題。腦波基線是水平線，這是本頁最容易踩的地雷，直接繞開。
- [x] **沒有任何 `filter:drop-shadow()` 掛在零面積路徑上**：頁面沒有用到逐路徑 drop-shadow。
- [x] **三個 canvas 都有 CSS 高度**（`#cvHero` `min(46vh,330px)`、`#cvClock`／`#cvRoll` 290px、`#cvAvg` 340px），不會從 `height` 屬性反推版面高度。
- [x] **resize 先比較尺寸再指派**：`measure()` 內 `if (cv.width !== nw || cv.height !== nh)` 才重設，ResizeObserver 不會形成每幀翻倍的回饋迴圈；也不會在手機網址列收放時清空畫布或重生狀態。
- [x] **沒有用 dasharray 做畫線動畫**：平均曲線的「畫出來」是 canvas 逐點推進（`prog` 由 rAF 的 dt 累加），可以無限次重播，不需要 reflow 技巧。
- [x] **畫線方向正確**：平均曲線依實際時間順序（−1500 ms → +250 ms）繪製，不會倒放。
- [x] **rAF 紀律**：單一 rAF 迴圈驅動所有畫布；`document.hidden` 時整個迴圈不繪製；每個畫布用 IntersectionObserver 記錄是否在畫面內，離屏不畫；非動畫畫布只在 `dirty` 時重畫。
- [x] **`prefers-reduced-motion` 完整降級**：轉動的亮點不再轉（改為靜態鐘面＋數字讀秒，每 250 ms 更新一次）、平均曲線直接畫完不做進場動畫、`.rise` 全部直接顯示、收尾數字直接跳到終值；並且用 `matchMedia` 的 `change` 事件動態監聽，中途切換也會即時反應。
- [x] **CSS 動畫只用 transform／opacity**（`.rise` 的位移淡入、按鈕按下的 `translateY`、按鈕的亮度呼吸）。
- [x] **無障礙**：主按鈕是真的 `<button>`（空白鍵／Enter 可用），實驗站在畫面內時全域空白鍵／Enter 也會觸發；旋轉的鐘點有非動畫的替代讀法（畫面上的「刻度 / 已等 X.X 秒」數字，以及 canvas 的 `aria-label`）；W 的標記除了點鐘面之外一定有滑桿路徑；`:focus-visible` 有明顯外框；狀態訊息用 `role="status" aria-live="polite"` 播報。
- [x] **手機 <560px 單欄**：實驗站的 grid 在 560px 以下改成單欄，畫布高度同步縮小。
- [x] **`file://` 可開**：沒有 ES module、沒有 `fetch()`、沒有任何外部資源（連 cdnjs 都沒用）。

## 測試

- `node tools/check.js`：本專案零錯誤、零提醒。
- 核心斷言（直接從 `index.html` 抽出標了 `MODEL START/END` 的那段程式碼，丟進 node 的 `vm` 跑，不是另外重寫一份）：
  1. 模型正確性——每個試次的動作都是**由下往上**越過門檻、等待時間都 ≥ 3 秒、epoch 前段長度足夠。
  2. **這頁的靈魂**：同一批 400 個模擬試次，以觸發時刻往回對齊的平均在 −500 ms 到 0 ms 之間、每 50 ms 一箱**嚴格單調上升**，末端 0.189（基線 ≈ 0）；以隨機時刻對齊的平均最大振幅只有 0.013，兩者相差 **14.5 倍**（超過一個數量級），且隨機對齊的平均不單調上升。
  3. 爬升起點（50 ms 分箱，從零點往回找最後一段「連續兩箱低於峰值 10%」）落在 **−450 ms**，並斷言它必須落在 −1000 ～ −300 ms 之間——和 Libet 報告的 −550 ms 是同一個量級。用「連續兩箱」是因為試次少的時候單一箱很容易被雜訊頂上去，起點會被誤判到太早。
  4. 真實使用情境：12～20 個試次、300 回合隨機重跑，末端最低仍有 0.135、峰值對隨機對齊 RMS 的比值最低 3.4 倍、「後 200 ms 高於前 200 ms」零次失敗、隨機對齊誤爬 0/300。
  5. `matchTrial` 在 3.2／4.5／6.0／9.0／14.0 秒的目標等待時間下都挑得到誤差 < 0.6 秒的試次。
  6. epoch 基線校正確實把最前面 200 ms 拉到 0，長度正確。
- 另外用 jsdom（搭配真實的 canvas 2D 實作）跑過完整流程：正常模式按滿 8 次、減少動態模式標 3 次後自動切「只按」再用「按夠了」在第 5 次收工，兩條路徑都能一路走到第四章，全程沒有任何 JS 執行期錯誤，並輸出各畫布的實際渲染結果逐張目視檢查過。（流程改版後另用 DOM 替身重跑一次，見下。）
