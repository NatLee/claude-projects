# 你讀第二遍的時候

## 故事線

- **鉤子**：不解釋任何研究，也不先講「提取練習是什麼」。開頁第一屏只有五個字——**「記住這一段。」**——底下就是一段真的要背的短文，和一個「開始 · 22 秒」的按鈕。讀者在還沒搞清楚自己在幹嘛之前，就已經是受試者了。
- **鋪陳（由使用者動手，這是骨幹）**：材料被切成兩半，兩半用兩種讀法。**重讀那半**：讀三遍，每遍 22 秒，中間夾 8 秒心算干擾（原研究真的用乘法題當 distractor）。**回想那半**：只讀一遍 22 秒，材料就被收走，接著三次自由回憶——**而且一次都不告訴他對不對**。每收一次，頁面就說一句「不告訴你對不對，這是刻意的」。誰配到哪一半、哪一種先做，開頁時擲兩次硬幣決定。
- **關鍵一步**：兩半都做完，**先不考**。先要他押注：兩根滑桿（各半能答對幾成）＋一個三選一（哪一半比較有把握）。按下**「鎖住我的預測」**之後就不能改。多數人會押重讀那半——那半讀起來順多了。
- **誠實的中場**：接著頁面直接承認一件做不到的事——原研究的分水嶺在**第二天**，網頁留不住人兩天，所以只能給一個 60 秒的干擾版本，並白紙黑字寫「**這不是原研究的複製**」。
- **高潮（由使用者親手觸發）**：十二題，兩半各六題，順序打散。按下**「交卷」**——長條圖上，他鎖住的預測是粉紅色虛線的空心柱，實際分數是實心柱長上來。兩根柱子中間那段空白，就是這一頁要給的東西。
- **記憶點（回馬槍）**：結論不是「所以要多考試」。收尾先把原研究裡最扎人的那張表攤開（讀了 14.2 遍的人信心 4.8 分、一週後 40%；讀 3.4 遍的人信心 4.0 分、一週後 61%——**信心那一欄和成績那一欄排序完全顛倒**），然後鏡頭轉回讀者身上：**「順便一提，你剛剛讀這一頁，讀得很順吧。」**——按鈕「那考我這一頁」，三題選擇題，考的是他剛剛讀完的這一頁。最後一句：「這一頁你只讀了一遍，沒有人考過你。剛剛那三題，是你的第一次提取。」

這一頁的主角不是「測驗效應」，是**流暢幻覺**：你判斷自己學會了沒有，用的是「讀起來順不順」這根指針，而它量的是熟悉，不是記憶。

## 這是什麼

一場**你自己一個人跑完的雙組實驗**。整頁是一台實驗台：頂部有一條進度軌，標出兩個組各自的回合數（讀 ×3ㅤ／ㅤ讀 ×1 ＋ 回想 ×3），下面是逐段推進的舞台。不是論文摘要，也不是讀書方法清單。

## 怎麼玩

1. 開頁就是材料。按「開始 · 讀三遍」或「開始 · 讀一遍」（看你被抽到哪一種先做）。
2. **重讀那半**：三段 22 秒的閱讀，中間兩次 8 秒心算空檔（心算題不計分，隨便算）。
3. **回想那半**：一次 22 秒閱讀 → 材料收走 → 三次自由回憶，每次上限 35 秒，寫完可以按「寫完了」提前交。**全程沒有任何回饋。**
4. 兩半做完 → **押注**：拉兩根滑桿、選一個你比較有把握的半邊，按「鎖住我的預測」。鎖了不能改。
5. **延遲**：60 秒心算干擾。旁邊有「我不等了，直接考」，按了頁面會點你一句。
6. **考試**：12 題短答，兩半各 6 題、順序打散。拼錯字寬容，數字寫阿拉伯或國字都收，空著也可以。按「交卷」。
7. **結果**：預測（粉紅虛線空心柱）與實際（實心柱）並排；下面接原研究那條在第二天交叉的折線，以及信心 vs 成績顛倒的那張表。
8. **回馬槍**：按「還有一件事」→「那考我這一頁」，三題選擇題考剛剛這一頁。

## 為什麼有趣

因為它會在讀者身上**製造**那個錯覺，而不是描述它。讀第三遍的時候那種「我會了」的順暢感是真的、當場發生的；十分鐘後那根粉紅虛線比實心柱高出一截，也是他自己按出來的。中間沒有任何一句話在說服他。

而且最後那一擊是這一頁自己承擔的：整頁讀起來很順——所以按照這一頁的邏輯，讀者對這一頁的記憶最不可靠。三題選擇題就是當場的校正。

## 資料來源與方法論

### 主要文獻

**Roediger, H. L., III, & Karpicke, J. D. (2006). Test-enhanced learning: Taking memory tests improves long-term retention. _Psychological Science, 17_(3), 249–255.** <https://doi.org/10.1111/j.1467-9280.2006.01693.x>

#### 實驗一：三個延遲條件

- 受試者 **120 位**華盛頓大學（聖路易）大學部學生，18–24 歲。
- 材料：兩篇取自 TOEFL 應試書（Rogers, 2001, _TOEFL CBT Success_）閱讀測驗的說明文——〈The Sun〉與〈Sea Otters〉，**256 字**與 **275 字**，各切成 **30 個意念單位（idea units）**供計分。
- 設計：2 × 3 混合設計。學習方式（**重讀 vs 測驗**）**受試者內**操弄（同一個人兩篇各一種），最終測驗延遲（**5 分鐘 / 2 天 / 1 週**）**受試者間**操弄。順序與篇章都做了對抗平衡。
- 程序：第一階段四個 **7 分鐘**的時段（讀一篇、重讀一篇、或考一篇）；時段之間做 **2 分鐘乘法題**，最後一個時段後做 5 分鐘。測驗是**自由回憶、沒有回饋**——只給文章標題，把記得的寫下來。
- 初次那一次 7 分鐘測驗，平均寫出 **20.9 個意念單位（約 70%）**。
- 最終測驗答對比例：

  | 延遲 | 重讀組 | 考過一次 | 差 |
  |---|---|---|---|
  | 5 分鐘 | **81%** | 75% | 重讀 +6（t(39)=3.22, d=0.52） |
  | 2 天 | 54% | **68%** | 測驗 +14（t(39)=6.97, d=0.95） |
  | 1 週 | 42% | **56%** | 測驗 +14（t(39)=6.41, d=0.83） |

  學習方式 × 延遲的交互作用顯著：F(2, 117) = 32.10, ηp² = .35。
- 論文特別指出：**被考過那組在一週後記得的，比重讀組在兩天後記得的還多**——一次測驗替他們多擋了五天的遺忘。
- 這個對照的關鍵在於，重讀組被重新曝露到 **100% 的內容**，而測驗組（沒有回饋）只能重新經歷自己想得起來的部分。也就是說，實驗設計本身是**偏袒重讀組**的。

#### 實驗二：信心與成績脫鉤（這一頁真正的重點）

- 受試者 **180 位**，三種學習條件（S = 讀、T = 考），每個時段 **5 分鐘**，最終測驗在 **5 分鐘**或 **1 週**後，每格 30 人：
  - **SSSS**：讀四遍，完全不考
  - **SSST**：讀三遍 + 考一次
  - **STTT**：讀一遍 + 考三次（全部無回饋）
- 受試者用計數紙記錄自己把全文讀完幾次：**SSSS 平均 14.2 次、SSST 10.3 次、STTT 3.4 次**。
- STTT 三次測驗的成績幾乎不動：**20.9、21.2、21.1** 個意念單位（各約 70%）——沒有回饋，重複提取本身並沒有讓他們「多學到」新內容。
- 第一階段結束時填一份問卷（7 點量表），其中一題是：**你覺得一週後你會記得多好？**（1 = 不太記得，7 = 記得很牢）

  | 條件 | 讀完全文次數 | 覺得有趣 | 覺得好讀 | **自評信心** | 5 分鐘後 | **1 週後** |
  |---|---|---|---|---|---|---|
  | SSSS | 14.2 | 3.8 | 2.5 | **4.8** | 83% | **40%** |
  | SSST | 10.3 | 4.1 | 2.5 | 4.2 | 78% | 56% |
  | STTT | 3.4 | 4.6 | 2.8 | 4.0 | 71% | **61%** |

  信心差異顯著：F(2, 177) = 6.09, η² = .06；SSSS vs SSST t(118) = 2.95, d = 0.54；SSSS vs STTT t(118) = 3.35, d = 0.61；後兩組之間不顯著。**信心的排序與一週後成績的排序完全顛倒。**
- 換成比例遺忘量（(初測 − 終測) / 初測）看，一週內遺忘：**SSSS 52%、SSST 28%、STTT 14%**。
- 論文原話：重讀相對於測驗，**膨脹了學生對自己未來記得住的信心**，而他們實際上表現最差；學生偏好重讀，是因為它「產生短期收益」，而他們**用短期收益去預測長期表現**。

### 佐證文獻（頁面上有引用其結論）

**Karpicke, J. D., & Roediger, H. L., III (2008). The critical importance of retrieval for learning. _Science, 319_(5865), 966–968.** <https://doi.org/10.1126/science.1152408>

- 40 對斯瓦希里語–英語單字，四種練法：標準（ST）、答對就不再重讀但仍受測（SNT）、答對就不再受測但仍重讀（STN）、答對就完全退出（SNTN）。
- 四組的**學習曲線完全一樣**，四組對自己一週後表現的**預測也完全一樣**（分別預測答對 20.8、20.4、22.0、20.3 題／40 題，約 50%，F < 1）。
- 一週後實際：**重複受測的兩組約 80%**，被抽離測驗的兩組只有 **36% 與 33%**。合併後 d = 4.03，兩群分數**分布不重疊**（退出測驗組 10–60%，重複測驗組 63–95%）。
- 頁面上「所有人的預測都停在 50% 上下，差了四個標準差」這句話，出處在此。

**Karpicke, J. D., & Blunt, J. R. (2011). Retrieval practice produces more learning than elaborative studying with concept mapping. _Science, 331_(6018), 772–775.** <https://doi.org/10.1126/science.1199327>

- 實驗一（N = 80）：一週後的簡答測驗，**提取練習 M = 0.67**，**概念構圖 M = 0.45**（合併字面題與推論題），d = 1.50, F(1,38) = 21.63, ηp² = 0.36；而學生的學習判斷（JOL）預測**重複閱讀最好、提取練習最差**，剛好相反。
- 實驗二（N = 120，受試者內）：d = 1.07（簡答）與 d = 1.01（連最終測驗改成畫概念圖，提取練習還是贏）。**120 人裡有 101 人（84%）在提取練習那一邊表現較好，但 120 人裡有 90 人（75%）事前認為概念構圖會一樣好或更好。**
- 這篇沒有直接印在頁面上，但它是「這個效應不只贏過『再讀一次』，也贏過公認的主動學習法」的依據，寫在這裡備查。

### 誠實邊界（頁面收尾也寫了）

- **這不是在說「讀書沒用」。** 沒有讀進去的東西提取不出來；提取練習需要先有輸入，原研究每一組都先讀過。
- 效果**依材料、依測驗形式、依初次表現而變**。Roediger & Karpicke 自己在討論裡寫：測驗效應的邊界條件還不清楚，但推測在「學完後不久測」且「初次表現水準夠高」時最強。
- 原研究測的是**散文的自由回憶**（近似申論），不是選擇題；也不是技能學習或理解本身。
- 真正被推翻的是一個很窄但很常見的東西：**「多讀幾遍，讀到順為止」這個停止條件。**

## 我的材料怎麼設計，以及怎麼確保兩半對等

頁面上用的兩段短文（〈灰岬 · 鹽鐘〉與〈白磧 · 沙笛〉）是**為這場實驗寫的虛構說明文**，這件事在頁面上（第二半結束後的小字）直接寫明。

**為什麼刻意用虛構內容**：這是一個方法論上的選擇，不是偷懶。如果用真實的科普材料，讀者的**先備知識**會直接污染兩半的比較——他碰巧知道其中一邊的主題，那一半就贏了，而那跟他用哪一種讀法無關。原研究用 TOEFL 文章時，靠「大量受試者 + 對抗平衡」把這個變異平均掉；只有一位受試者的網頁做不到，所以改成從源頭消除它。

**怎麼配對難度**（每一項都寫進 `RRX.equivalence()`，並在 node 斷言裡鎖住）：

| 對齊項目 | 鹽鐘 | 沙笛 |
|---|---|---|
| 字數 | 159 | 161 |
| 句數（。） | 5 | 5 |
| 標點數 | 14 | 14 |
| 可考點數 | 6 | 6 |
| 可考點型別序列 | name → size → year → event → count → span | 同左，逐位相同 |

兩段的**句法骨架逐句對齊**：第 1 句「地名＋地形＋一種東西＋當地人叫它 X」；第 2 句「機制＋一年大約〈數量〉」；第 3 句「〈年代〉起，某群人開始拿它看某件事：條件句」；第 4 句「〈年份〉一場〈災害〉毀掉最大的那個，數出〈計數〉」；第 5 句「研究者據此推算，它撐了將近〈幾個世紀〉」。

**答案刻意不可混淆**：4 毫米 / 2 公斤、1890 / 1920、260 / 340、七個世紀 / 九個世紀、颶風 / 沙暴、鹽鐘 / 沙笛。node 斷言逐題驗證「把甲半的答案填進乙半的題目一定判錯」，反之亦然。

**兩段的表面主題刻意拉開**（海邊岩柱 vs 沙漠甲蟲），降低兩半互相干擾（proactive／retroactive interference）的機會。代價是無法做到「主題難度」層面的完全等價——但可考點的型別、數量、句法位置都對齊了。

**指派是隨機的**：開頁時擲兩次硬幣，決定（a）哪一段配到重讀、哪一段配到提取，（b）哪一種讀法先做。所以重刷會拿到不同的組合，也不會有「第一段永遠是重讀」這種系統性偏差。

## 評分規則

全部走 `RRX.gradeOne(fact, input)`，先正規化再比對：

1. **正規化**：全形轉半形 → 轉小寫 → 去所有空白 → 去 ASCII 標點與中文標點。所以「　鹽鐘。」「２６０」「4 mm」都能過。
2. **文字題**（名稱、事件）：對別名清單做子字串比對，別名含常見錯字與簡體（鹽鐘／鹽鍾／盐钟、沙笛／砂笛、颶風／飓风、沙暴／沙塵暴）。三字以上的別名再放寬**一個編輯距離**。**兩字詞不放寬編輯距離**——否則「颱風」會被判成「颶風」。
3. **數字題**（數量、年代、計數、跨度）：從作答裡撈出所有數字再比對集合。撈法有三路：
   - 阿拉伯數字直接抓；
   - 中文數字**逐位讀**（「一八九〇」→ 1890），但**只在該串不含十／百／千時**才用——否則「四十」會被讀成 4；
   - 中文數字**正規解析**（「兩百六十」→ 260、「七百」→ 700、「十二」→ 12）。
   所以「七個世紀」「七百年」「700 年」「7」都算對，「九個世紀」「1700 年」「四十毫米」都算錯。數字題**不套用編輯距離**（不然「九個世紀」對「七個世紀」只差一個字，會被誤放行）。
4. **空作答**：正規化後為空字串一律判錯，且 `gradeOne(null, x)`、`gradeOne(f, null)`、`gradeAll(facts, undefined)` 都不會拋例外。

## 網頁版壓縮了延遲——這不是原研究的複製

這句話同時寫在頁面上（延遲階段那個虛線框）與這裡：

- 原研究的最終測驗排在 **5 分鐘 / 2 天 / 1 週**，方向的翻轉發生在**第二天**。網頁留不住讀者兩天，所以壓成 **60 秒**的心算干擾。
- 因此，**這一頁很可能會看到「重讀那半贏」**——那正是原研究在 5 分鐘條件下看到的結果（81% vs 75%）。頁面的判讀文字對三種結果（重讀贏／打平／提取贏）各寫了一句，重讀贏的那句就是這樣講的。
- 其他做不到的地方，一併說明：
  - **n = 1**，沒有統計，沒有對照組間平均。
  - **順序未在同一位讀者身上對抗平衡**（一個人只能有一個順序），只能靠開頁隨機化讓它在讀者之間平均掉。
  - **時間投入不相等**：重讀那半 3 × 22 秒；提取那半 22 秒閱讀 + 最多 3 × 35 秒回憶。原研究實驗二是四個時段對四個時段，時間相等。這一頁沿用「讀三遍 vs 讀一遍＋回想三次」的設定，所以提取那半花的**總**時間較長，但**看到材料**的時間只有重讀那半的三分之一——後者才是效應的重點。
  - **開始鍵按下前材料是看得見的**，兩半都一樣，所以不會系統性地偏袒哪一邊，但確實無法阻止讀者在按鈕前多看幾秒。
  - 意念單位改成 6 個關鍵詞的短答，不是 30 個意念單位的自由回憶評分。

一句話：**這一頁是一個示範，不是一次複製。** 它能可靠地讓你看見的是「你的預測」和「你的成績」之間的落差；它不能證明測驗效應——那件事交給那 120 位和 180 位受試者。

- 前綴：`rereadx26.`（同檔字面常數 `var LS = 'rereadx26.';`）
- 唯一的 key：**`rereadx26.last`**，內容是一個 JSON：時間戳、哪一段材料配到重讀、哪一種讀法先做、你的預測（兩個百分比＋押注）、以及 `computeGap()` 算出來的落差物件。
- 用途：下次再玩時，結果區會多一行「上一次你押 X% 對 Y%，考出來是 A% 對 B%」。沒有它整頁照樣完整運作。
- 讀寫全部包在 `try/catch` 裡，無痕模式擋掉 localStorage 時功能不受影響。

## 渲染自我檢查表

- **SVG 漸層描邊**：全頁**沒有任何 SVG**，兩張圖都是 canvas，不存在 `stroke:url(#g)` 與 `gradientUnits` 的坑。長條圖的基線是水平線——正因為知道這是重災區，才走 canvas。
- **逐路徑 drop-shadow**：全頁沒有使用 `filter: drop-shadow()`。
- **canvas CSS 尺寸**：`canvas.chart` 有明確 CSS 高度（308px；折線圖 270px；≤560px 改成 266 / 236），不是只有 `width:100%`。
- **resize 回饋迴圈**：`fitCanvas()` 先算出 `w / h / dpr` 再**逐項比較**，三者都沒變就 `return false`，完全不碰 `canvas.width`。**不使用 ResizeObserver**，只用 130ms debounce 的 resize 監聽。無頭測試在 `canvas.width` 的 setter 上裝了計數器：連發 **60 次 resize，指派次數為 0**；真的改變 CSS 尺寸（640×308 → 900×340）才增加 1 次。dpr 上限鎖 2，dpr = 1 與 2 都測過。
- **dasharray 動畫**：**沒有使用 CSS dasharray 動畫**。折線的畫線動畫在 canvas 內用「已走完的線段比例」推進，重播只要把進度歸零，不依賴 CSS transition 的重排時機。
- **繪製方向**：折線由 `5 分鐘 → 2 天 → 1 週`（左 → 右，時間由早到晚）逐段產生，與時間方向一致，不會倒放。
- **只用 transform / opacity**：進度條是 `transform: scaleX()`；捲動進場是 `opacity` + `translateY`。沒有動 width / height / top / left。
- **rAF 紀律**：全頁**單一** rAF 迴圈，同時驅動計時器與圖表動畫；沒有待處理的工作就自己停（`needFrames()` 為 false 即 `running = false` 且不再排程）；`document.hidden` 時取消、回前景恢復（計時器也跟著凍結——分頁在背景時本來就不該算閱讀時間）。**全頁沒有 `setInterval`。**
- **動畫接力不被清掉**：`tickAnim()` 先把 `anim.on / anim.target` 收乾淨再呼叫回呼，所以「第一張圖畫完 → 接著開始畫第二張」不會被自己的收尾邏輯清掉（這是第一版真的有的 bug，已修並被無頭測試覆蓋）。
- **prefers-reduced-motion**：初始讀取 + `matchMedia` 的 `change` 動態監聽（`addEventListener` 優先、退回 `addListener`）。開啟時：所有 `.fade` 直接顯示、兩張圖一次畫到最終狀態、`scroll-behavior` 改回 `auto`、`scrollIntoView` 用 `behavior:'auto'`。**計時器不受減動態影響**——那是內容節奏，不是裝飾動畫。減動態情境的完整流程無頭跑過，零錯誤。
- **兩張圖不只靠顏色區分**：長條圖的預測是**虛線空心柱**、實際是**實心柱**，並各自標數字；折線圖的重讀是**實線＋方形端點＋數字在線上方**，測驗是**虛線＋圓形端點＋數字在線下方**，線末另有文字標籤。
- **圖上文字不打架**：折線的左端數字靠右排、右端數字靠左排（否則 75% 會壓到 y 軸的 70%，實測過）；長條圖的圖例第二段依 `measureText` 量到的寬度接續，窄畫布不會疊住。340px 寬的手機尺寸實際輸出 PNG 檢視過。
- **無障礙**：全部用原生表單元素（`range` / `text` / `textarea` / `radio` / `button`）；`:focus-visible` 有明顯外框；兩張 canvas 有 `role="img"` 且 `aria-label` 會被實際數字覆寫；每個階段的狀態文字放在 `role="status" aria-live="polite"`（閱讀倒數、回想提示、作答題數、延遲倒數）；考卷的每個輸入框有 `aria-label` 帶題號與題目；頂部進度軌是裝飾，標了 `aria-hidden="true"`。
- **手機 <560px**：單欄流動，圖高縮小，押注的三個選項改成直排，材料卡片內距縮小。頂部進度軌可橫向捲動，左側保留 108px 給固定的「← 回首頁」，兩者不會重疊。
