# 切開之後長出兩顆頭

一頁攤在解剖顯微鏡旁的活頁實驗日誌。你親手切開一條渦蟲，一輪一輪翻下去，
直到你發現那份「該長成什麼樣子」的記憶，根本不在你以為的地方。

---

## 故事線

**鉤子。** 第一屏只有一條蟲、一把刀、一句話：牠被切開會長回來——但長回什麼，是誰決定的？
不解釋生物電，不解釋渦蟲，先把刀遞給你。

**鋪陳（輪次 I）。** 你按下「下刀」。兩刀，三段。我們只盯著中間那一段軀幹——
它前後都缺，兩邊都得重新長。白色的芽長出來，前面成頭，後面成尾。
再切一次，還是。再切，還是。這不是運氣，這是規格。

**鋪陳（輪次 II）。** 你親手滴進一滴辛醇。它不改基因，只是暫時讓細胞之間講不了話。
泡一下，沖掉，然後下刀。這一次，有的軀幹段兩端都長出了頭。
**頁面從頭到尾不會告訴你「四分之一」這個數字**——你得多切幾條，
讓那條比例條自己浮出來（有「一次切十條」可以加速）。

**轉折。** 你把兩頭蟲撈進乾淨的清水裡——沒有藥了——再切一次。還是兩顆頭。
第三代、第四代、第五代……藥早就沖掉了，牠還記得。這裡要停一下。
然後是更毛的那一半：那些**看起來完全正常**的呢？你切一條看看。
同樣的比例又長回來了。牠身上一點跡象都沒有，可是那份設定還在裡面。

**高潮（由你觸發）。** 你按下「送檢」。序列一格一格掃過去，兩排完全對齊，
四個檢查項一個一個蓋上「正常」章：基因體序列、組織學、分子標記表現、幹細胞分布。
差異：**0**。被改掉的東西，不在這四個地方。

**記憶點。** 鏡頭拉遠，一整排培養皿沿著世代排開，每一皿裡都是兩顆頭。
回扣開頭那把刀：刀切得開身體，切不開那份設定。
基因體是原始碼；真正在跑的那份設定，寫在細胞與細胞之間的電位上——而設定，是可以被改的。

---

## 這是什麼

一個以「培養皿實驗日誌」為容器的互動敘事頁。整頁是一本活頁記錄：
打孔的邊條、日期戳、一輪一輪的記錄卡、旁邊潦草的紅筆註記。
所有的蟲、培養皿、刀口、再生過程都是 canvas 即時繪製，沒有任何圖檔。

## 怎麼玩

1. **輪次 I ｜對照組**：按「下刀 ✂」切開牠。三段；只看中間那段軀幹。多切幾次確認它有多穩定。
2. **輪次 II ｜一滴辛醇**：先按「滴一滴辛醇」，等它擴散、沖掉，再下刀。
   一條一條切，或用「一次切十條」快轉。切滿十二條之後，比例條會自己出現。
3. **輪次 III ｜清水**：把兩頭蟲撈進清水再切，看世代數字一代一代往上滾。
4. **那 72%**：切一條「看起來正常」的治療組個體——同樣的比例又長出來了。
5. **送檢**：按下按鈕做定序與組織檢查。這是這頁的「哇」時刻。
6. 最後一屏是拉遠鏡頭，還會告訴你今天總共切了幾刀。

鍵盤全程可用：每個動作都是真正的 `<button>`，Tab 走得到，有可見的 focus 框，
所有結果都以 `aria-live` 播報。培養皿本身也可以直接點（滑鼠的觸覺版本），
但不依賴它——按鈕是等價的替代路徑。

## 為什麼有趣

因為它把「記憶」從我們最熟悉的兩個地方（腦、基因）搬走了。
渦蟲切成兩段，後段長出一顆頭——這件事本身已經夠奇怪。
真正詭異的是：那份「我該長成什麼樣子」的規格書，可以被一次**暫時的電學干擾**永久改寫，
而承載這份規格的介質，不是 DNA。

而且它有一個很少見的敘事禮物：**機率本身就是劇情**。
你不需要被告知那個數字，你自己切個二三十條就會看見它。

### 物種與基本事實

- 實驗物種是 **Dugesia japonica**（日本三角渦蟲）。渦蟲是再生研究的經典模式生物：
  切成數段，每一段都會補回缺少的部分，長成一條完整、比例正確的蟲。
  正常情況下再生產物是原本那條蟲的精確複本。
- 本頁只追蹤「軀幹段」（trunk fragment）——把蟲橫切兩刀分成頭段、軀幹段、尾段，
  中間那段前後都缺，前端該長頭、後端該長尾，是最能看出「方向性決定」被改寫的片段。
  這也是論文計數的對象。頁面上另外兩段畫成淡出並註明「另外兩段也會長回來，我們先不看它們」。

### 辛醇（octanol，8-OH）怎麼作用

- 辛醇是一種**間隙連接（gap junction）阻斷劑**。間隙連接是細胞之間的蛋白通道，
  相當於細胞的「電突觸」，讓細胞在近距離與長距離之間交換電訊號。
- 短暫暴露辛醇＝短暫切斷這張全身性的電網路。它**不改變任何基因序列**，
  也不是永久性的化學修飾；藥物會被沖洗掉。改變的是這張網路穩定下來之後所編碼的「目標形態」。
- 頁面把時序簡化成「泡一下、沖掉、下刀」。實際論文中的暴露是圍繞截肢前後的一段短暫處理，
  細部時程與濃度請見原論文的 Methods。

### 25% 這個數字的來源與性質

- 出自 Durant et al. (2017) 並在 Tufts Now 新聞稿中被明確引述：
  **25% 的截肢軀幹段再生成兩頭渦蟲，72% 再生成外觀正常的單頭渦蟲，約 3% 未能正常發育。**
- 這個比例是**隨機的（stochastic）**，不是「每四條就一定有一條」。
  論文標題裡的 stochastic 就是這個意思：同一批、同樣處理的個體會出現不同結果。
  這也是論文特別指出的價值之一——它提供了線索去理解「為什麼同樣處理的個體會有不同生物學結果」。
- 頁面把 25 / 72 / 3 寫進一個純函式 `regenerate()` 當作抽樣分布，
  **刻意不在文案中寫出這三個數字**，讓讀者自己切出來。
  切滿十二條之後才顯示比例條——樣本太少時的比例會很難看，這是刻意的設計節奏。

### 「基因體不變」的確切意思

這是最容易被寫壞的一句話，所以講清楚：

- 論文的說法是這些蟲具有 **wild-type genomic sequence**——牠們是野生型品系，
  沒有任何基因改造、沒有 RNAi 敲降留下的持久改變，處理手段是純藥理學且暫時的。
- 論文明確指出：被改變的目標形態**並非**編碼在
  **組織學（histology）、分子標記表現（molecular marker expression）、幹細胞分布（stem cell distribution）**中——
  這三項在兩頭蟲與隱性帶原的正常外觀蟲身上都是正常的。
- **論文並沒有做全基因體定序去逐字比對。** 所以頁面上的「差異：0」指的是
  「沒有人動過牠們的基因，牠們是野生型」，而不是「我們定序了三十億個鹼基對，一個都沒差」。
  頁面文案因此寫成「沒有人動過牠們的基因」而非「我們把牠的基因體從頭讀到尾」。
  那個 0 旁邊的標籤是「處被改寫的地方」，指的是這四項檢查的結果。

### 「無限期維持」的確切意思

- 兩頭渦蟲在普通清水中再次截肢，會繼續再生成兩頭——這個表現型會在後續世代持續維持，
  相關回顧見 Durant et al. (2016, *Biology Open*)。頁面的輪次 III 把它模型化成**確定性**的
  （兩頭一旦建立，之後每一代都是兩頭），這是為了讓「狀態一旦建立就維持」這件事清楚可測；
  真實實驗中維持率極高但不必然是嚴格的 100%。
- **論文中更驚人的那一半**（也是頁面第 4 個互動）：那 72% 外觀完全正常的個體，
  在**數個月間於普通泉水中反覆截肢**，仍然產生同樣比例的兩頭 / 單頭後代。
  也就是說被改寫的目標形態是**隱性的（cryptic）**——完整的蟲身上看不出來，
  只有在再生時才會顯現。這正是論文摘要說的「可以用生物電網路去研究先前無法觀察的隱性表現型」。

### 哪些是 Levin 的主張，不是共識

- 「生物電模式是一種**形態的記憶（pattern memory）**、可以被讀寫」——
  這是論文的實驗結論所支持的說法，本頁採用它。
- 「**basal cognition（基礎認知）**」「認知是一條從細胞一路連續到我們的光譜」「細胞集體有目標、有偏好」——
  這是 **Michael Levin 本人的理論主張與詮釋框架**，在領域內有爭議，不是共識。
  頁面上只用一句話帶到，並且明確標示成「他的主張」。
- 本頁**刻意不寫**的東西：細胞有意識、記憶是靈魂、電裡面住著什麼。
  這頁的立場只有一句：**形態的記憶可以存在非基因的媒介裡。** 這件事本身就已經夠驚人了。
- 相關延伸只用一句話帶到、不展開：同一個實驗室後來以青蛙細胞做出了 Xenobots。

## 核心邏輯與斷言

抽成純函式（原始碼中以 `/* ===PURE=== */ … /* ===END PURE=== */` 標記，測試直接抽這段來跑）：

```js
regenerate(state, rnd)   // state: 'naive' | 'edited' | 'twoheaded'
lineage(state, n, rnd)   // 連續 n 代的狀態轉移
```

以 node assert 驗過：

1. `naive` 抽 20000 次全部是一顆頭、零發育不全、狀態不變。
2. `edited` 抽 200000 次：兩頭比例落在 0.245–0.255、發育不全落在 0.027–0.033
   （用固定種子的 mulberry32 亂數，可重現）。
3. `edited` 的隨機性確實存在：不同種子的結果不完全相同，但都落在區間內。
4. `twoheaded` 抽 20000 次全部是兩顆頭、狀態恆為 `twoheaded`。
5. 世代鏈：從 `edited` 跑 500 代，一旦轉成 `twoheaded` 就再也不會離開；
   且轉成之後每一代的 `heads` 都是 2。
6. 邊界：`rnd` 回傳 0、0.2499、0.25、0.9699、0.97、0.9999 時的分類正確。

## 渲染自我檢查表

- **SVG 漸層描邊**：整頁沒有任何 SVG 漸層描邊。視覺全部走 canvas 與 CSS，`stroke:url(#…)` 零使用。
- **零面積路徑的 drop-shadow**：沒有逐路徑 `filter:drop-shadow()`；陰影一律是 DOM 的 `box-shadow`
  或 canvas 的 `shadowBlur`（掛在有面積的形狀上）。
- **canvas CSS 尺寸**：六個 canvas 全部在 CSS 裡給了明確的 `height`（含 <560px 的手機值），
  不靠 `height` 屬性撐版面。
- **resize 先比較再重設**：`measure()` 先比對 `cv.width/height` 的目標值，
  相等就不指派——避免 ResizeObserver 每幀翻倍讓整張圖消失（dpr=1 螢幕看不出來的那個 bug）。
- **dasharray 重播**：整頁沒有使用 CSS dasharray 畫線動畫，改用 canvas 逐幀繪製與 transform，
  從源頭避開這個地雷。世代數字的滾動用「移除 class → 讀 `getBoundingClientRect()` 強制 reflow →
  下一個 rAF 再加回」的可靠重播寫法。
- **繪製方向**：刀口的掃描動畫由上往下畫（`moveTo(x, top)` → `lineTo(x, top + 進度)`），
  與視覺上刀刃落下的方向一致，不會倒放。
- **比例條動畫只用 transform**：三段比例用 `transform: translateX() scaleX()` 疊出來，
  沒有 `width` 過渡。
- **動畫紀律**：單一 rAF 迴圈驅動六個 canvas；`document.hidden` 時整迴圈不繪製；
  每個 canvas 用 IntersectionObserver 標記可見性，離屏不畫；
  `prefers-reduced-motion` 時環境動畫全停、切割動畫直接跳到結果（互動仍然完整可用），
  並且監聽 matchMedia 的 `change` 事件即時切換。
- **自包含**：純靜態單一檔案，零外部資源、零 ES module、零 `fetch()`，雙擊 `file://` 可開。
