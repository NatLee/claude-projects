# 睡著之後放給你聽

## 故事線

- **鉤子**：不從「TMR 是什麼」開始，而是先把那個都市傳說完整地、誘人地講一次——今晚戴著耳機睡，早上起來你會說荷蘭文。第一屏只有一副在呼吸的耳機和這句話。**不先破梗**，先讓讀者站進那個房間裡。（第一屏底下有一條低調的側線：「沒時間看故事？直接去實驗台，一鍵跑完一夜 ↓」，趕時間的人可以一步跳過敘事。）
- **轉折一（破掉它）**：1956 年，Simon 與 Emmons 把電極貼上去。腦波說了實話——凡是受試者事後答得出來的題目，播放的那一刻他的腦波都還醒著。**你沒辦法在睡覺的時候學會你不會的東西。**
- **轉折二（真正的內容）**：可是——如果你白天已經學過了呢？揭曉 Schreiner & Rasch (2015)。他們只是在你睡著之後，把你白天學過的字**再念一次**。被播過的那一半記得比較牢；清醒時重播完全沒有效果。清醒對照組才是關鍵，它把「多聽幾次」這個平庸的解釋直接排除掉。這一幕收在一句翻轉身分的話：**與其躺下來當那個受試者——不如換你來設計那一夜。**
- **高潮（由使用者親手觸發）**：**實驗設計台**。讀者不再是受試者，是設計 protocol 的人。五個旋鈕（白天有沒有先學過／在哪個階段播／播幾次／音量／要不要補答案），按一顆鈕，**八個小時在 4.6 秒內跑完**：hypnogram 從左往右畫出來、線索自動落到選定的階段上、吵醒事件當場冒出來、效果量從 0 滾到定值。然後每跑一夜就在下面**疊一列紀錄**——真正的高潮不是任何單一結果，是**條件之間的落差**。趕時間的人有一顆「一次跑完整組」，2.7 秒把八種關鍵條件的矩陣一次攤開。
- **記憶點**：不是「所以可以睡覺學外語」。收尾先拉遠鏡頭——**沒被點名的那些字，那一夜也在被複習**；TMR 只是插隊，所以你表上「完全不播」那一列不是空白對照，是一整夜認真工作的大腦。然後回馬槍：那個傳說唯一講對的部分是「你確實可以在睡覺的時候變強」——**你只是不能在睡覺的時候變新。** 最後把耳機放回讀者手上：真正有用的，是白天戴著它的那幾個小時。
- **誠實作為記憶點的一部分**：因為整頁都是模擬，那句「**就算全是真的，g = 0.29 在十個字上約 0.3 個字，你不可能感覺得到**」現在被放在誠實聲明的最後一段，同時是揭穿自己、也是全頁最狠的一句。

**敘事容器**：一個夜晚 + 一張實驗桌。前三幕仍然掛著時刻戳（22:40 → 22:58 → 23:06），第四幕把時間標籤換成「實驗設計台」——身分在這裡切換。暗、慢、安靜；但操作很快。

## 這是什麼

一台**睡眠中記憶再活化（TMR）的實驗設計台**。使用者設定一組 protocol，按一顆鈕，頁面用一個真的在跑的模型模擬那一夜：依睡眠醫學的週期結構生成 hypnogram（canvas 繪製）、把線索落到指定階段的實際時刻上、逐次判定會不會把人吵醒，最後算出效果量與兩組保留率。**整個結果面板都是模型算出來的，頁面上明講。**

## 怎麼玩

1. **設定 protocol**（全部原生表單元素，預設值就是有效的那一組）：
   - **白天先學過這十個字**（checkbox，預設開）——最重要的那個開關。關掉時，任何組合的效果都趨近零。
   - **在哪個階段播線索**（select）：N3 慢波深睡／N2 淺睡／REM／清醒／整夜隨機撒。
   - **播幾次**（range 0–8，預設 5）。0 次就是純對照組。
   - **音量**（select：低／中／高）。高音量會提高吵醒機率並打折效果。
   - **線索後面立刻補上答案**（checkbox，預設關）。打開就歸零。
2. **按「跑這一夜」**：整夜 4.6 秒跑完；動畫途中可以按「跳過動畫，直接看結果」立刻結束；跑完主鈕變成「再跑一夜」。
3. **看結果**：效果量 g（數字會滾上去）、被點名／未點名兩組的保留率長條與差距、放大到論文規模的字數差，以及一段**判詞**告訴你為什麼有效／為什麼沒效。
4. **連跑與並排比較**：每跑一夜就在下面的「實驗紀錄」疊一列（protocol → 結果），新的一列會短暫高亮。可以連跑好幾種條件，親眼看出約束條件長什麼樣。有「清空紀錄」。
5. **「一次跑完整組（8 種條件）」**：自動連跑八種關鍵條件，把整張矩陣一次攤開（見下）。這是給趕時間的人的高潮。
6. **側門（可選）**：頁尾一個折疊區「想親身試一次？大約要兩分鐘，而且結果會有點掃興。」——真的學十個荷蘭文、真的考一次，收在「TMR 全開也只值 0.3 個字」。這條路**不在主線上**，預設收合。

## 為什麼有趣

因為它的結論是**反直覺兩次**的。第一次：睡覺學外語是假的。第二次：可是有一種很窄的版本是真的，只是它苛刻到近乎刁難。

而改版之後，那個「苛刻」不再是用文字宣稱的，是**使用者自己把它撞出來的**：關掉「白天先學過」，不管怎麼調都是零；把線索移到 REM，數字翻負還把自己吵醒；把音量開大、次數加倍，效果反而掉了。**約束條件的形狀，是使用者用旋鈕摸出來的。**

## 資料來源與方法論

### 〇、最重要的一句：這一頁的結果全部是模擬

頁面預設路徑**沒有任何真實測量**。沒有人在使用者耳邊念荷蘭文，使用者也沒有睡著。結果面板上掛著一個虛線徽章「**整個面板都是模型算出來的**」，面板下方有一段固定可見的誠實聲明，把三件事講清楚：

1. 這一頁做的是「生一夜 hypnogram → 把線索落到那一夜真正的階段上 → 用一組有出處的參數算效果量」；
2. **哪些參數來自論文、哪些是我設的假設值**（下面第五節逐條列出）；
3. 就算全部是真的，**g = 0.29 在 10 個字上大約是 0.3 個字**，你不可能感覺得到。

唯一涉及使用者真實表現的地方是頁尾那個**預設收合的側門**，那裡明講「這一頁只有這個數字沒有經過任何模型」。

### 一、核心論文

**Schreiner, T., & Rasch, B. (2015). Boosting Vocabulary Learning by Verbal Cueing During Sleep. _Cerebral Cortex, 25_(11), 4169–4179.**
DOI: <https://doi.org/10.1093/cercor/bhu139>　PMID: 24962994

- **設計**：說德語的受試者在**清醒時先學**一批荷蘭文—德文的單字對。之後：
  - **睡眠組**：在**非快速動眼睡眠（NonREM）**期間，重新播放其中**一部分**荷蘭文單字；另一部分不播，作為**組內對照**（同一個人身上比較被播過與沒被播過的字，排除個人差異）。
  - **清醒對照組**：兩組——**主動清醒**（專心聽）與**被動清醒**（當背景音）。
- **結果**：睡眠中被重播的字，之後對德文翻譯的回憶成績**優於**沒被重播的字；**清醒時重播沒有這個效果**（主動、被動都沒有）。
- **神經機制**（高密度腦電圖）：成功的線索伴隨額區明顯的**事件相關電位負波**、額區**慢波頻率提高**、以及**右額與左頂的 theta 振盪功率上升**。
- 論文的措辭是：睡眠中的語音線索**再活化**（reactivate）了相關記憶，促進之後的回憶，而**不干擾正在進行的鞏固歷程**。

#### 為什麼清醒對照組是關鍵

沒有它，這個實驗一文不值。任何「多聽幾次記得比較牢」的平庸解釋都能解釋睡眠組的結果。清醒組把那條路堵死了：**同樣的重播、同樣的次數，在清醒時什麼都沒發生。**這也是為什麼設計台把「清醒」放進階段選單——那不是一個湊數的選項，是那篇論文最重要的一格。

### 二、破梗那一段的出處

**Simon, C. W., & Emmons, W. H. (1956). Responses to material presented during various levels of sleep. _Journal of Experimental Psychology, 51_(2), 89–97.**

在此之前的「睡眠學習」實驗只憑實驗者目視判斷受試者是否睡著。Simon 與 Emmons 一邊播放材料一邊記錄腦波，發現**受試者事後答得出來的題目，播放當下的腦波都還屬於清醒或極淺的狀態**；真正進入睡眠之後，材料無法被習得。（相關回顧另見 Simon & Emmons, 1955, _Psychological Bulletin, 52_(4), 328–342, "Learning during sleep?"）

**誠實的但書（頁面上也寫了一小段）**：近年確實有睡眠中的**內隱**學習證據——

**Züst, M. A., Ruch, S., Wiest, R., & Henke, K. (2019). Implicit Vocabulary Learning during Sleep Is Bound to Slow-Wave Peaks. _Current Biology, 29_(4), 541–553.** DOI: 10.1016/j.cub.2018.12.038

受試者在慢波的**波峰**上被播放假詞—真詞配對，事後在強迫選擇作業上的正確率略高於機率水準，但**無法外顯地說出自己學過什麼**。頁面把這個區分寫進破梗段落的註記裡，沒有藏起來。

### 三、這條研究線後來怎麼了（頁面收尾誠實反映）

### 四、睡眠週期結構的依據

睡眠階段圖不是隨手畫的。它照下列教科書級的事實生成（Physiology of Sleep, StatPearls / NCBI Bookshelf 等睡眠醫學標準敘述）：

- NREM 與 REM 以**約 90 分鐘**為一個週期循環；
- **慢波睡眠（N3）集中在前面幾個週期**，並逐個週期縮短；
- **REM 期逐個週期加長**——第一段常不到 10 分鐘，後面的可以到 40 分鐘；
- 成人整夜比例大致為：N1 約 2–5%、N2 約 45–55%、N3 約 15–25%、REM 約 20–25%。

#### 生成器（`buildHypnogram(seed)`，整夜 480 分鐘 = 8 小時，23:30 → 07:30）

```
入睡前     清醒 6 分鐘
週期 1..5  每個週期 90 分鐘，依序為
           N1 → N2(前段) → N3 → N2(後段) → REM  （最後一個週期沒有 N3）
           N2 前後段比例 45% / 55%
           週期參數（分鐘）：
             週期  N1   N3   REM   REM 後的短暫清醒
               1    8   48    8      0
               2    4   36   16      0
               3    4   16   24      3
               4    4    6   30      3
               5    4    0   34      0
收尾       N2 一段 + 清醒 6 分鐘（把總長對齊 480）
抖動       N1 ±1.5、N3 ±3、REM ±3 分鐘，由 mulberry32(seed) 決定
```

**與舊版的差別**：每一次「跑這一夜」用的是**不同的種子**（`seed ^ 0x9E3779B9`），所以每一夜的結構都會微幅不同，不再是同一張固定的圖。掃 200 顆種子的實測：

| 階段 | 佔比範圍 | 對照教科書區間 |
|---|---|---|
| N1 | 4.0–5.8% | 2–5% |
| N2 | 42.5–49.0% | 45–55% |
| N3 | 20.0–23.8% | 15–25% |
| REM | 21.0–25.2% | 20–25% |
| 清醒 | 3.8% | — |

- **前半夜的 N3 佔全夜 N3 的 91.3–97.2%**（每一顆種子都成立）；
- **後半夜的 REM 佔全夜 REM 的 73.9–83.0%**（每一顆種子都成立）；
- REM 段數固定 4–6 段；最後一段 REM 必長於第一段；第一段 N3 必長於最後一段 N3。

### 五、模型：完整公式、參數，以及哪些是論文給的、哪些是我設的

```js
/* ── 常數 ───────────────────────────────────────── */
BASE   = { N3: 0.27, N2: 0.32, N1: 0.00, REM: 0.00, W: 0.00 }  // 各階段的 Hedges' g
AROUSE = { N3: 0.06, N2: 0.12, N1: 0.35, REM: 0.30, W: 0.20 }  // 喚醒傾向
VOLF   = { low: 0.5, mid: 1.0, high: 1.9 }                     // 音量因子
COST_K = 0.12   COUNT_K = 3   COUNT_REF = 5
SD_PP  = 12     BASE_RET = 0.62   LIST_N = 60
WAKE_PEN = 0.06   WAKE_TH = 0.12   WAKE_SLOPE = 2.2
NOISE_REL = 0.07  NULL_SD = 0.012

/* ── 純函式 ─────────────────────────────────────── */
volFactor(v)          = VOLF[v]
satCount(n)           = n>0 ? (1 − e^(−n/3)) / (1 − e^(−5/3)) : 0      // n=5 時恰為 1.0
arousalCost(stage,v)  = AROUSE[stage] · volFactor(v) · 0.12
wakeChance(stage,v)   = stage==='W' ? 0
                      : clamp((AROUSE[stage]·volFactor(v) − 0.12) · 2.2, 0, 0.85)

/* ── 一夜（simulateNight(protocol, seed)）───────── */
segs   = buildHypnogram(seed ^ 0x9E3779B9)
times  = pickCueTimes(segs, stage, n, rnd)      // 見下
每一次線索 i：
    stage_i = 疊上「已插入的清醒段」之後，該時刻真正的階段
    base_i  = BASE[stage_i]
    cost_i  = arousalCost(stage_i, vol)
    若 rnd() < wakeChance(stage_i, vol) → 吵醒一次，圖上插入 7 分鐘的清醒段

live    = 學過 且 沒補答案 且 n>0                 // 三個硬性歸零條件
benefit = live ? mean(base_i) · satCount(n) : 0
cost    = live ? Σ cost_i                   : 0
g       = live ? (benefit − cost)·(1 + 0.07·z₁) − 0.06·吵醒次數
               : clamp(0.012·z₂, ±0.04)      // 空結果會在 0 附近抖動，不是硬編的 0

pp         = g · 12                          // 保留率百分點
uncuedRate = clamp(0.62 + 0.015·z₃, 0.30, 0.92)
cuedRate   = clamp(uncuedRate + pp/100, 0, 1)
字數差     = (cuedRate − uncuedRate) · 60     // 論文規模：每組 60 個字
```

`pickCueTimes`：
- **指定階段時**，先掃出整夜屬於該階段的每一分鐘，把這串候選切成 n 等分，**每一等分裡隨機挑一個**——線索因此分散在整夜，而不是擠在一起。
- **「整夜隨機撒」時**，把整夜切成 n 段，**每段裡真的隨機挑一個時刻**。刻意不用等距落點：等距的間隔會和 90 分鐘的睡眠週期產生**別名效應**，每次都落在同一個相位上（實測會讓效果虛高一倍），那就不叫隨機撒了。

#### 哪些數字來自論文、哪些是假設值

| 參數 | 來源 | 說明 |
|---|---|---|
| `BASE.N2 = 0.32` | **論文** | Hu et al. (2020) 統合分析的 N2 分階段 Hedges' g |
| `BASE.N3 = 0.27` | **論文** | 同上，慢波睡眠 |
| `BASE.REM = 0`、`BASE.W = 0` | **論文** | 同上：REM 無效、清醒無效 |
| `BASE.N1 = 0` | **假設** | 統合分析沒有報 N1；N1 是過渡階段，保守設為 0 |
| 「補答案 → 效果歸零」 | **論文** | Schreiner, Lehmann & Rasch (2015, _Nat Commun_) |
| 「沒學過 → 效果歸零」 | **論文** | Simon & Emmons (1956)：睡著之後新材料進不去；TMR 的定義本身就是「再活化既有痕跡」 |
| `AROUSE`（各階段喚醒傾向） | **假設** | 沒有單一權威數字。排序依睡眠醫學常識：慢波睡眠的喚醒閾值最高、N1 與 REM 最低 |

| `COST_K = 0.12` | **假設** | 把喚醒成本折算成效果量的係數 |

| `WAKE_PEN = 0.06` | **假設** | 每醒一次扣的效果量 |
| `SD_PP = 12` | **假設** | 把 g 換算成保留率百分點所需的組內標準差 |
| `BASE_RET = 0.62` | **假設** | 未點名組的保留率基線 |
| `NOISE_REL = 0.07`、`NULL_SD = 0.012` | **假設** | 隨機性。刻意小於條件之間的差距（見下方斷言） |
| `LIST_N = 60` | **論文規模** | Schreiner & Rasch 用 120 個字、一半被點名 |

| 階段 | 效果量 g | 平均吵醒次數 |
|---|---|---|
| N3 慢波深睡 | **+0.233 ± 0.015** | 0.00 |
| N2 淺睡 | **+0.247 ± 0.016** | 0.00 |

## 渲染自我檢查表

- **SVG 漸層描邊**：全頁**沒有任何 SVG**。睡眠階段圖有大量水平線段，正是 `stroke:url(#g)` + 預設 `objectBoundingBox` 最容易整條消失的情境——所以**整張圖走 canvas**，從根本上避開。
- **逐路徑 drop-shadow**：全頁沒有 `filter: drop-shadow()`。canvas 內只有時間游標那一個圓點用了 `shadowBlur`（圓點有面積，且用 `save/restore` 包住），水平線段一律不掛陰影。
- **canvas 一定有 CSS 尺寸**：`#hypno` 是 `height:230px`（≤560px 改 190px）、`#eeg` 是 `height:84px`（≤560px 改 72px），不是只有 `width:100%`。
- **resize 回饋迴圈**：`fitCanvas(cv, force)` 先算出 `w / h / dpr` 再**逐一比較**，三者都沒變就 `return false`，完全不碰 `canvas.width`。尺寸狀態存在 `WeakMap`（每個 canvas 各一份），並有無 WeakMap 環境的退路；`dpr` 上限鎖 2。無頭測試連發 **200 次 `ResizeObserver` 回呼 + 50 次 `resize`**，`canvas.width` 的指派次數**一次都沒有增加**；dpr = 1、420px 寬的窄畫布另外連發 100 次也不重設。
- **dasharray 畫線動畫**：**沒有使用 CSS dasharray 動畫**。整夜的「畫出來」是 canvas 內依動畫進度 `view.t` 逐分鐘重繪，重播只要把 `view.t` 歸零；REM 的虛線是 canvas 的 `setLineDash`（靜態樣式，不是動畫），畫完立刻還原。成績長條用 `transform: scaleX()`。
- **繪製方向**：階梯線一律由 `t = 0` 走到 `t = view.t`（左 → 右、時間由早到晚），與夜晚推進的方向一致，不會倒放。腦波是環狀緩衝區從左往右畫，同方向。
- **rAF 紀律**：單一 rAF 迴圈；`setRunning()` 同時檢查 `document.hidden`、`prefers-reduced-motion`、`IntersectionObserver` 的 `inView`、以及「現在是不是正在跑一夜」，任一不成立就 `cancelAnimationFrame`。**全頁沒有任何 `setInterval`**；`setTimeout` 只有四處：成績長條的一次性進場、新紀錄列高亮 1.4 秒後移除、整組連跑的 330 ms stagger、以及 `resize` 的 120 ms 防抖。
- **prefers-reduced-motion**：初始讀取 + `matchMedia` 的 `change` 動態監聽（`addEventListener` 優先、退回 `addListener`）。開啟時：
  - CSS 端把**所有** `animation` 與 `transition` 關掉，`scroll-behavior` 改回 `auto`；所有 `.rv` 直接顯示；
  - **按「跑這一夜」直接出結果，完全不啟動 rAF**（實測 rAF 呼叫次數 = 0，耗時 10 ms）；「跳過動畫」鈕根本不會出現；
  - 「一次跑完整組」的 stagger 設為 0，58 ms 跑完；
  - 中途切換到減動態時，正在跑的那一夜會立刻結束並給出結果——**不會出現「夜晚永遠到不了天亮」**。
- **睡眠階段不只靠顏色區分**：每個階段有**固定的列位置**（清醒最上、N3 最下）與**永遠可見的中文列標籤**；**N3 額外畫成往下延伸的實心區塊**；**REM 畫成虛線 + 斜線網底**；線索標記用**形狀**區分（有效是實心圓、無效是叉），被吵醒的那一次在「清醒」列上多畫一個標著「醒」的圈；圖例同時說明形狀與圖樣。
- **無障礙**：全部原生元素（`<button>` / `<select>` / `<input type=range|checkbox|text>` / `<fieldset><legend>` / `<details><summary>` / `<output>`）；每個控制項都有 `<label for>`；全站 `:focus-visible` 有明顯外框；兩張 canvas 有 `role="img"` 與描述性 `aria-label`；**結果一律經由一個隱藏的 `role="status" aria-live="polite"` 區播報**，內容是「效果量、保留率差、判詞」組成的一段完整句子（刻意只用這一個播報通道，避免結果面板與狀態區重複念兩次）；「一次跑完整組」跑完也會播報摘要。
- **手機**：≤820px 結果區從「大數字 + 長條」兩欄變單欄；≤560px 旋鈕改單欄、按鈕滿版、縮字級與圖高。紀錄表放在可橫向捲動的容器裡（`min-width:620px`），不會擠爆版面。時間軸左邊界在窄畫布時自動從 52px 縮成 38px，最左與最右的時刻標籤改用 `left` / `right` 對齊避免被裁掉。
- **`file://` 可開**：純靜態單檔。無 ES module、無 `fetch()`、**無任何外部資源**（連 cdnjs 都沒用）、**無任何外部音檔**。
- **沒有聲音**：改版後整頁不播任何聲音，也不建立 `AudioContext`。舊版的合成音是為了「線索響起」那一刻服務的；新版一夜只跑 4.6 秒、線索密集落下，聲音只會變成噪音。

## 改版紀錄（2026-08-10）

### 為什麼改

上線版的預設路徑要求使用者**真的學十個荷蘭文 → 真的考一次睡前基準 → 躺下後守著時間軸、在正確的睡眠階段親手按五次點名 → 早上再考一次**。全程好幾分鐘，中間有等待與時機壓力。大部分人會在學單字那一段就離開，看不到這一頁真正的內容。**主題很好，但門檻擋在故事前面。**

### 改了什麼

1. **身分翻轉：受試者 → 實驗設計者。** 新的主互動是「實驗設計台」：五個旋鈕定義 protocol，一顆鈕跑完一夜（4.6 秒），可跳過動畫、可重跑。從進站到第一個結果**只要一次點擊**。
2. **價值從「一次體驗」移到「條件之間的落差」。** 每跑一夜就疊一列紀錄，可以連跑並排比較；再加一顆「一次跑完整組（8 種條件）」，2.7 秒把整張矩陣攤開。這一顆是給趕時間的人的高潮。
3. **模型重寫，讓五個因子真的進入計算。** 舊模型的整夜效果是「每次線索淨效果的平均」，**次數完全不影響結果**，而且沒有「有沒有學過」這個因子（那時它是靠流程強制的）。新模型是 `benefit = mean(BASE) × satCount(n)`、`cost = Σ arousalCost`，並把「學過／補答案／次數為 0」做成三個硬性歸零條件；喚醒也從「累積條爆表」改成**每次線索獨立的機率**（累積模型在真實的線索間隔下幾乎不會觸發，而且生理上也講不通）。
4. **每一夜的 hypnogram 都是新的。** 舊版固定 `seed = 7`；新版每次跑用新種子，結構會微幅不同。
5. **「整夜隨機撒」是真的隨機。** 第一版寫成等距落點，結果和 90 分鐘的睡眠週期產生別名效應——每次都落在同一個相位上，效果虛高了一倍（0.21 而不是 0.11）。改成分層隨機（整夜切 n 段、每段裡真的隨機挑）。這個 bug 是靠斷言抓到的。
6. **誠實聲明換了講法。** 舊版是「你的真實表現 / 模擬」兩欄對照，並且明講不能把兩欄接起來。新版預設路徑沒有真實表現那一欄，所以改成：結果面板掛一個虛線徽章「**整個面板都是模型算出來的**」，下方一段固定可見的聲明交代**哪些參數來自論文、哪些是我設的假設值**，最後仍然收在那句「g = 0.29 在十個字上約 0.3 個字，你不可能感覺得到」。誠實的量沒有變少，只是換了施力點。
7. **`BASE.N1` 從 0.05 改成 0。** 統合分析沒有報 N1；舊值會讓「低音量的 N1 線索」算出微正的效果，那既沒有依據，也和「只有 NonREM 的 N2／N3 有效」的敘事打架。

### 砍了什麼

- **完整的親身體驗路線（學十個字 → 睡前測驗 → 即時按鈕點名 → 早上測驗 → 兩欄成績）整條移除。** 取捨的理由：它的成本是三到五分鐘與時機壓力，而它換來的東西——「你的真實保留率」——**在 10 個字的尺度上本來就偵測不到 TMR**（那正是這一頁自己的結論）。留著它等於用最貴的互動去證明一件它證明不了的事。
- **改成一個明顯標示、預設收合的側門**：「想親身試一次？大約要兩分鐘，而且結果會有點掃興。」裡面保留了它最有價值的部分——真的學十個字、真的考一次（十題一次作答，不是一題一題卡住），然後把分數直接接到那句記憶點：「就算條件全中，明天早上你會答對 N 個，或者 N+1 個。這個差別完全埋在你昨晚睡得好不好、早餐吃了沒、和你剛剛有沒有手滑的雜訊裡。」**它現在是誠實聲明的一部分，而不是入場費。**
- **即時點名、播放速度切換、手動時間軸、線索合成音、聲音開關**——全部移除。夜晚只跑 4.6 秒，這些控制項不再有意義；聲音在這個節奏下只會變成噪音。
- **localStorage 從兩個 key 減成一個**（`sleepcue26.sound` 移除，`sleepcue26.last` 換成 `sleepcue26.runs`）。
