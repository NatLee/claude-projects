# 科學證實了靈魂

一台放在桌上的「報導可信度檢查機」。八根撥桿、一把檢定力尺、一個會亮的診斷面板，
外加一場讓你親手在純雜訊裡挖出「重大發現」的意外。

---

## 故事線

**鉤子**——第一屏沒有標題、沒有說明，只有一則看起來很像真的假報導躺在你的動態牆上：
「重大突破：科學家首度測得意識離開身體的訊號」。下面一個真的在跑的三秒倒數，
兩顆按鈕：立刻分享／等一下。不管你按哪一顆，或是讓它倒數到零，它都會回你一句話。
到這裡為止，我沒有告訴你這是一個工具。

**轉折**——「你不是不會判斷。你只是手上沒有東西可以按。」那則假報導身上每一個零件
（12 個受試者、「首度測得」、下週的記者會）都是從真報導上拆下來的。所以桌上放了一台機器，
把「這聽起來很扯」這種情緒，翻譯成八個查得到答案的問題。那則報導已經在投入槽裡了，
讀者一根一根把撥桿扳開，看分數怎麼動、看診斷面板怎麼換臉色。

**高潮（由使用者親手觸發）**——「為什麼第一根撥桿一個人就拿走 22 分？因為沒有它，
接下來這件事你我在十秒內都做得到。」讀者變成研究者：30 個人、20 個變項、一個幸福感分數，
資料是他按下按鈕那一刻在瀏覽器裡用亂數產生器做出來的。他一個一個點下去，
點到某一個 p < .05 的時候，一張綠色的「你的第一篇論文」卡片滑出來，
標題已經幫他寫好了：「重大發現：鞋子數量與幸福感呈顯著負相關（r = −.41，p = .025，n = 30）」。
底下一句：你沒有作弊，你只是看完之後才決定要報哪一個。
接著一顆按鈕讓瀏覽器真的跑 2000 次同樣的研究，跑出 64% 上下——正好是 1 − 0.95²⁰。

**記憶點**——把場景拉到 2011 年：有人把這一整套做到了頂級期刊上，而它最後的下場
不是「預知不存在」，是讓一整個學科回頭懷疑自己已經發表過的所有東西。
然後鏡頭回到開頭那則假報導，這次它右下角蓋著檢查機打的 7 分。
收尾不給結論，給一個可以帶走的問句：「他們是在看到資料之前，決定要測什麼的嗎？」
最後一顆按鈕「投入下一則」把機器歸零、捲回投入槽——工具可以一直用下去。

**敘事容器**：一台儀器的介面（投入槽 → 撥桿 → 診斷面板 → 實驗台），
不是捲動科普文章，也不是「標題→一個 demo→三張卡→結語」。

---

## 這是什麼、怎麼用

### 1. 投入槽

貼上任何一則報導的標題。它會**真的掃描**標題裡的動詞強度（`verbScan()`），
偵測到「證實／首度／突破」這類最強級用字就自動替你扳好第 08 根撥桿，並列出命中的詞。

三顆預設：

| 預設 | 是什麼 | 檢查機給幾分 |
|---|---|---|
| 第一屏那則 | 頁面開頭那則假報導 | **7** |
| Bem 2011（真的論文） | 發在 JPSP 的預知研究 | **46** |
| 一個做對的研究 | 預先註冊＋獨立複製成功的樣子 | **97** |

### 2. 八根撥桿（權重總和 100）

| # | 判準 | 權重 | 一句話 |
|---|---|---|---|
| 01 | 有沒有預先註冊 | **22** | 收資料前就公開「要測什麼、怎麼分析」了嗎 |
| 02 | 樣本數 | 14 | 效果量越小、需要的人越多 |
| 03 | 有沒有對照組／盲法 | 14 | 沒有對照組只能說「他們吃了然後好了」 |
| 04 | 有沒有被獨立複製 | **20** | 同一個實驗室自己再做一次不算 |
| 05 | 效果量與 p 值 | 12 | p 說「是不是巧合」，效果量說「有多大」 |
| 06 | 發表管道與同儕審查 | 6 | 故意只給 6 分——Bem 那篇就在頂級期刊 |
| 07 | 利益衝突與資助來源 | 8 | 誰出的錢，他會不會因為這個結論賺到 |
| 08 | 標題的動詞 | 4 | 記者的用字通常比論文強一級 |

每一根都附一個 `<details>`：**怎麼查**（具體到去哪個網站、搜哪個欄位、看哪個關鍵字）
與**為什麼算數**。這些是這頁真正想留給讀者的東西。

### 3. 檢定力尺

拉 n（10–600）、選真實效果量（d = 0.2 / 0.5 / 0.8），即時算出「抓得到它的機率」
與「要有 80% 把握每組需要幾人」。這是給第 02 根撥桿的靠山：
d = 0.2 時，每組 30 人只有 **12%** 的機會，每組 300 人也才 **69%**，要 80% 得要 **393 人**。

### 4. 診斷面板（不是只給一個分數）

- **儀表 + 分數 + 分級**（尚未查證／別按分享／高度存疑／值得追蹤／相當紮實／罕見的紮實）
- **最該去查的一項**：算出每一根撥桿的「最大槓桿」＝ 權重 × (1 − 目前得分)，指出投報率最高的那一項，並直接把查法貼出來。
- **可以直接用的一句話**：由狀態組出來、可一鍵複製，貼進群組就能用。
- **分數是從哪裡來的**：八條分項長條，看得到分數被誰吃掉。
- 全部用 `aria-live="polite"` 播報。

### 5. 多重比較現場

30／100／300 人、20 個變項、一個結果變項，全部是**當場產生的常態亂數**（Box–Muller）。
點任一變項 → canvas 畫散布圖與迴歸線 → 顯示**真的算出來的** Pearson r 與雙尾 p 值。
「一次看完 20 個」把全部攤開；「換一批受試者」重灑。
「跑 2000 次」在 rAF 分片裡**真的跑** 2000 次完整模擬，回報實測比率與理論值 1 − 0.95²⁰ = 64.2%。

把 n 從 30 換到 300 之後再跑一次：假陽性率**完全不變**（還是六成多），
變小的只有那個假的 r。這是全頁最想講的一件事：人多救不了多重比較，事先講清楚才可以。

## 為什麼有用

因為它把「可信度」從一種情緒，變成八個**你自己查得到**的事實問題。
而且它給的不是分數，是**下一步**：最該去查哪一項、去哪裡查、以及一句可以直接講出來的話。

它的核心洞見寫在頁面收尾：**一個發現能不能信，跟它有多驚人無關，
跟研究者在看到資料之前把自己綁得多緊有關。**

## 完整資料來源

### 骨幹案例

1. **Bem, D. J. (2011).** *Feeling the future: Experimental evidence for anomalous retroactive
   influences on cognition and affect.* **Journal of Personality and Social Psychology, 100(3), 407–425.**
   DOI: [10.1037/a0021524](https://doi.org/10.1037/a0021524)
   - 九個實驗，宣稱找到預知／逆向因果的證據。
   - **平均效果量 d = 0.22**；九個實驗裡**八個**達統計顯著。
   - 期刊編輯另外刊了一篇社論說明刊登理由，並明白表達期待別人來複製。

2. **Ritchie, S. J., Wiseman, R., & French, C. C. (2012).** *Failing the future: Three unsuccessful
   attempts to replicate Bem's "retroactive facilitation of recall" effect.* **PLOS ONE, 7(3), e33423.**
   DOI: [10.1371/journal.pone.0033423](https://doi.org/10.1371/journal.pone.0033423)
   - 三次**預先註冊**的獨立複製，**合計 n = 150**，全部失敗，**合併 p = .83（單尾）**。
   - JPSP 起初拒絕刊登這份失敗複製（該刊當時不收複製研究），最後登在 PLOS ONE。

3. **Galak, J., LeBoeuf, R. A., Nelson, L. D., & Simmons, J. P. (2012).** *Correcting the past:
   Failures to replicate ψ.* **Journal of Personality and Social Psychology, 103(6), 933–948.**
   DOI: [10.1037/a0029709](https://doi.org/10.1037/a0029709)
   - 七個實驗、**總 N = 3,289**（最後一個實驗單獨就有 2,469 人），複製 Bem 的實驗 8 與 9。
   - 全部複製嘗試的整合分析：**平均效果量 d = 0.04**，與 0 無異。

**後續影響**：Bem (2011) 通常被視為引爆心理學可重複性危機、催生預先註冊與註冊報告制度的
關鍵事件之一——它的重點從來不是預知，而是「當時所有人都在用的方法，可以做出這種結果」。
頁面裡那句「這篇論文沒有說服心理學家相信預知，它讓心理學家開始懷疑其他所有已發表的發現」
是這段歷史的敘事化說法，不是任一篇論文的原句引用。

### 每一根撥桿的依據

| 判準 | 依據 |
|---|---|
| 預先註冊 | Ritchie et al. (2012) 的三次複製正是預先註冊的；Bem (2011) 不是。這組對照本身就是這一根權重最高的理由。 |
| 樣本數／檢定力 | 標準兩組 t 檢定的檢定力公式（見下方方法論）；Galak et al. (2012) 用 3,289 人把效果量壓到 d = 0.04，也示範了「夠大的 n 會把假效果打回原形」。 |
| 對照組／盲法 | 隨機分派＋盲法是把自發緩解、期待效應、實驗者效應扣掉的標準做法（臨床試驗與實驗心理學通識）。 |
| 獨立複製 | 三份骨幹文獻的核心衝突就在這一根：原團隊 vs 獨立團隊，結論完全相反。 |
| 效果量與 p 值 | Bem 報了 d = 0.22（有效果量），但複製後整合起來是 d = 0.04——說明「有報效果量」是必要而非充分。 |
| 發表管道 | Bem (2011) 通過 JPSP 完整同儕審查，所以這一根刻意只給 6 分。 |
| 利益衝突 | 一般研究倫理規範（Funding / Conflict of interest 揭露），非特定文獻。 |
| 標題動詞 | 科學新聞學的常識性判準：報導的動詞強度普遍高於論文摘要（頁面上只給 4 分，因為它測的是記者不是研究）。 |

### 評分權重怎麼定的——**這是啟發式，不是科學量表**

> **重要聲明：**這台機器的權重（22 / 20 / 14 / 14 / 12 / 8 / 6 / 4）是我為了教學效果訂的
> **啟發式排序**，不是任何經過驗證的心理計量量表，沒有信效度資料，也不應該拿去做任何
> 正式的證據品質評鑑。真正的正式工具請看 GRADE、Cochrane RoB 2、JBI 等既有評鑑架構。

排序的邏輯只有一條：**哪一項最難用「事後調整」偽造，就給它最高的權重。**

- 預先註冊（22）與獨立複製（20）合計 42 分，因為這兩項是唯一「研究者無法在看到結果之後
  回頭修改」的東西——這正是這一頁的中心論點。
- 樣本數（14）與對照組／盲法（14）是設計層面的硬條件，會決定結果值不值得看。
- 效果量與 p 值（12）是報告品質，重要但可以事後補。
- 利益衝突（8）是脈絡訊號，本身不決定真假。
- 發表管道（6）與標題動詞（4）刻意壓低：前者是這頁反覆打臉的東西（Bem 通過了），
  後者測的是記者不是科學。

**分數的算法**：`score = Σ(權重ᵢ × 選項值ᵢ) / Σ權重ᵢ × 100`，每根撥桿的選項值從 0（最差）
到 1（最佳）單調遞增。因為權重恆正、選項值單調不減，所以**整體分數對每一根撥桿都是單調的**：
多一項好特徵，分數不可能變低（有 node 斷言逐項驗過，見下）。

**「最該去查的一項」**：`argmaxᵢ 權重ᵢ × (1 − 選項值ᵢ)`，也就是把哪一項查清楚最多能改變幾分。

**分級門檻**：0–29 別按分享／30–54 高度存疑／55–74 值得追蹤／75–89 相當紮實／90+ 罕見的紮實；
八根全在最低檔時另有一個「尚未查證」狀態，因為 0 分的意思是「我還沒查」，不是「它是假的」。

### 統計方法論

- **Pearson 相關係數**：`r = Σ(xᵢ−x̄)(yᵢ−ȳ) / √(Σ(xᵢ−x̄)²·Σ(yᵢ−ȳ)²)`。
- **相關係數的雙尾 p 值**：`t = r·√(df / (1−r²))`，`df = n − 2`；
  `p = P(|T_df| > |t|) = I_{df/(df+t²)}(df/2, 1/2)`，其中 I 是正則化不完全 Beta 函數
  （Lanczos logΓ ＋ Numerical Recipes 的連分數 `betacf`，收斂門檻 3×10⁻¹⁴）。
- **亂數**：mulberry32 PRNG（可指定種子、可重現）＋ Box–Muller 轉成標準常態。
  20 個「變項」與結果變項全部獨立產生，**真值完全沒有關聯**。
- **家族錯誤率**：k 次比較至少一次假陽性的機率 = 1 − (1−α)^k。
  這裡 k 個相關係數共用同一個 y，但在常態虛無假設下、給定 y 之後各 r 互相獨立，
  所以 1 − 0.95²⁰ = 64.15% 是精確值而不是近似值——頁面上的 2000 次模擬就是在驗這件事。
- **檢定力**（兩組獨立樣本、雙尾 α = .05，常態近似）：
  `power = Φ(d√(n/2) − z_{.975}) + Φ(−d√(n/2) − z_{.975})`；
  `n₈₀ = ⌈2·((z_{.975} + z_{.80}) / d)²⌉`。
  常態近似會比 G*Power 的精確 t 解略小一點點（d = 0.2 時是 393 vs 394），已標明是近似。
  Φ 用 Abramowitz & Stegun 7.1.26 的 erf 近似（誤差 < 1.5×10⁻⁷）。

### node 斷言（59 條，全部通過）

核心數學與評分邏輯全部抽在 `index.html` 的 `<script id="hc-core">` 裡，**完全不碰 DOM**，
可以直接抽出來丟給 node 執行。實際驗過的東西：

1. **Pearson**：已知資料 r = 6/√60 與手算值相符（1e−12）；完全正／負相關 = ±1；
   線性變換後 |r| 不變；零變異回傳 NaN。
2. **t 分布 p 值對照 t 表**：df = 1 / 10 / 20 / 100 的 .05 臨界值、df = 10 的 .02 與 .01 臨界值，
   全部落在 ±5×10⁻⁴；df → ∞ 收斂到 z = 1.96；p 對 |t| 單調遞減。
3. **相關係數的 p 值**：n = 30 / 100 / 300 的 .05 臨界 r（.3610 / .19655 / .1133）誤差 < 1×10⁻³。
4. **多重比較（大量模擬）**：單次比較假陽性率 ≈ 5%（20,000 次模擬）；
   **n = 30 做 20 次比較至少一次 p < .05 的比率 = 0.6434，理論值 0.64151**（20,000 次模擬，容差 0.02）；
   n 加到 300 後比率不變（驗證「人多救不了多重比較」）；5 次比較 ≈ 22.6%。
5. **檢定力**：Φ(1.96) = 0.975；d = 0.2 每組 394 人 → 80%；n₈₀(0.2/0.5/0.8) = 393/63/25；
   檢定力對 n 單調遞增；n = 30 → 12%、n = 300 → 69%。
6. **評分函式**：權重和 = 100；全最差 = 0、全最佳 = 100；
   **單調性 15,600 組比較全通過**（任一根撥桿往好的方向扳，分數絕不變低，且選項值變好時嚴格變高）；
   3,000 組隨機狀態分數都在 0–100；`weakest()` 永遠指向最大槓桿；
   三組預設分別是 7 / 46.1 / 96.8 分；Bem 的最大槓桿確實是「預先註冊」；分級門檻正確。
7. **標題動詞掃描**：強／中／弱三級判對，同時出現時取最強級，空字串與 null 回傳 −1。

另外用 headless Chromium 實機跑過整頁：`file://` 直開、無 console error、
canvas 有實際繪製、蒙地卡羅實測 64.1%、桌機與 380px 手機都沒有橫向溢出。

## 渲染地雷自我檢查表

- [x] **SVG 漸層描邊**：全頁沒有任何 `stroke:url(#…)`，儀表與倒數圈都用純色描邊，
      不會踩到 `objectBoundingBox` 讓水平／垂直線消失的坑。
- [x] **逐路徑 drop-shadow**：沒有掛在任何路徑上；LED 光暈用 `box-shadow` 掛在 `<span>` 上，
      不是掛在零面積路徑。
- [x] **canvas 一定要有 CSS 尺寸**：`#cvScatter` 明確設 `height:250px`（<560px 時 210px），
      不是靠 `height` 屬性撐版面。
- [x] **resize 先比尺寸再重設**：`fitCanvas()` 比較 `clientWidth／clientHeight／dpr`，
      三者都沒變就 `return false`，不重設畫布、不重生狀態；resize 另外 debounce 130ms。
      沒有用 ResizeObserver，所以不存在每幀翻倍的回饋迴圈。
- [x] **dasharray 動畫可靠重播**：儀表在載入預設時走完整配方——
      `transition:none` → dashoffset 歸零 → 讀 `getBoundingClientRect()` 強制 reflow →
