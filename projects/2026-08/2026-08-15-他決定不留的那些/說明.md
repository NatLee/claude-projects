# 他決定不留的那些

**2026-08-15｜學習新知｜📦**

**敘事容器**：一場開箱（1980 年的紙箱 → 卷一 他們給的圖 → 卷二 箱子裡真正的東西 → 卷三 傳說與紙 → 回到紙箱）
**互動形式**：在轟炸機上焊三塊裝甲 → **按鈕把沒回來的 20 架疊上同一張圖** → 轉動 q 讓 Wald 的等式平衡，把不存在的資料算出來

---

## 這一頁的故事線

**鉤子**──不從「二戰有一位統計學家」開始，而從一個紙箱開始。1980 年，一個人從自家搬出一箱舊紙，交給同事說「你讀一讀，看有沒有值得留的」。同事讀完，決定**大部分不留**。留下來的那一疊，寫的人已經死了三十年。開場不解釋這是什麼，只給箱子和那句話。

**鋪陳**──1943 年，西 118 街 401 號。軍方帶著轟炸機的損傷圖上門：機身、主翼、尾翼滿是彈孔，引擎附近乾乾淨淨。彈孔在讀者往下捲時一顆一顆浮出來，圖自己把「該加在洞最多的地方」這個結論說完。

**轉折（讀者先動手，再被打臉）**──決定交到讀者手上：只扛得動三塊裝甲，點三個區塊。畫面即時告訴你「你蓋住了圖上 89% 的彈孔」——這個數字會讓人很有把握。送出、蓋章。然後畫面暗下來：**這張圖上有 380 架飛機，那天出擊的是 400 架。**

**高潮（讀者親手觸發）**──按下「把沒回來的那 20 架疊上來」。原本的彈孔淡下去，一組橘紅色的命中一顆一顆落在機鼻、引擎、油箱——正好是讀者剛剛沒有焊裝甲的地方。接著推演機給出數字：不加裝甲會損失 19.9 架；你的三塊救回 1.9 架；洞最少的那三塊救回 12.2 架。同樣的鋼板、同樣的重量，差十個機組。

**第二個高潮（比傳說更狠）**──翻開箱子裡真正的東西：沒有那句名言，也沒有那張紅點飛機圖，只有一份表和一條等式。Wald 問的是更難的問題——**只憑回來的 380 架，能不能算出沒回來的 20 架各是中第幾發掉的？** 讀者轉動 q（多挨一發後仍飛得回來的機率），讓等式左邊對上 0.200；對上的那一刻表格自己長出來：11.9、5.4、1.6、0.8、0.4，合計正好 20.0。你手上從頭到尾只有活著回來的那些。

**記憶點（回馬槍）**──鏡頭拉回 1980 年的紙箱：那天大部分的紙被判定不值得留下來，那些是什麼，永遠不會有人知道了。**這一頁講的東西，正好就是關於這個。**最後留一句可以帶走的話：下次有人給你一張很漂亮的圖，你只要問一句——這上面少了誰？

## 這是什麼

一頁講**倖存者偏誤（survivorship bias）**的互動敘事。用 1943 年 Abraham Wald 在哥倫比亞大學統計研究組（SRG）的轟炸機裝甲問題當載體，但刻意做兩件多數版本不做的事：

1. **讓讀者先犯錯**，而不是先聽結論。你會親手把裝甲焊在彈孔最多的地方，因為那看起來完全合理。
2. **把傳說和史料分開**。網路上那句「裝甲要加在沒有彈孔的地方」和那張畫滿紅點的飛機圖，都不是 Wald 留下來的。頁面第三卷專門講這件事。

## 怎麼玩

1. 往下捲，看彈孔一顆一顆出現在回收圖上。
2. 在飛機上點三個區塊（或用下面的按鈕），看「蓋住的彈孔比例」怎麼變，然後送出。
3. 按「把沒回來的那 20 架疊上來」，看橘紅色的命中落在哪裡，以及三個方案的損失架數。
4. 翻到卷二，拖動 q 讓等式左邊等於 0.200（答案在 0.851 附近，容差夠寬，用拖的就找得到），看反推出來的損失表長出來。
5. 卷三和尾聲會依序解鎖。

## 為什麼有趣

- **「哇」是機制本身，不是動畫**：你會先拿到一個很漂亮的 89%，然後發現那 89% 幾乎不值錢。這個落差是自己算出來的，不是被告知的。
- **第二幕比第一幕更硬**：從「只有倖存者」的資料反推「不存在者」的分布，看起來像招魂術，但只需要一條等式和一個假設。而且它**自我驗證**——反推出來的五個數字加起來，會剛好回到你已經知道的 20 架。
- **結尾自己就是一個例子**：那個 1980 年的紙箱，本身就是一次倖存者篩選。

## 資料來源與方法論

### 史實部分

- **Wald, A. (1943)**《A Method of Estimating Plane Vulnerability Based on Damage of Survivors》。八份備忘錄，寫於 SRG（哥倫比亞大學，紐約西 118 街 401 號）。**從未正式發表**，1980 年由 Center for Naval Analyses（CNA）出版、解密。1980 年的重印本收錄於 DTIC（ADA091073）。
- **紙箱的故事**：1980 年前後，W. Allen Wallis 離開羅徹斯特大學搬家時找到一箱 SRG 舊文件，交給當時在 CNA 的 Phil DePoy。DePoy 的原話（引自 AMS Feature Column）：他讀完後認為「大部分不值得保存」，只留下 Wald 那一疊，1981 年以 Wald 之名出版八篇。頁面開頭與結尾用的就是這件事。
- **備忘錄的內容分布**：八份中有五份處理「已中 k 發的條件存活機率」，一份處理各部位脆弱度。Wald 在文件中**沒有給任何行動建議**——SRG 的政策是只回答被問的問題。
- **那句名言的出處問題**：「armor goes where the bullet holes aren't」這句話、以及網路上那張畫滿紅點的飛機圖，都**沒有一手來源**。AMS Feature Column「The Legend of Abraham Wald」（Bill Casselman, 2016）逐條檢查後的結論是：故事可能是真的，核心也確實有據，但「最精彩的那幾段幾乎沒有證據」。目前唯一把 Wald 和這個推理明確連在一起的一手記述，是 Wallis 1980 年發表於 JASA 的文章之後的那篇 rejoinder（頁面卷三引用的段落即出自此）。
- **Wald 之死**：1950 年，Wald 與妻子在印度南部山區的一場空難中過世，時年 47 歲；他沒有留下自傳。（Morgenstern, *Econometrica* 19, 1951；Wolfowitz, *Annals of Mathematical Statistics* 23, 1952）
- **通俗版本**：Jordan Ellenberg,《How Not to Be Wrong》(Penguin, 2014) 開篇。頁面尾聲「復健室裡腿中槍的人比胸口中槍的人多」的比喻、以及基金存活偏誤的例子，都出自這裡。AMS 稱它是「較好的一種合理重建」。

### 卷二的算式（真的是 Wald 的）

示例數字取自 Mangel & Samaniego (1984)《Abraham Wald's Work on Aircraft Survivability》(*JASA* 79) 轉述的 Wald 原例：

| | 架數 | 比例 |
|---|---|---|
| 出擊 | 400 | 1.00 |
| 回來 | 380 | 0.95 |
| 沒回來 | 20 | 0.05 |
| 回來、0 發 | 320 | 0.80 |
| 1 發 | 32 | 0.080 |
| 2 發 | 20 | 0.050 |
| 3 發 | 4 | 0.010 |
| 4 發 | 2 | 0.005 |
| 5 發 | 2 | 0.005 |

設 q_i = 已中 i−1 發、再中第 i 發仍飛得回來的條件機率。Wald 基本等式：

```
Σ_{m=1..n}  s_m / (q₁q₂…q_m)  =  1 − s₀
```

在「每一發同樣傷」的最簡化下（Wald 自己先做的第一步近似）令所有 q_i = q：

```
0.080/q + 0.050/q² + 0.010/q³ + 0.005/q⁴ + 0.005/q⁵ = 0.200
```

解得 **q ≈ 0.851**（頁面用二分法；AMS 用牛頓法得到同一個值）。再由

```
L_i = (1 − q) · ( N − Σ_{j<i} S_j − Σ_{j<i} L_j )，  L₀ = 0
```

遞推得 L₁…L₅ ≈ 11.9 / 5.4 / 1.6 / 0.8 / 0.4，**合計 20.0** —— 與實際損失架數吻合，這是這條式子的自洽性檢查，也是 `tests.js` 的主要斷言。

需要說明的是：Wald 的備忘錄在這一步之後還走得更遠，改用**不等式求 q_i 的合理上下界**而非單一估計值；頁面只呈現他的第一步近似，因為那一步已經足以把「反推不存在的資料」這件事講清楚。

### 卷一的裝甲推演機（示意模型，非史料）

1943 年的原始損傷數字沒有留下來，所以頁面上的六區參數是**為了說明而設的**，不是史料。頁面本身也標明了這一點。模型如下（見 `logic.js`）：

| 區塊 | 面積比例 a | 中一發後仍飛得回來 s |
|---|---|---|
| 機鼻與駕駛艙 | 0.08 | 0.25 |
| 引擎 | 0.10 | 0.15 |
| 油箱與油路 | 0.12 | 0.40 |
| 機身 | 0.30 | 0.97 |
| 主翼 | 0.28 | 0.95 |
| 尾翼 | 0.12 | 0.90 |

- **唯一的假設**（也是 Wald 的假設）：命中位置在機身表面**均勻分布**，即落在某區的機率 = 該區面積比例。
- 每架飛機這趟中 k 發的機率：`[0.862, 0.079, 0.039, 0.012, 0.005, 0.003]`（k = 0…5）。這組數字是回推出來的——目的是讓「不加裝甲時 400 架出擊約損失 20 架」與備忘錄那一頁對齊（實際算出 19.9）。
- 一架飛機活著回來的機率 = Σ_k P(k)·h^k，其中 h = Σ_r a_r·s_r。
- **回收圖上看得到的彈孔**，各區占比 ∝ a·s；**沒回來的飛機身上的命中**，各區占比 ∝ a·(1−s)。這兩條就是整頁的核心：同一組均勻的命中，被「有沒有回來」這道篩子分成兩張完全相反的圖。
- 裝甲的效果：把該區「這一發會把飛機打下來」的機率壓成原本的 1/4（`ARMOR_CUT = 0.25`）。
- 結果：不加裝甲損失 **19.9** 架；焊在彈孔最多的機身＋主翼＋尾翼損失 **18.1**（救回 1.9）；焊在機鼻＋引擎＋油箱損失 **7.7**（救回 12.2）。差距 6.4 倍。一架 B-17 標準機組 10 人，兩案相差約 10.4 架，即約一百人。
- 彈孔的散布位置用固定亂數種子（mulberry32）產生，所以每次打開圖都一樣；主翼取樣會避開引擎與油箱區以免視覺重疊。

`tests.js` 用 node 斷言驗證：面積與機率分布總和為 1、基準損失落在 20±0.6、回收圖上引擎彈孔占比 <3%、沒回來的機上前三區占比 >80%、Wald 方案救回的架數是直覺方案的 4 倍以上、裝甲的單調性、q 解出來落在 0.851±0.002、反推損失總和 = 20±0.01、L₁ 過半。
