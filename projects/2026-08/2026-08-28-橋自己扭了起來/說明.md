# 橋自己扭了起來——塔科馬海峽大橋聽證會

## 故事線

1940 年 11 月 7 日上午 10 點，你正握著方向盤開上塔科馬海峽大橋。過路費七十五分——四個月來，駕駛專程排隊來坐這座通車第一天就會上下起伏的「奔騰的葛蒂」。頁面以事故調查聽證會的形式逐件呈上證物：太瘦的鈑梁設計、可愛的垂直波動，然後在上午十點「喀」的一聲，畫面從側視圖切換成正視圖——橋面開始以前所未見的方式**扭轉**，扭角 35 度，每分鐘 14 次，慢得令人不安。插曲交代唯一罹難者：困在車裡的可卡犬 Tubby。接著聽證會傳喚你上風洞台：一座簡化橋模型、一支風速滑桿、兩份假設。教科書的「純共振」假設怎麼吹都吹不垮；切到「顫振（含扭轉自由度）」，一過臨界風速 19 m/s，振幅指數放大、模型斷裂——你親手證明了教科書錯了。回馬槍：葛蒂的殘骸如今是章魚公寓；而你的物理課本「共振」那一頁，還在不在？

## 這是什麼

「每日小專案」的科學趣聞子頁面：單檔 HTML（CSS/JS 全 inline），雙擊即可開啟。以敘事捲動頁 + 互動風洞模擬，講 1940 年塔科馬海峽大橋崩塌，以及「共振說」與「氣動彈性顫振」之爭。

## 怎麼玩

1. 往下捲動，依聽證會證物順序讀完前因（垂直模態動畫→扭轉模態動畫→Tubby 插曲）。
2. 到「風洞台」：預設是**假設 A・純共振（教科書版）**。拖動風速滑桿 0–30 m/s——你會在 15 m/s 附近找到一個小峰值（渦脫頻率恰好對上固有頻率），但振幅永遠有限，吹不垮。
3. 切換**假設 B・顫振（含扭轉自由度）**：低於 19 m/s 時模型晃一下就收斂；一旦超過臨界風速，有效阻尼轉負，扭角指數放大直到 35 度斷裂。斷裂後可按「重建模型」重試。
4. 全程鍵盤可操作（Tab / 方向鍵）；若系統開啟「減少動態效果」，動畫定格、模擬改為一次算完直接呈現結果曲線。

## 為什麼有趣

- **教科書之恥**：幾十年來物理課本把塔科馬當「共振」的招牌案例——風的週期剛好對上橋的固有頻率。但當天的風是穩定的，渦脫頻率（約 1 Hz）跟扭轉頻率（14 次/分 ≈ 0.23 Hz）根本對不上。1991 年 Billah 與 Scanlan 在《American Journal of Physics》正式點名這個集體錯誤。
- 真正的機制是**氣動彈性顫振（aeroelastic flutter）**：橋面一扭，風的攻角改變；攻角改變，風給的扭力矩更大——正回饋、自激振盪，不需要風有任何週期性。「不是風的節奏對上了橋，是橋自己跟自己共舞。」
- 這頁讓你**親手做實驗分出勝負**：同一支滑桿，兩個模型，一個怎麼吹都有限振幅，一個過臨界就發散——這正是兩種理論最本質的可觀測差異。

## 物理模型與簡化

把橋面簡化為**單一扭轉自由度** θ（弧度）的線性振子：

```
I·θ'' + c·θ' + k·θ = M(t)          k = I·ω²
```

- **假設 A・純共振**：阻尼固定為結構阻尼 `c = 2ζωI`，外力為週期性渦脫強迫
  `M = F0·U²·sin(Ωt)`，其中 `Ω = St'·U`（渦脫頻率隨風速線性變化，Strouhal 關係的簡化）。
  線性受迫振盪的穩態振幅為 `F0U² / √((k−IΩ²)² + (cΩ)²)`——**永遠有限**；即使 Ω=ω 完全對頻，也被阻尼壓在幾度以內。
- **假設 B・顫振**：氣動力矩含自激項 `M_a ∝ U²·θ'`（扭轉速度改變攻角、回饋出同向力矩），併入阻尼得**有效阻尼**
  `c(U) = 2ζωI·(1 − U²/Uc²)`。
  當 `U > Uc` 時 c 轉負，任何微擾（模型中以決定性亂數模擬紊流）都以增長率 `σ = −c/2I` 指數放大，直到扭角超過 35°（史實斷裂扭角）判定崩塌。臨界風速取 `Uc = 19 m/s`，對齊 1940-11-07 的實測風速。

**主要簡化**（與真橋的差異）：
- 真實顫振是**扭轉—升沉二自由度耦合**（θ 與 y），完整式為 Scanlan 的 flutter derivatives（H*、A* 係數）體系；本頁把耦合效應整併進單一「有效阻尼隨 U² 遞減」的扭轉方程，保留「過臨界→負阻尼→指數發散」的本質。
- 結構阻尼比取 ζ=0.18（真橋僅約 0.005），固有頻率也調到示範尺度——否則發散要等好幾分鐘，網頁上看不完。
- 數值積分用半隱式歐拉、固定步長 1/120 s；紊流微擾用可重現的 mulberry32 亂數。

模型抽成純函式（`PHYS`、`effDamping`、`criticalSpeed`、`stepTheta`、`simulate`），可整段抽出以 node 斷言（實測通過）：

```js
simulate('flutter', 12, 60).diverged === false   // 低於臨界：收斂（max ≈ 0.4°）
simulate('flutter', 26, 60).diverged === true    // 高於臨界：發散，約 14 秒斷裂
simulate('resonance', 30, 60).diverged === false // 共振模型：任何風速皆有限振幅
```
