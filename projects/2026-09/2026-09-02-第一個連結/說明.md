# 所有的路都通往同一個字 🔗（2026-09-02・網路趣聞・冷知識）

## 故事線

- **鉤子**：第一屏不解釋名詞，只下一個大膽斷言——「隨便想一個東西。章魚也行，皮卡丘也行。打開它的英文維基百科，點正文第一個連結，一直點下去。不管你從哪裡出發，你都會停在同一個字上面。」而且刻意不說那個字是什麼。
- **鋪陳**：先把規則講死（正文最前面的那一個連結；括號、斜體、註腳、外部連結都不算），然後把選擇權交出去：章魚，還是皮卡丘？
- **轉折**：使用者進入一台假維基百科閱讀器。每一頁只顯示條目的導言第一句（英文原文＋中文對照），句中「第一個有效連結」會發亮、其他連結全部變成不可點的灰色。**只有親手點那一個，紙才會翻頁。** 走到第三、四步時旁白揭曉背後的機制：維基百科的寫作規範要求開頭先定義自己，而定義一件事就是把它放進更大的盒子——你每點一次，就往上爬一階。
- **高潮**：紙翻到最後一頁，整台閱讀器安靜下來，`Philosophy` 以大字落地。章魚 9 步、皮卡丘 12 步；旁邊是 2011 年 94.52%、2016 年 97%、中位數 23 步。接著兩條路被畫成一張匯流圖：**兩條毫不相干的路，在「Proposition（命題）」那一格併成同一條**，之後每一步一模一樣。
- **記憶點（回馬槍）**：最後一顆按鈕問「那，如果起點就是終點呢？」——從「哲學」自己出發：Philosophy → Existence → Reality → Subject and object → **Philosophy**。四步，回到原地。畫面轉成一個緩緩轉動的環：「你以為你一直在往上爬。其實你在繞圈——只是那個圈太大，大部分人走了二十幾步都還沒發現。」
- **收尾**：今晚只要有人改了其中一句話的頭幾個字，這條路就會改道。這一頁記的是 2026-09-02 的走法。

## 這是什麼

「Getting to Philosophy」是維基百科上流傳最久的都市傳說之一，而且是真的：從任何條目出發，反覆點擊正文的第一個連結，絕大多數路徑最後都會抵達「Philosophy」。這一頁不是介紹它，是讓你親手走一次。

## 怎麼玩

1. 選一個起點（章魚／皮卡丘）。
2. 每一頁只有一個連結可以點——那是導言第一句裡最前面的有效連結。點它。
3. 走到底之後，換另一個起點再走一次，匯流圖才會出現第二條河。
4. 最後按「從『哲學』出發」，看它怎麼繞回自己。

進度（走過哪幾條路）會被記住，`localStorage` 前綴 `flink.`（key：`flink.done`）。

## 為什麼有趣

沒有人設計過這件事。維基百科幾百萬篇條目由幾十萬個互不相識的人寫成，唯一的共同約束只是一條格式建議：**開頭第一句要先定義主題**。定義＝上位化，於是每一個「第一連結」都是一次抽象度的爬升，整個網絡就在無人指揮的情況下，把所有具體事物往同一個抽象頂點推。這是自組織最漂亮的日常樣本之一。

而回馬槍更好：那個「頂點」其實不是終點，是一個長度 4 的閉環。系統沒有真正的最上層——它只是把你送進一個夠大的圈子，讓你以為自己還在往上走。

## 資料來源與方法論

- **現象與統計**：[Wikipedia:Getting to Philosophy](https://en.wikipedia.org/wiki/Wikipedia:Getting_to_Philosophy)（2011-05-26 抽樣 94.52%、中位鏈長 23、方法定義：點擊第一個非括號、非斜體連結，忽略外部連結、指向自身的連結與紅字連結；抵達 Philosophy／無連結頁／不存在頁／形成迴圈時停止）。
- **97% 與研究**：[Wikipedia philosophy phenomenon](https://en.wikipedia.org/wiki/Wikipedia_philosophy_phenomenon)。2016 年比例為 97%；現象由維基人 Mark J. 於 2008-05-26 首次記錄，2011-05-25 因 xkcd #903〈Extended Mind〉的滑鼠提示文字而廣為人知。
- **機制解釋**：Ibrahim, M.; Danforth, C. M.; Dodds, P. S.,《Connecting every bit of knowledge: The structure of Wikipedia's First Link Network》, *Journal of Computational Science* 19 (2017) 21–30（arXiv:1605.00309）。研究指出第一連結網路並非因為大量條目直接連向「Philosophy」，而是「由具體向廣義概括」，把 Philosophy 推成最終的錨點。
- **語言差異**：Lamprecht, D. 等，《Evaluating and Improving Navigability of Wikipedia: A Comparative Study of Eight Language Editions》(OpenSym 2016)。德文、法文、俄文版同樣導向哲學；荷蘭文與日文版不會。義大利文版的最高中心性概念是「心理學」，東亞語系則常收束到「人類」或「地球」。
- **本頁的三條路徑**：2026-09-02 於英文維基百科逐頁人工實走並記錄，導言首句為當日原文節錄（為了排版，刪去了註腳標記與部分不影響判定的子句；被判定為「第一個有效連結」的錨文字一律保留原位）。經過的重導向已標成實際落點：`mollusc → Mollusca`、`Pokémon species → List of Pokémon`、`Media (communication) → Means of communication`。
  - 章魚：Octopus → Mollusca → Phylum → Biology → Scientific study → Knowledge → Declarative knowledge → Proposition → Meaning (philosophy) → **Philosophy**（9 步）
  - 皮卡丘：Pikachu → List of Pokémon → Pokémon → Media franchise → Means of communication → Communication → Information → Abstraction → Rule of inference → Premise → Proposition → Meaning (philosophy) → **Philosophy**（12 步）
  - 哲學自己：Philosophy → Existence → Reality → Subject and object (philosophy) → **Philosophy**（4 步閉環）
- **注意**：第一連結會隨編輯改變，上面兩條路徑在幾週後很可能已經不同。頁面結尾對此有明說，這也是故事的一部分。

## 技術

- 使用 `assets/page-kit.{css,js}`；純靜態、`file://` 雙擊可開、無外部資源。
- 核心資料與純函式包在 `/* ==== CORE-START ==== */ … /* ==== CORE-END ==== */` 之間（`NODES`、`firstLinkOf`、`walk`、`firstCommon`），可由 node 抽出後以 `new Function` 執行斷言：三條路徑的完整節點序列、步數、匯流點為 `Proposition`、匯流後兩條路完全相同、無孤兒節點。
- 匯流圖與環都是行內 SVG，只用實色描邊（不使用漸層描邊，避開水平／垂直線不繪製的地雷）；環的旋轉設 `transform-box: fill-box` 與 `transform-origin`，並在 `prefers-reduced-motion` 下停止；畫線動畫使用 `PK.replayDash`。
