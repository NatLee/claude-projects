# 你這輩子點過三千次的那個框

## 故事線

- **鉤子**：不解釋 CAPTCHA 是什麼，直接指認一個你每天在做、卻從沒想過的動作——「你這輩子大概點過三千次那個框。它從來沒告訴你，它真正在問什麼。」
- **轉折**：頁面把那個框重製出來，讓你真的打進去。打完才揭曉：左邊那個字是拿來驗你的，**右邊那個字沒有人知道答案**——你剛剛替一份你沒讀過的舊報紙認出了一個字，而你以為你只是在登入。
- **高潮**：由使用者親手觸發，而且觸發三次。框隨年代變形——2007 的雙字、2012 的街景門牌、2014 的紅綠燈九宮格。第三關過關那一刻是真正的翻頁：紅綠燈、人行道、公車、消防栓不是「人類才認得的東西」清單，**那是一台車在路口需要認得的東西的清單**。
- **記憶點**：拉遠鏡頭。819,000,000 小時的無償人力，然後回到今天只剩一個勾選框——它不再考你，因為它已經學會了。回馬槍：「那個框從來不是在問你是不是人類，它是在問：你還能做什麼，是機器還做不到的？而每一次你答對，那份清單就短一項。」

## 敘事容器

**假介面 + 逐步揭曉**。整頁的骨幹是一個會隨年代變形的驗證框，後面的章節在你通過前**完全不存在於 DOM**（`hidden`），必須親手解開才會出現並自動捲入視野。刻意不用「標題→demo→三張卡→結語」。

## 怎麼玩

1. 第一關：輸入兩個歪字（控制字是 `overhead`，錯三次會給提示）。第二個字打什麼都算過——這正是重點。
2. 計分條會自動跑：兩台 OCR 各 0.5 票、每個人類 1 票，滿 2.5 票定案。
3. 第二關：門牌 `1451`。
4. 第三關：九宮格選出 4 個有紅綠燈的格子（1、3、6、7，0-indexed），全對才過。
5. 結尾：勾選「我不是機器人」，看那條游標軌跡被畫出來。

## 為什麼有趣

因為這是少數「你已經參與了幾千次、卻完全不知道自己在做什麼」的集體行為。把機制攤開的瞬間，一個日常的煩人動作會突然變成一段二十五年的勞動史。

## 資料來源與方法論

- von Ahn, L., Maurer, B., McMillen, C., Abraham, D., Blum, M.（2008）〈reCAPTCHA: Human-Based Character Recognition via Web Security Measures〉，*Science* 321(5895): 1465–1468, doi:10.1126/science.1160379 —— 兩字機制、OCR 0.5 分／人類 1.0 分／2.5 分定案、六人否決即丟棄。
- Google 官方部落格〈Teaching computers to read: Google acquires reCAPTCHA〉（2009-09）—— 收購、《紐約時報》檔案與 Google Books 的數位化。
- 發布日 2007-05-27；卡內基美隆大學（von Ahn、Blum、Abraham、Crawford、Maurer、McMillen、Tan）。
- Hutchinson, A.〈Human Resources〉，*The Walrus*（2009）—— von Ahn 意識到自己「以十秒為單位」消耗人類腦力的那段話。
- TechCrunch（2012-03-29）—— 街景門牌號碼進入 reCAPTCHA。
- Google Security Blog〈Are you a robot? Introducing "No CAPTCHA reCAPTCHA"〉（2014-12-03）—— 勾選框與圖片九宮格；2013 起加入行為分析；2017 推出隱形版；v1 於 2018-03-31 關閉。
- Searles, A., Prapty, R. T., Tsudik, G.〈Dazed & Confused: A Large-Scale Real-World User Study of reCAPTCHAv2〉，arXiv:2311.10911（2023，UC Irvine）—— 13 個月研究，估算 **8.19 億小時**無償人力、約 **61 億美元**工資等值，並指出 v2 對機器人的防護有限。
- 關於九宮格標註是否用於 Waymo：Vox（2021）報導此為外界推測，Google 代表否認，稱資料當時用於改進 Google Maps。頁面上只寫「Google 說是拿去改進地圖，至於還去了哪裡，他們沒有再說」，不做未經證實的斷言。

**重製說明**：頁面中的三個驗證框是示意重製，不是真實驗證服務，也沒有任何連外請求。歪字用 CSS `transform`（rotate/translate/skew）以 `PK.hash` 產生固定抖動，每次載入長得一樣；九宮格的九張圖是就地畫的 inline SVG。控制字 `overhead`、可疑字 `railway`、門牌 `1451` 是為敘事挑的例子，不是真實的歷史語料。

## localStorage

前綴 `cap07.`，三個 key：`cap07.g1`（第一關你替那個字打了什麼）、`cap07.g3`（九宮格已過關）、`cap07.done`（走到最後）。回訪時第一屏會換成另一句話，其餘不變。

## 渲染地雷檢查

- 扭曲字用 HTML `<span>` 而非 SVG 子元素旋轉，繞開 `transform-box`／`transform-origin` 地雷；仍顯式設了 `transform-origin`。
- 兩處 `dasharray` 動畫（游標軌跡、勾勾）一律走 `PK.replayDash`。
- 沒有 canvas，沒有 SVG 漸層描邊，沒有零面積路徑掛 drop-shadow。
- SVG 皆設 `overflow:visible`；`.warp` 用 `overflow:hidden` 讓歪出去的字被紙張裁掉（刻意）。
- `prefers-reduced-motion`：閃爍點停止、計分條瞬間到位、數字直接顯示、打字機整段放上、捲動改 `auto`。
