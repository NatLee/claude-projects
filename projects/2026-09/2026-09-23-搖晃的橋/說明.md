# 不是風，也不是卡車

## 故事線

- **鉤子**：2000 年 6 月 10 日，泰晤士河上開了一座新橋；兩天後被關掉。不是風，不是卡車，不是炸彈。
- **轉折**：Arup 算過風壓、洪水、兩千噸纜索張力，垂直方向穩如磐石——唯獨「左右」沒進到算式裡。因為橫向擺有個垂直方向沒有的怪毛病：橋會回頭教人怎麼走路。
- **高潮**：讀者自己把人推上橋。人少的時候點是散的、橋是靜的；推過一百六十幾人，相位盤上的針啪一聲收成一束，橋面開始整塊左右平移，位移曲線爬向 70 公釐那條紅線。再按一下「裝上 37 組阻尼器」——同一群人、同樣的步伐，橋不再接話。
- **記憶點**：那 70 公釐從來沒有一刻讓橋接近垮掉；把九萬人請下橋的是「兩千個陌生人正在同時往同一邊倒」這件事本身。最後被改寫的不是橋，是規範——今天每一座不動的人行橋，都是有人先替你算過這件事。

敘事容器是**實驗台**（工程師的測試台，讀者親手轉旋鈕），主互動是**滑桿**。

## 這是什麼

倫敦千禧橋（London Millennium Footbridge）2000 年開幕日發生「同步橫向激振」（synchronous lateral excitation）事件的可玩重現。頁面把 Strogatz 等人 2005 年發表在 Nature 的橋—行人耦合模型直接跑在瀏覽器裡，滑桿控制橋上人數，讀者可以自己找出臨界點。

## 怎麼玩

1. 拉「橋上人數」滑桿。人數少於一百多的時候，點是散的、位移曲線貼著底線。
2. 推過一百六十幾人，等個幾秒：右下角相位盤上原本亂指的針會收攏成一束，橋面開始整塊平移，擺幅讀數往上爬。
3. 把人數推到 400（相當於中跨滿載），擺幅會停在 65–70 公釐左右——和 2000 年當天的實測值同一個量級。
4. 按「裝上 37 組阻尼器」，同樣人數重跑一次。

## 為什麼有趣

垂直共振是老知識（亞伯特橋上 1873 年的「軍隊請斷步」告示牌還在）。橫向不一樣的地方在於**回饋是閉環的**：橋一斜，人為了不跌倒會把下一步踩偏，而全橋的人是被同一塊橋面同時推的——他們不需要彼此協調就會同步。人推橋、橋推人，正回饋自己把自己放大。這不是「一群人碰巧同步」，是橋在指揮一群人同步。

## 模型與參數

橋為單自由度振子，行人為 Kuramoto 型相位振子，耦合方式取自 Strogatz et al. (2005)：

```
橋：M x'' + B x' + K x = G Σ sin θi
人：θi' = ωi + C · A · sin(Ψ − θi + α)
```

其中 A、Ψ 是橋面振動的瞬時振幅與相位（由 x 與 x'/Ω 求得），α = π/2。

| 參數 | 值 | 來源／說明 |
|---|---|---|
| M（模態質量） | 113,000 kg | Strogatz et al. 2005 |
| K（模態勁度） | 4,730,000 kg/s² | 同上；Ω = √(K/M) = 6.47 rad/s ≈ **1.03 Hz** |
| B（模態阻尼） | 11,000 kg/s | 同上，阻尼比約 0.008 |
| G（單人橫向力） | 85 N | 為讓臨界人數落在文獻值附近而校準 |
| C（人對橋的敏感度） | 36 m⁻¹s⁻¹ | 同上 |
| σ（步頻分布標準差） | 0.8 rad/s | 同上 |
| 阻尼器 | B × 8 | 示意 37 組黏滯阻尼器＋52 組 TMD 的效果 |

**誠實說明**：M、K、B 取自論文，G、C、σ 三個是為了讓臨界點落在「一百六十幾人」、滿載擺幅落在「約 70 公釐」而校準過的，屬示意用的定性重現，不是 Arup 原始模型的複刻。文獻提到的臨界人數在中跨約 156 人、北跨約 166 人。

模擬時間以 5 倍速推進（`SPEED = 5`），純粹是為了戲劇節奏，物理式子沒有改。積分用固定步長 0.004 秒的半隱式尤拉。

## 技術註記

- 全頁自包含，`file://` 雙擊可開；無外部資源、無 fetch、無 module。
- localStorage 前綴 `wob00.`，只存一個 `best`：使用者這台機器上曾把橋推到的最大擺幅（毫米），下次進來會用它當開場白。
- `prefers-reduced-motion` 下不跑 rAF 動畫，改為在滑桿變動時同步解出 60 秒穩態，畫成靜態快照＋數字，並以 `matchMedia` 監聽即時切換。
- canvas 用 `PK.fitCanvas` 處理 dpr（先比對尺寸相等才重設，避開 ResizeObserver 每幀翻倍的老地雷）。
- 核心 `makeRig` / `stepRig` / `steady` 為純函式並掛在 `module.exports` 下，可直接被 node 抽出斷言；已驗證 8 項：人少不抖、擺幅隨人數單調、跨門檻為跳躍非線性、滿載落在實測量級、阻尼器壓下一個量級、空橋恆靜、模態頻率 < 1.3 Hz、長時間積分不產生 NaN。
