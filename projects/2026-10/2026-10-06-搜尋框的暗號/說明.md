# 搜尋框的暗號

**2026-10-06｜創意・娛樂｜🔣**

**敘事容器**：假介面（一台深炭灰底、琥珀游標的終端機式虛構搜尋引擎「掘字」）
**互動形式**：輸入文字——在假搜尋框裡打查詢，頁面即時解析、即時排序；按 Enter 交件判定。高潮是第七張委託單：所有運算子都救不了，只能換成作者的詞。

## 這一頁的故事線

**鉤子**──第一屏只有兩行：「你要找的東西就在網路上。」「問題是：你打的字，跟它寫的字不一樣。」底下的假搜尋框自己打出「房東不還押金怎麼辦」，回報掘到 2 筆，全是農場與熱搜；市府那份處理須知不在裡面，因為它通篇沒寫「房東」。

**承**──掘字是一台很笨、很誠實的引擎：只收 56 份虛構文件、只認字。八張委託單逐步升級：引號（一字不差的原句）→ 減號（同名休旅車）→ site:（轉貼站排在官方前面）→ filetype:＋日期（年報「年度」與發布年份不同的陷阱）→ OR（三個局處三種叫法）→ intitle:（被提到≠就是它）。

**轉折／高潮（由讀者親手觸發）**──第七張委託單，連 site: 都把筆數篩成 0：官方文件寫的是「出租人」「承租人」「押租金」「返還」。退件訊息直接說出「那份文件裡找不到『房東』」；第二個提示叫你回頭讀排第一的農場文——它為了被搜到，把正式名稱寫出來了。接著第八張要求把所有運算子串成管線，只能剩一份。

**記憶點**──一頁「手冊」把關鍵字思維寫成五條選項（作者的詞彙、具體名詞、錯誤訊息照貼加引號、列出所有叫法、換語言），然後讀者把自己的真實問題丟進「拆字機」，拿到幾種可直接拿去真實搜尋框的寫法。結尾回扣開頭兩行，第三行改成「那就先去學它的字」，最後的假搜尋框裡留著讀者剛剛改寫出來的那串查詢。

## 這是什麼／怎麼玩

- **八張委託單**：每張有情境、目標與過關條件（目標排進前 K 名，且總筆數 ≤ N）。輸入即時更新「解析軌跡」（掘字怎麼讀你的查詢：詞、片語、拆成幾組兩字、排除、網域、類型、日期）與清單（命中的字以琥珀色標出；長中文串被拆成兩字一組比對時，以虛線標出對上的那幾組）。
- **退件診斷**：失敗時逐條說明目標文件被哪條規則擋下（不在該網域、類型不符、日期被擋、找不到某個字、含有你排除的字）、排第幾名、誰擋在前面。
- **漸進提示**：失敗一次給方向、兩次給運算子名稱、三次給示範寫法（可一鍵填入）；也可以主動按「要提示」。
- **常見誤用會被點名**：`site: x`（冒號後空格）、全形冒號、小寫 or、`+`／`~`（已退役）、`cache:`（已退役）、看不懂的日期格式、沒關上的引號。
- **拆字機**：規則式純函式。拿掉問句詞與語氣詞、保護詞庫裡的詞、把口語換成文件常用語（房東→出租人、押金→押租金、加班費→延長工作時間 工資、罰單→罰鍰……）、偵測錯誤訊息並建議整段加引號與去變數版本、偵測年份／檔案類型／官方需求而加上 after:/before:、filetype:、site:gov.tw，必要時給英文術語版本。每條建議可複製。
- **帶走（五個折疊區）**：Google 運算子三欄速查（官方說明頁列出／坊間流傳但官方未列／已退役）、跨平台對照表（Google／Gmail／GitHub Code Search／PubMed）、給工程師（Chrome 網站搜尋捷徑、ripgrep 對應寫法）、五題回家作業、自學地圖。

### 掘字的規則（教學簡化）
- 沒加引號的字：每個都必須出現（不分大小寫、子字串比對）。五個以上中文字連在一起時，拆成兩字一組，命中一半以上就算（模擬「整句丟進去會撈到一堆差不多的頁面」）。
- 排名：字在標題 3 分、在內文 1 分、模糊比對依覆蓋率折算，再加網站熱門度×2（內容農場熱門度高，所以天真的查法會被它們淹沒）。
- 支援 `"…"`（含 `*` 萬用）、`-`、`site:`（網域、子網域、網址前綴）、`-site:`、`filetype:`／`ext:`、`after:`／`before:`（含當天）、`OR`／`|`、`( )`、`intitle:`、`inurl:`。

## 為什麼有趣

運算子教學到處都有，但多數人卡住的地方不是語法，而是「我打的字根本不在那一頁上」。這一頁讓讀者先把篩子練熟，再讓篩子在第七關集體失靈——失敗訊息把「你的字 vs 它的字」的落差攤開來，讀者是被逼著自己發現關鍵字思維的。後段把同一套想法搬到 Gmail、GitHub、PubMed 與命令列，讓從一般讀者到工程師都有東西帶走。

## 資料來源與方法論

查證日期一律為 **2026-10-06**。

- Google 搜尋說明〈Refine Google searches〉https://support.google.com/websearch/answer/2466433 ——官方列出 `"…"`、`site:`、`-`、`before:`／`after:`（可合用、可用 2019-03-01 或 2025/11/01 格式）、`filetype:`；運算子與詞之間不能有空格；另有「工具 → 進階搜尋」。（由主協調者查證，本頁照用）
- Google Search Central〈Overview of Google search operators〉https://developers.google.com/search/docs/monitor-debug/search-operators （頁面標示 Last updated 2025-12-10）——除錯用運算子 `filetype:`、`site:`，以及只在 Google 圖片有效的 `imagesize:`、`src:`。
- Gmail 說明〈Refine searches in Gmail〉https://support.google.com/mail/answer/7190 ——`from:`、`to:`、`subject:`、`after:`／`before:`（2004/04/16）、`older_than:`／`newer_than:`、`OR`／`{ }`、`AND`、`-`、`AROUND`、`has:attachment`、`filename:`、`"…"`、`( )`、`+`（完全符合該字）、負面運算子會讓整串對話仍出現的說明、搜尋後可建立篩選器。
- GitHub Docs〈Understanding GitHub Code Search syntax〉https://docs.github.com/en/search-github/github-code-search/understanding-github-code-search-syntax ——空白＝AND、`AND`/`OR`/`NOT`、`repo:`（完整 owner/name）、`org:`、`user:`、`language:`、`path:`（glob）、`symbol:`、`content:`、正規表示式 `/…/`（不支援 look-around、`(?-i)` 區分大小寫）。（由主協調者查證）
- PubMed User Guide https://pubmed.ncbi.nlm.nih.gov/help/ ——欄位標籤 `[ti]`、`[tiab]`、`[au]`、`[ad]`、`[mh]`、`[dp]`（日期區間 2019/01/01:2019/06/30[dp]）、`[pt]`（如 systematic review[pt]）；布林運算子必須大寫、由左到右處理、可用括號；萬用字元 `*` 前至少 4 個字元；欄位標籤與萬用字元會關閉 Automatic Term Mapping；同欄位多詞要各自加標籤；鄰近搜尋 `"hip pain"[Title:~4]`。
- Chrome 說明〈Set default search engine and site search shortcuts〉https://support.google.com/chrome/answer/95426 ——Settings → Search engine → Manage search engines and site search → Site search「Add」，三欄：名稱、捷徑、以 `%s` 代替查詢的網址。頁面上的中文介面字樣為意譯，已註明「依版本略有不同」。
- ripgrep User Guide https://github.com/BurntSushi/ripgrep/blob/master/GUIDE.md （以 raw.githubusercontent.com 取得）——`-i`、`-S`、`-F`、`-w`、`-c`、`-C`、`-g '*.toml'`／`-g '!*.toml'`、指定目錄、預設略過 .gitignore／隱藏檔／二進位檔、`-u` 逐層放寬、`--debug`、以 pdftotext／`--pre` 搜 PDF。
- Ahrefs〈Google Search Operators: The Complete List〉https://ahrefs.com/blog/google-advanced-search-operators/ （2023-04-25 發表，2026-08-12 更新）——「坊間流傳」欄的 OR、`|`、AND、`*`、`( )`、`define:`、`ext:`、`intitle:`／`allintitle:`、`inurl:`／`allinurl:`、`intext:`；`AROUND(X)` 列為不可靠；退役年份：`+` 2011、`~` 2013、`link:`／`info:` 2017（該文各自連到 Search Engine Land 報導，本頁標示為「據 Ahrefs 引 Search Engine Land」，未直接讀到 SEL 原文）；before:／after: 因頁面更新而不一定準。該文仍把 `cache:` 列為可用，與下列來源矛盾，頁面以此當「清單也會過時」的例子。
- 維基百科〈Google Search〉https://en.wikipedia.org/wiki/Google_Search ——運算子列表（OR／|、*、..、( ) 等）；「As of 2024 Google no longer displays cached versions of webpages」與 cache: 的舊用法。
- 維基百科〈Search engine cache〉https://en.wikipedia.org/wiki/Search_engine_cache ——Google 於 2024-02-02 退役快取（引 The Verge 2024-02-02〈Google Search's cache links are officially being retired〉）。
- **虛構示意**：「掘字」引擎、青岬市與其所有機關、56 份文件的標題／摘要／日期、所有 `.example` 網域、散文家「沈汀」與散文〈退潮以前〉、「雪鴞汽車」皆為虛構；頁面兩處標示「虛構示意」，footer 亦註明。第七關「押租金」等用詞為教學設計（法律文件與判決中常見的寫法），不代表任何真實機關的文件內容。
